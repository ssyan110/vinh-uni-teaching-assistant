# 第一周课外活动：HTML slide prototypes

这三份是给投影机使用的课外补充／活动首屏 prototype。主要课程 slides 仍然使用原来的 PPTX，不在这里替换。

三份 prototype 使用同一组课堂方向：

- 先认识新老师
- 话题限于《初级起步篇》一、二册熟悉的内容：姓名、家乡、家庭、兴趣、日常生活、学习和校园
- 学生听老师说、向老师提问，再回答老师的问题
- 学生已经彼此认识，不安排同学互相采访、介绍或小组提案

## 视觉方向

- `style-a.html`：分屏柔和风。桃色与薰衣草色分开过去、现在、未来，适合温和但有结构的课堂开场。
- `style-b.html`：校园海报风。黑色粗边框、硬阴影和明亮色块，适合希望第一周更有活动气氛的课堂。
- `style-c.html`：校园讯号风。深色网格、讯号点和轨道线，适合较成熟、较有设计感的活动页面。

## 操作

打开任一 HTML 后：

- 使用方向键、空格、Page Up／Page Down、滑鼠滚轮或触控左右滑动。
- 将滑鼠移到左上角，或按 `E`，可以进入文字编辑模式。
- 在编辑模式按 `Ctrl／Command + S` 会保存到浏览器的本地储存。

这些 prototype 目前各有一张固定 1920×1080、16:9 投影舞台，状态是 `prototype_only`，尚未进入课程 release。

## 已选方向：Open-Slide 1920 Canvas

当前投影入口按 [1weiho/open-slide](https://github.com/1weiho/open-slide) 的固定 1920×1080 画布和自由编排原则重做为单文件 HTML。画面保留 Apple 式留白和大字，但每页都直接显示“现在要做什么”：教师先说、学生听、学生问、学生回答，最后留下可直接朗读的句子框。

[打开 Open-Slide 风格完整活动 deck](../lesson-01-课外活动-OpenSlide.html)

12 页流程是：今天认识老师 → 看路线 → 老师自我介绍 → 第一次听大意 → 第二次记三个信息 → 学生问老师 → 听完再问一句 → 老师问学生 → 找一个共同点 → 说清楚自己的情况 → 说课程希望 → 说两句话结束。

活动对象已经互相认识，所以没有同学互相采访、重新配对或小组计划。内容只使用《初级起步篇》一、二册熟悉的姓名、家乡、家庭、兴趣、日常生活、学习和校园话题。投影不要求发纸；教师把第 3 页空格换成自己的真实资料即可。

点击页面或按方向键、空格可以推进；`N` 显示当前页教师口头提示；`E` 进入编辑模式，`Command／Control + S` 保存本机浏览器中的临时修改。页面也支持 URL `#slide=1` 到 `#slide=12`，方便从指定页开始。
