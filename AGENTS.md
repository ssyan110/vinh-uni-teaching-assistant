## Writing quality / AI-isms

When writing or editing any user-facing copy in this project, use the Hermes skill `avoid-ai-writing` automatically. Trigger it for README/docs, website copy, landing-page text, blog/social drafts, lesson content, emails, captions, product messaging, pitch material, and any request like "make this sound human" or "clean up AI writing."

Skill location:
`~/.hermes/skills/writing/avoid-ai-writing/SKILL.md`

Default behavior:
- Use rewrite mode for draft copy unless the user asks for audit/detect only.
- Preserve meaning, facts, technical details, Vietnamese/Chinese language requirements, and project-specific terminology.
- Remove AI tells such as generic hype, em-dash overuse, "delve/leverage/robust/seamless" filler, formulaic openings, excessive bullets, vague attributions, and chatbot-style closings.
- Keep Adam's preferred style: direct, specific, practical, human, concise.
