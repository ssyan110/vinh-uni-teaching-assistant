## Design Direction: Gamma Soft Gradient (LOCKED)

**Full spec:** `reference/ppt-style-guide.md` — apply exactly, do not deviate.

### Quick summary
- White/light backgrounds, soft teal/lavender gradients
- macOS-style frosted menu bar on every slide (except cover/closing)
- Color-coded sections (teal=vocab, orange=warmup/exercises, green=text, purple=practice, pink=culture)
- Vocabulary cards: clean, no examples inside (examples on separate "Mẫu câu" page)
- All vocab includes hán việt in parentheses
- Pinyin ABOVE 漢字 always (separate lines)
- Large text for back-of-room visibility
- Lucide icons for visual cues (via CDN: https://unpkg.com/lucide-static/icons/)
- Unsplash stock images where relevant (via https://source.unsplash.com/)

### Text format rules (all versions must follow)
- Pinyin always ABOVE 漢字 (separate line)
- Vietnamese meaning below
- Examples stacked vertically: pinyin / 漢字 / Vietnamese
- Use "từ vựng" not "sinh từ"
- Use "cụm từ" not "thành ngữ"
- Characters with separators: 一、八、大、不、五、口、白、女、马、你、好
- No page footer references
- Dialogue format: A: pinyin \n 漢字 (top to bottom sequence)
