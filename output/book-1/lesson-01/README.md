# Lesson 01 Folder

Open `index.html` from this folder root for class.

## Folder Map

| Path | Purpose |
|---|---|
| `index.html` | Classroom entry point. Opens `slides/index.html`. |
| `slides/` | Editable slide source files and runtime assets. |
| `database/` | Reviewable lesson data and Google Sheets-ready CSV. |
| `exports/final/` | Clean PDF backups for teaching/archive. |
| `exports/qa/` | Screenshots, contact sheets, and visual QA artifacts. |
| `exports/archive/` | Deprecated generated files kept only for traceability. |
| `teacher-guide/` | Teacher prep notes and Huashu brief. |
| `homework-question-bank/` | Homework/question-bank outputs. |

In class, do not dig through `slides/` unless you need to edit a slide.
