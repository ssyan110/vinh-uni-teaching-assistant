# Teacher Guide Format Reference

Learned from: 《來！學華語》教師手冊 (Let's Learn Mandarin Teacher's Manual, ROC Overseas Community Affairs Council)

This reference defines what a professional Chinese-language teacher's guide must include. Apply this structure when generating teacher guides for our system.

## Required sections per lesson

### 壹、學習目標 (Learning Objectives)
- State the lesson theme
- List 2-4 concrete outcomes: "After this lesson, students can use Chinese to..."
- Outcomes must be observable and measurable (not vague like "understand")

### 貳、教學重點及教學活動設計 (Teaching Focus & Activity Design)

#### 一、暖身活動 (Warm-up)
- Describe the activity format (pair work, whole class, cards, etc.)
- List specific sentences/phrases the teacher will use
- Note whether to write pinyin on the board

#### 二、詞彙教學 (Vocabulary Teaching)
- For each word that needs explanation:
  - Clarify meaning scope in THIS lesson (don't extend to other meanings)
  - Note common student errors
  - Distinguish between standalone words vs phrases (短語)
  - Suggest teaching order (may differ from textbook order)
- Teaching method note: For beginners, teach vocabulary top-down (from sentences, not isolated words). Introduce vocab within context/dialogue, not separately.

#### 三、語法教學 (Grammar Teaching)
- For each grammar point:
  - State the meaning and key point
  - Show the structure formula: S + V + Object
  - Provide 2-3 example sentences
  - List common student errors with incorrect examples
  - Note: only teach THIS lesson's usage, don't extend

#### 四、課文教學 (Text/Dialogue Teaching)
- List the lesson's key sentences (重點句子)
- Suggested teaching flow (建議流程):
  1. Teacher models the dialogue (with props/images)
  2. Lead reading — students repeat together
  3. Segment teaching: break dialogue into parts, teach vocab+grammar per segment
  4. Spiral up: incorporate earlier segments into later ones
  5. Teacher asks comprehension questions about the text
  6. Students practice in pairs/groups
- Provide specific comprehension questions (提問範例)

#### 五、綜合活動 (Integrated Activities)
- 朗讀及認讀課文: Read aloud for fluency and character recognition
- 完成課文句子: Fill in sentences to consolidate grammar + practice writing
- 溝通任務活動: Real-world communication tasks (listening + speaking)

#### 六、課文補充教學 (Supplementary Text)
- 1-2 supplementary dialogues/passages using the same vocab and grammar
- Can be used as listening material or reading material

### 參、課本練習答案 (Textbook Exercise Answers)
- Full answer key for all exercises
- Include listening exercise transcripts

### 肆、作業本答案 (Workbook Answers)
- Answer key for homework exercises

### 伍、習寫漢字 (Character Writing)
- List characters to practice writing
- Note stroke order resources

## Key principles from the reference

1. **Segmented teaching (分段教學)**: Don't teach the whole dialogue at once. Break it into segments, each introducing specific vocab + grammar. Students practice each segment before moving to the next. Spiral upward.

2. **Top-down vocabulary**: For beginners, don't teach words in isolation. Introduce them within sentences and dialogue context.

3. **Common errors**: Always list what students typically get wrong. This is the most valuable part for new teachers.

4. **Scope control**: Only teach the meaning/usage relevant to THIS lesson. Don't extend to other meanings even if the word has them.

5. **Phrases as units (短語)**: Fixed expressions like 你好, 貴姓 should be taught as whole units, not broken into individual characters.

6. **Comprehension questions**: After teaching the text, ask specific questions that require students to use the target structures.

7. **Practice before production**: Students hear → repeat → practice in controlled context → produce freely.

## Adaptation for our system

Our system targets Vietnamese university students learning Chinese. Adaptations:
- All instructions and explanations in Vietnamese
- Vietnamese translations for all Chinese content
- Cultural comparisons are Vietnam-China (not Taiwan-focused)
- Pinyin is handled by separate pinyin lessons — regular lessons skip phonetics teaching
- Game platform is Blooket (not physical cards unless necessary)
- Section "Bài đọc" (not "Bài khóa") for the text/dialogue section
