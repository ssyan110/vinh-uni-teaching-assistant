# Skills index

For teaching slides, select the [online PPTX or native classroom OpenSlide route](steering/agent-routing.md) before a visual skill. Use [teaching-material preparation](skills/ai-teaching-material-systems/SKILL.md); classic HTML references do not set current output defaults.


Read [AGENTS.md](../AGENTS.md) first. Select only the task-relevant skill from `skills/`; historical references are optional context.

For video editing, repurposing, or full production, read [the video editing workflow](../docs/workflow/video-editing-workflow.md) and use the matching project-local skill:

- Short classroom Chinese dialogue: [chinese-conversation-short-video](skills/chinese-conversation-short-video/SKILL.md)
- Extended or multi-scene classroom Chinese dialogue: [chinese-conversation-long-video](skills/chinese-conversation-long-video/SKILL.md)
- Code-built film in a Lemo-Opuscar style or a custom visual style: [lemo-opuscar](skills/lemo-opuscar/SKILL.md)
- Branded social video: use the governing brand workflow and add a classroom-video skill only when the content is a course dialogue.

Idea-only or script-only requests do not need an editing skill. For video references and limits, see [video-reference-research](skills/video-reference-research/analysis.md).
