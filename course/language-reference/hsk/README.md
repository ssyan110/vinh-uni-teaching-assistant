# 跨教材 HSK 詞彙與語法參考庫

狀態：2026-09-21 建立；供榮市大學華語教材製作與課程規劃跨年級共用。這是難度與來源查找工具，不是任何一班的學習成績表，也不是官方 HSK 資料庫。

## 使用邊界

- 本庫供本專案所有教材、年級、學期使用。當前大一 W02 的 HSK 1—3 目標只是該次課程的限制，不會限制或取代其他年級的課程範圍。
- 每次審閱學生文案，先記錄該班的 HSK 版本和最高級別。舊版 HSK 2.0、GF0025-2021 與 2025 新版 HSK 3.0 必須分開查；「HSK 3」沒有版本標記時不是充分的範圍描述。
- 詞表中找到某個詞，或語法表把某個項目列在較低級，**都不代表這班已經學過**。正式教學範圍仍要看該班使用教材的 canonical 詞彙／語法資料、已批准課程規劃、已完成課次，以及教師對本班實際進度的確認。把「教材出現」「正式教過」「課堂練過／複習過」「未教」「未知」分開記錄。
- 語言檢查要涵蓋整句和實際任務用語：詞語、固定搭配、句式、助詞、補語、連接詞、問答和學生操作句。HSK 標籤不能代替自然口語審讀或「學生能不能立刻照著做」的理解檢查。
- 沒在詞表找到只表示「這個來源裡未核實」，不自動等於高級。優先用學生已學且自然的簡單說法；必要的專有名詞或課本詞要另標用途和理解支架。使用者明確指出尚未教的語法，優先於 HSK 標籤；例如本次 W02 文案不使用學生尚未學過的「把」字結構。

`level_profiles.csv` 的 2021 標準數量是該標準各級累計指標；2025 語法欄的 `grammar_rows_in_local_database` 是所引第三方檔案的摘錄列數，**不是官方宣告的總量**。2015 年各級考試大綱包含語言點大綱，但本庫尚未建立一份逐級、授權狀態可核且完整的 HSK 2.0 語法表；請使用對應版本原大綱及本班教材核對，不以 HSK 3.0 語法表代替舊版。

## 檔案與欄位

- `vocabulary.csv`：7,224 條來源詞目，包含舊 HSK 2.0 第 1—6 級與新版 HSK 3.0 第 1—6 級詞彙，以及只見於舊版、供跨版本核對的詞。`hsk2_2015_level` 與 `hsk3_2025_band` 是兩個獨立欄位；空白代表該來源未列出。相同漢字可能因讀音、詞性或詞義不同而有多行；必須按句中實際讀音與用法查行，不能只拿同形字中最低或最高的級別代表所有用法。新版第 7—9 級在來源中合併為 `7`，只在同一詞也有舊版 1—6 級資料時保留作跨版本提醒，不能解讀成精確的新第 7、8、9 級。
- `grammar.csv`：459 條新版 2025 考試大綱第 1—6 級的第三方結構化語法記錄；保留原分類和順序欄位，不包含例句。條目文字可能有轉錄或標點問題；正式採用前查原始大綱。語法列級只是標準歸類，不是本班已學記錄。
- `level_profiles.csv`：三種標準第 1—6 級詞彙累計數，以及 GF0025-2021 的語法累計數；各數字附有統計依據。
- `source-manifest.json`：來源版本、授權聲明、原始資料雜湊、匯入欄位、本地列數和本地檔案 SHA-256。

## 供下一次文案審閱的最短流程

1. 在內部審閱稿寫下班級、教材、目標 HSK 版本和最高級別；版本未知時，不把不同名單拼成一套。
2. 對學生看得到的內容逐頁核詞彙與語法；同形異音或多義詞按本句讀音、詞性與用法核對。將高於目標、版本不一致、未出現在參考名單、以及可能沒教過的項目分開標記。
3. 用該教材自己的來源／語法表和已完成課次查「是否教過」；不能只看本 HSK 庫。若學生尚未學某種句式，從操作說明中換掉它；不要把待教的新語法藏進指令。
4. 用熟悉、自然、短而完整的口語重寫；明確說出學生要做什麼、對誰做、用什麼材料、最後說出或記下什麼。
5. 保留逐頁審閱稿供教師確認。這些資料庫檢索與自動檢查不能替教師批准文案，也不能代替上課效果驗證。
