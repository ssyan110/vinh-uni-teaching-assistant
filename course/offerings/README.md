# 开课实例

每个学期或独立开课实例使用一个目录，例如 `2026-fall/` 或 `2027-fall/`。开课实例只记录该学期采用哪些教材、教材顺序、状态与课程层级文件，不保存教材 PDF、QR、音频或逐课制作文件。

同一开课实例可以在 `offering.json` 的 `textbooks` 数组中登记多本教材。2026 秋季使用《准中级加速篇 I》；2027 秋季直接登记《中级冲刺篇 I》。正式学期时数与顺序必须在完整理解教材后定稿，不从教材数量自动推算；来源尚未批准前只能登记规划草案。排课时先计算每课的实体课节数，线上自学由学生自行安排，属于不设固定分钟数的课外 self-paced study，另列且不折抵实体课。
