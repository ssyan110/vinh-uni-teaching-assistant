# 第9–25課學生任務包

課堂使用說明：老師按標題分別裁切或複製當課片段；不把整課所有讀本和隱藏資訊完整發到公共群。聽力逐字稿與教師答案不在本冊。對讀時A、B分別拿自己的文字；角色卡分別發，不把所有隱藏資料同時投在屏幕上。

這些是配合《博雅漢語聽說·初級起步篇 I》的教師原創材料，不是教材原文，也不是真實訪談、現實商店價格或學校規定。

| 路徑 | 你要做什麼 |
|---|---|
| 核心 | 聽懂本課資訊，完成交流；需要時用句框 |
| 延伸 | 已掌握的重複練習可以免做；閱讀新資訊，解釋、追問、回應 |
| 更高挑戰／閱讀 | 延伸仍無挑戰時，與老師選一個更適合的目標或材料；不是加做同樣的題 |

## 共同操作

兩人先各自理解；三人交流時每個人都輪到發言、追問與核證。聽的人先說自己聽懂什麼，再問真正不清楚的地方。回饋後再說一次，不要只背原稿。

## 第9課｜我們怎麼去

### 核心任務

兩人電話核對：A知道“週六09:30、東門、坐地鐵”；B拿到錯誤記錄“周日09:30、南門、騎車”。B先逐項詢問，A糾正；最後B不看紙複述。第二輪換角色，用“周日14:15、西門、坐公共汽車”與“兩點半、西門、地鐵”。不要使用學生真實電話。

**需要幫助時：**我們……點在……見。／你坐……去嗎？／不是……，是……。

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 說話人什麼時候、在哪個門見小林？ |
| 2 | 他怎麼去？現在有什麼聯繫方式？ |
| 3 | 老師的辦公室號碼已經確定了嗎？ |

### 延伸：A讀本（只給A）

【學生服務員的留言】新同學第一次來學校，最需要的可能不是最短路線，而是容易認出來的集合點。上次我只說“在學校門口見”，對方卻到了南門，我一直在東門等。後來我把“東門、圖書館旁邊、九點半”寫清楚，他很快就找到了。不過我不願意把老師的私人手機號碼直接發給不認識的人，最好先徵得老師同意，或者提供辦公室的公開聯繫方式。

### 延伸：B讀本（只給B）

【新同學的回信】我並不是完全看不懂地圖，而是不確定地圖上的入口是不是可以進去。我更想知道：從哪個出口出來以後，能看見什麼明顯的建築？路上需要多久？如果遲到，應該通知誰？別人一下子給我三個號碼，我反而不知道先聯繫哪一個。我希望先收到一條簡短明確的消息，有必要時再問細節。

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：接待者 | 你要給新同學說明來校方式。你只有老師的私人號碼，不知道老師是否同意轉發；可以幫忙聯繫，但不能假裝已獲同意。 |
| B：來訪者 | 你已到南門，正式入口是否開放不清楚。你不願意盲目繞校一圈；要求對方用地標說明，並確認在哪裡等。 |
| C：資訊審核者 | 你看到活動通知寫“東門09:30”。你必須指出一句仍然可能誤解的話，問清後向另一組轉述；不是只旁觀。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 兩段材料認為“清楚的說明”分別需要什麼？ |
| 2 | 哪些資訊已經知道，哪些必須詢問或獲得同意？ |
| 3 | 把接待者的說明縮成45秒，再回答來訪者兩個未預告的問題。 |

**交流前可選的表達：**為了避免誤會……；我確認一下，你說的是……嗎？；目前能確定的是……；關於……，還需要先問一下。。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**先用90秒向學校工作人員解釋資訊失誤，再用30秒向新同學給出可執行說明。保留事實、刪除推測；聽者指出是否遺漏入口或聯絡責任。提高的是受眾適配與資訊精確度，不是增加路線數量。

**完成後：**備用8分鐘：同一到校說明先給熟悉校園的同學，再給第一次來的人。聽者畫出自己理解的集合點，檢查兩種說法需要保留哪些不同細節。


## 第10課｜西瓜怎麼賣

### 核心任務

顧客持需求卡“2斤蘋果＋3瓶水”，店員持價簽“蘋果6元／斤、水2元／瓶、牛奶5元／瓶”。顧客詢價、確認，再口頭改一項。輪換時變成“1斤蘋果＋2瓶牛奶”，店員必須複述訂單，不能只報總價。所有價格為模擬，斤在本任務統一按500克使用。

**需要幫助時：**……多少錢？／我要……。／再加……。／一共……，對嗎？

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 最初的訂單是什麼？一共多少錢？ |
| 2 | 最後改了什麼？最終總價是多少？ |
| 3 | 說話人用什麼付款？ |

### 延伸：A讀本（只給A）

【買家甲的評論】這家店寫著“滿二十元免送貨費”。我本來只要十二元的水果，為了免運費，又加了九元不需要的飲料。下單時覺得自己省了錢，收到後卻發現飲料一直沒喝。對我來說，真正要比較的是“買完一共花多少錢”和“這些東西會不會用到”，不是只看省了多少運費。

### 延伸：B讀本（只給B）

【買家乙的評論】我和室友合併訂單後，剛好超過二十元，兩個人都買到了原來就需要的東西，所以免運費確實有幫助。但我們沒有比較附近另一家店的價格，也沒有記錄水果重量，不能據此說這家店一定最便宜。評論里的“很划算”只代表這次購買經驗，不等於所有人都適合。

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：買家 | 你的必需品合計12元，送貨費5元；可以自取。你只接受有理由的推薦，不會為了湊單買不需要的飲料。 |
| B：店員 | 同一店滿20元免送貨費；所有條件要說清楚。你知道室友需要9元商品，但不能替室友承諾購買。 |
| C：室友兼核賬者 | 你確實需要9元商品，今天也可以去店裡自取。先問清付款與取貨安排，再提出是否合單；每個人的支出要能說明。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 甲和乙的經歷衝突嗎？為什麼？ |
| 2 | 僅憑兩條評論，能不能斷言這家店最便宜？ |
| 3 | 提出一個推薦，說明它成立的條件，再回應“免運費一定更省”的觀點。 |

**交流前可選的表達：**表面上……，實際上……；關鍵不在於……，而在於……；這個結論只適用於……；如果原來就需要……，那麼……。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**做一段120秒消費建議：先準確呈現支持與反對觀點，再限定結論適用範圍。另一組提出一個反例，發言者必須修改或捍衛自己的條件，而不是重複“便宜就好”。

**完成後：**備用10分鐘：把一句“這家最好、最便宜”改成有依據但不過度承諾的推薦；同伴判斷哪些詞變得更準確。


## 第11課｜明天天氣怎麼樣

### 核心任務

兩人各聽不同天氣資訊（無獨立設備時由老師分組朗讀，或改用不同閱讀卡並明確這是閱讀）。A週六上午晴24度，B下午可能下雨28度。先互相問清，再各向另一個同學給一條建議，聽者說出建議依據。

**需要幫助時：**上午……，下午……。／我喜歡……。／現在還不知道……。

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 上午與下午有什麼不同？ |
| 2 | 大家已經決定什麼時候去了嗎？ |
| 3 | 哪一句屬於個人喜好或建議，而不是天氣資訊？ |

### 延伸：A讀本（只給A）

【活動負責人】我們昨天安排了週六下午的戶外活動。今天看到預報說“下午可能有雨”，有人立刻要求取消，也有人認為“可能”就是可以忽略。我認為這兩種說法都太快。我們需要先確定什麼時間作最後決定，以及如何通知參加者。天氣資料只能提供部分依據，參加者是否願意接受下雨的可能，也會影響選擇。

### 延伸：B讀本（只給B）

【參加者】我已經空出了下午，所以希望不要隨便取消。不過，我不反對準備一個室內方案。我最在意的是通知是否清楚：現在是確定改地點，還是只在考慮？“應該照常”讓我不知道要不要出門。請負責人把已決定的事項與尚未確定的事項分開說明，不要把個人樂觀當成天氣預報。

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：負責人 | 活動14:00開始。你可以在12:00統一通知，但現在沒有最終決定。不能把備選方案說成已確定。 |
| B：參加者 | 你13:00需要出門。你要求出門前明確通知；能接受室內方案，但要問清地點是否已確認。 |
| C：消息核證者 | 最新消息只寫“下午可能有雨”；室內教室是否可用尚未確認。你必須區分事實、預測、意見，再轉述給兩人。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 將句子分成“資料／預測”“個人意見”“已作決定”。 |
| 2 | 哪些詞容易讓聽者誤以為事情已經確定？ |
| 3 | 寫下三行提示，口頭髮布一則45秒更新，聽者檢查有無把可能說成一定。 |

**交流前可選的表達：**根據目前的資訊……；這不表示……一定……；我們暫時保留……；最晚在……之前確認。。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**將同一更新分別改成給同學的語音和給學校負責人的口頭彙報；指出自己哪些判斷超出了資料，不討論真實災害處置。

**完成後：**備用8分鐘：對四條模擬預報標題判斷哪條表達過度確定，改寫其中兩條。


## 第12課｜我正在等公共汽車呢

### 核心任務

現在／平時雙面卡：每人選一個角色，回答“現在在做什麼”和“每天做什麼”，聽者在兩欄記錄關鍵詞。第二輪加入“從週一到週五／從下星期開始”資訊，聽者須核實是日期範圍還是每天的動作。

**需要幫助時：**他正在……。／他每天都……。／從……到……。

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 三個人現在分別在做什麼？ |
| 2 | 哪件事是平時的習慣，不只發生在今天？ |
| 3 | 小王已經確定遲到了嗎？ |

### 延伸：A讀本（只給A）

【12:20項目群消息】我正在檢查照片，還沒有發給老師。小林負責選擇三張照片，他說午飯後再看。我們每天都在群裡報告一次，但今天的報告不代表所有事情已經完成。請不要只回覆“好了”，最好說明完成了哪一步，還有哪一步需要別人配合。

### 延伸：B讀本（只給B）

【12:35轉述記錄】有人把群消息轉告老師：“照片已經選好，也發過去了。”負責同學聽到後很著急。他只是說正在檢查，沒說已經交出；小林也只是計畫午飯後看。一次轉述把正在進行、將來打算和已經完成混在了一起，其他人因此以為不必再做什麼。

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：原發言者 | 你正在檢查照片；尚未發送；需小林選3張。你要糾正轉述，但不把對方說成故意騙人。 |
| B：轉述者 | 你確實把“正在檢查”說成“已經發了”。先複述你現在理解的事實，再修正消息。 |
| C：接收者 | 你必須問清是誰負責什麼、現在在哪一步。聽完修改版後，獨立報告當前狀態，不能看A原卡。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 轉述改變了哪兩項意思？ |
| 2 | 找出原文的進行中、日常習慣、未來打算。 |
| 3 | 用30–45秒給未讀消息的同學說明狀態，並回答“所以現在都做好了嗎”。 |

**交流前可選的表達：**現在正在……，還沒有……；他原來的意思是……；每天……不等於今天已經……；我剛才轉述得不準確，應該是……。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**不得直接複述原句；在45秒內傳達三種時間狀態，聽者刻意提出一個錯誤推斷。發言者用澄清而非完整重講糾正。

**完成後：**備用10分鐘：三人傳遞一條含“現在／每天／下星期”的消息，最後與原文比對誤差；不得變成故意傳錯的遊戲。


## 第13課｜你打算買什麼樣子的

### 核心任務

需求訪談：買家不能先看商品，只告訴店員“要放什麼、喜歡什麼顏色、多少錢以內”。店員有A藍80元小、B黑90元大、C紅70元大的資料，先追問兩項需要再推薦。品質資料沒有提供，須說不知道或提出核實，不能憑價格猜。

**需要幫助時：**我想買……的。／這個有點兒……。／有沒有……一點兒的？

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 買家可以接受哪些顏色？ |
| 2 | 為什麼沒有立即買藍色的？ |
| 3 | 他已經買了黑色的嗎？ |

### 延伸：A讀本（只給A）

【商品頁面】輕便學生書包，適合上課、旅行與日常外出。頁面強調“容量充足、做工精細”，照片里放了電腦、書和水杯，但沒有說明電腦尺寸，也沒有展示裝滿以後背在身上的樣子。店員表示很多學生買，卻沒有提供這些學生的實際使用回饋。

### 延伸：B讀本（只給B）

【使用者的評論】我買來裝兩本書很方便，拉鍊也順。但把電腦、水杯和外套都放進去以後，空間就不太夠了。我不能說廣告完全不真實，因為我的使用需求可能和別人不同。對我而言，“適合學生”太寬泛，更有用的問題是：它是否適合我每天帶的東西？

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：買家 | 你每天帶電腦、3本書和水杯；可接受黑或藍；預算100元。你要的是能用，不是只要好看。 |
| B：店員 | 你有兩款樣品，可讓顧客試裝，但不知道電腦尺寸。不能僅憑“很多人買”作保證。 |
| C：評論審核者 | 你指出評論只報告一位用戶的情況；必須問一個能改變推薦的問題，並評價店員是否把未知說成保證。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 廣告里的哪兩個評價還缺少具體說明？ |
| 2 | 評論否定了整個商品嗎？ |
| 3 | 做一次需求訪談；先問再推薦，推薦中說出一個仍需試用的地方。 |

**交流前可選的表達：**就你的使用情況來說……；與其只看……，不如先確認……；這條評論說明……，但不能證明……；我想找……一點兒的。。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**把廣告改成60秒負責任的銷售說明，既有吸引力又不作材料不支持的承諾；同伴提出“你怎麼知道”的追問。

**完成後：**備用8分鐘：把“好看／好用／品質好”分別換成可觀察的描述；沒有證據的地方明確保留。


## 第14課｜祝你生日快樂

### 核心任務

三人生日電台：A提議先吃飯再送禮物，B問清壽星喜好，C把建議順序轉述給壽星。每人須提出或回應一個建議；第2輪不增加人數，改為壽星更想安靜聊天，重新解釋活動是否合適。

## 第19課｜你又熬夜了

### 核心任務

先拼時間線，再完成道歉：一人說約定與等候，另一人說明原因並提出下次做法；第二輪對方改變等待經歷而不是只換名字。至少核對“多久”與“幾點”的差別。

**需要幫助時：**我們約……點，我等了……分鐘。／今天又……。／下次我會……。

### 聽力檢查（先聽老師，不看逐字稿）

| 題 | 問題 |
| --- | --- |
| 1 | 原來幾點見？實際幾點到？等多久？ |
| 2 | 哪一個重複行為已經發生？ |
| 3 | 哪一件重複行為是將來的打算？ |

### 延伸：A讀本（只給A）

【遲到者】我知道遲到讓朋友不舒服，所以一見面就解釋自己為什麼沒看見消息。可是我說了很多原因，朋友還是生氣。回家後我發現，我一直在說明“不是故意的”，卻沒有回應他實際等了半小時、又不知道我要不要來的困擾。解釋原因和承擔這次影響，並不是只能選一個。

### 延伸：B讀本（只給B）

【等候者】我可以理解偶爾有意外，但我最不滿的是沒有消息。我並不需要對方保證以後永遠不會遲到，而是希望可能晚到時早點通知。聽到“你等一下又不會怎樣”，我覺得自己的時間不被重視；聽到“這次讓你等了很久，下次我先告訴你”，我更願意繼續談。

### 交流角色（分開發）

| 角色 | 你知道什麼、需要做什麼 |
| --- | --- |
| A：遲到者 | 你晚到30分鐘，確實沒發消息。說明原因，但不能說“你不應該生氣”。 |
| B：等候者 | 你願意聽原因，但要讓對方知道影響；你希望有提前通知，而不是不可能兌現的保證。 |
| C：調解者 | 分別複述雙方最在意的一點，再讓他們提出一個下次可執行的做法；不能判斷真實同學誰有錯。 |

| 步驟 | 任務 |
| --- | --- |
| 1 | 兩段敘述是事實衝突，還是關注點不同？ |

| 3 | 進行三分鐘進度會，再讓另一組只憑交接語音列出下一步。 |

**交流前可選的表達：**已經……，但還沒有……；目前完成到……這一步。；下一步由……在……之前……；確認……以後，才算……。只選自己需要的，不必全部塞進對話。

**回饋：**聽者說一件聽懂的事，再問一件不清楚的事。說話者改進後，對新聽者再說一次。

**更高挑戰：**給新負責人做90秒交接，只說關鍵依賴關係、風險與驗證方式。另一組提出“你怎麼確認已完成”，回答須有可觀察證據，不只“他跟我說好了”。

**完成後：**備用10分鐘：把五句“好了”改成不同結果狀態；聽者判斷還有沒有必要追問。
