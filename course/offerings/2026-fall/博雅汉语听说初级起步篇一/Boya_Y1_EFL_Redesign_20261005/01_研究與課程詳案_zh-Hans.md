# 大一第9–25课：EFL取向的混合程度听说课程详案

> 适用：2026年秋季大一第一学期《博雅汉语听说·初级起步篇 I》。
> 课程ID：BOYA-LS-E1-Y1S1-2026F｜研究与设计日期：2026-10-05｜状态：教师审核后试行。
> 本文件为独立的课程调整案，不覆盖原课程规范、旧PPT或二年级材料。

## 先执行的三个决定

| 决定 | 具体执行 |
|---|---|
| 保留主教材，改变重复练习要求 | 《博雅》负责本课语言与听力覆盖；对已证明会的目标，重复题可以免做，改用新材料与新交际目标。 |
| 不再把“挑战”全做成复杂排时间 | 本案轮换信息澄清、对读、评论判断、叙事、观点交换、建议诊所、语用角色扮演、反馈与交接。 |
| 以实际学生行为估时 | 每周准备200分钟计划＋约30分钟可替换储备；记录每环节实际结束时间。储备不是额外必做作业，不要求230分钟塞进200分钟。 |

### 今天第7、8课为什么会剩下近一节

教师报告的是“全套内容结束后仍剩将近一节”，不是每个学生都已经掌握的证据。本案据此修正上一版的活动量与估时，但没有现场录影或逐环节时间，不能断言问题来自某一个教学行为。

| 需要检查的现象 | 对应调整 |
|---|---|
| 任务很快找到唯一答案，随后无事可做 | 不延长同一道题的倒数时间；加入有新学习目标的语言分析、听者追问或独立阅读。 |
| 都是选时间、选地点、临时改约 | 第7、8课另配完整50分钟“邀请信息诊所”，练意图、澄清、拒绝与精确表达。 |
| 高程度者没有接触到新表达 | 替代输入不是教材原句换几个数字；从每课延伸材料选2项自己尚不稳定的表达或组织方式作为目标。 |
| 小组已交答案，但个别人没真正说 | 三人轮换角色，听者须复述／追问；保留个人独立退出证据。 |
| 全班都熟练，却为照顾少数不停重听 | 达标者转入延伸；老师给需要者小组补听，不要求全班等待。 |

**不因一次提前结束就擅自加快全学期进度。** 先检查基础学生是否独立听懂、是否能无稿回应，再决定压缩哪些目标。[S1–S3]

## 一、采用什么EFL方法，而不是笼统地“做更多游戏”

| 方法 | 本班采用的结构 | 与上版不同之处 | 证据性质 |
|---|---|---|---|
| Test–Teach–Test | 先作短任务，按实际错误短教，再作相近任务 | 不先把已会的所有词句重讲一遍 | British Council实践框架[R1] |
| Curriculum compacting | 针对某个目标确认已会→免重复→替代学习 | 不是做完15道简单题才获准学习新内容 | UConn框架；原场景不同[R3] |
| 技能型听力课 | 听前明确目的→首听大意→再听必要细节→使用信息 | 不把“对答案”当成完整听力学习 | British Council听力框架[R4] |
| Jigsaw＋信息中介 | 每人读／听不同信息，再转述、追问、整合 | 不把完整资料全投影，让学生默读后抄答案 | British Council活动框架[R6] |
| Functional language | 明确邀请、拒绝、建议、澄清的目的与语境 | 高程度者学习得体与精确，不只是复杂句数量 | British Council功能教学[R8] |
| 重复口说＋反馈 | 第一次→一项具体反馈→同内容换听者再说→另题迁移 | 既允许有目的的重复，也防止机械背稿 | 小规模ESL／越南EFL研究[R9–R11] |
| 自主泛读 | 自选能顺畅理解的材料，连续读15分钟，轻量记录 | 阅读可以是正当替代活动，不必每次交长摘要 | 实践框架[R12] |

“西方EFL”在本案指优先借鉴英语作为外语／第二语言教学资源中的这些方法，不表示西方课堂只有一种教法，也不表示它们天然优于其他方法。课堂目标语仍是中文，角色与材料重新写为大学生日常情境。

### 对研究结论的实际使用

[R9–R11]让本案保留“反馈后再说”，但**不把时间压力当作万能加难方式**。基础学生可用等时30–45秒重述；扩展组先90秒—反馈—90秒，再视情况60秒。这里的短版时长是教师适配，不是这些实验已经验证的华语方案。

## 二、教材选择：先用已有材料，不急着买新书

| 优先级 | 材料 | 推荐用途 | 不这样使用 |
|---|---|---|---|
| 1 | 《博雅》本课教材＋配套听力文本 | 核心词句、主旨与关键细节、个人基础能力证据 | 不要求所有人机械做完所有题；不遗漏后半册语言范围 |
| 2 | 本包每课原创短听力＋A/B对读＋角色卡 | 立即可用的新输入；有教师答案与输出标准 | 不冒充教材原文、真实访谈或实证资料 |
| 3 | 已有《当代中文课程2》精选段落 | 第1课路线→本课9／17；第2课交通比较→9，旅行角色→23；第3课学习经历→18／24；第8课邀请功能可候选用于7／8／15 | 只选一段与一个交际目的，不要求学生同时学第二本完整教材。原书场景费用、法律与交通资讯不当作现况 |
| 4 | Mandarin Bean精选文本 | 《周末做什么》作容易输入；《火爆的电商直播》作较高组资料时效与论证选读 | 不只看网站HSK标签；不把分级教学文称为真实生活原文 |
| 5 | Du Chinese Advanced／Master读物目录 | 给已超出本包延伸难度的学生选长期阅读材料 | 本案未逐篇审核全文；先试读，不将付费订阅当上课条件 |
| 教师参考 | British Council免费方法页；*Speaking Extra*借阅候选 | 学活动组织与口说回合设计 | 不是把英文学习单直接翻成中文就算完成适配 |

### 选材料的三步试读／试听

这是本班可调整的工作规则，不是科学统一分数线。

| 第一步 | 第二步 | 第三步 |
|---|---|---|
| 给60–90秒短样本，不提前把全部意思讲完 | 看能否抓大意、举依据、表达或提出真正问题 | 太难则降低输入负担；已完全掌握且无新语言目标则换材料，不加同类题 |

**泛读材料与精读／讨论材料不要混为一谈。** 泛读应读得顺，兴趣优先；对读材料可稍有挑战，但要提供少量关键词支持。[R12] 字数本身不代表语言等级，繁体辨字困难也不等于口说较弱。[S5]

## 三、分流规则：按目标，不按HSK身份

| 路径 | 进入依据 | 做什么 | 老师的责任 |
|---|---|---|---|
| 核心＋支持 | 某项独立听辨或表达尚不稳定 | 核心任务、图片／数字／句框、必要补听 | 短教实际缺口，不把支持变成整节低阶抄写 |
| 延伸E | 已有该目标的独立理解与表达证据 | 新对读、观点分析、较完整互动与针对性反馈 | 给真正的新学习目标，不安排长期教同学 |
| 延伸E＋／阅读合约 | E仍可轻松完成，或该学生需要更长输入 | 本周E＋任务，或约定材料的15–25分钟阅读／听读，再参加适合其水平的交流 | 定期给简短会议与反馈；不能放任整学期无人指导 |

E／E＋是本班路径名称，**不是ACTFL Advanced等级、CEFR等级，也不等于某HSK证书**。

### 6分钟首检怎样实际容纳27人

| 时间 | 学生与教师怎么做 |
|---:|---|
| 0–1分钟 | 老师读当课原创短稿一次，或播放已经确认可用的等值材料。首次不显示逐字稿。 |
| 1–3分钟 | 每人独立答2–3项信息题。答案是数字／关键词，不让读写负担掩盖听力。 |
| 3–5分钟 | 两人同时进行20–30秒回应与一次追问；无提示完成者可留简短录音。老师抽听本节目标学生。 |
| 5–6分钟 | 根据已有证据＋本次信息题暂定路径；未核实口说者标“待核实”，在任务时补听。 |

不能在6分钟内由老师逐一听完27人，也不能只凭同伴打勾宣布全部认证。前三节各集中观察7人，第四节观察剩余6–7人；关键困难者优先。单次成功只支持**当前目标的暂时免练**，后续还要检查稳定性。[S5]

### 哪些练习可以免

只免已经有证据的项目，例如某组的时间听辨、已会的句型替换、重复抄写。另一项不稳定的听力、语用或新结构仍需学习。**不使用“总分4／5，所以整课都免”**；听懂但说不清、说得多但听错信息，应分别处理。[R3]

课堂规则可直接说：

> “已经会的内容，可以不重复练。但是你需要让我看见你会。省下来的时间做延伸或约定的阅读。需要帮助时随时回来问；不是按HSK把人固定分组。”

## 四、每周200分钟的实际课型

正常双课周：P课型两节＋D深度课一节＋T改进迁移课一节。W07为第15课两节＋100分钟阶段检核。课间休息不算进50分钟。

### P：单课输入与互动，50分钟

| 时间 | 核心＋支持 | 延伸E／E＋ | 教师位置与产出 |
|---|---|---|---|
| 0–6 | 独立首检＋双人短回应 | 同样证明本课必要目标，不重复长操练 | 全班说明；暂定路径，不冒称逐一认证 |
| 6–18 | 原书选定短段：先大意，再按需要补听细节，短教必要词句 | 当课A/B分别读；交换主旨与依据，不给对方看整段；太容易者进E＋或阅读合约 | 先核心约7分钟，再扩展约5分钟；非教师组有明确读／听者任务 |
| 18–32 | 当课核心双人任务：不同信息核对、轮换；提供可选句框 | 当课三人活动：A、B、C各轮到发言、追问、核证角色 | 抽听6–7名目标学生，记录一个阻碍沟通的问题 |
| 32–40 | 针对真实缺口短练，重说关键一句 | 用同伴证据改语气、组织或准确性，不泛称“再说长一点” | 两路径各约4分钟指导；另一组按反馈表自修 |
| 40–47 | 同任务换搭档或小资料再完成 | 保留同内容，收到反馈后换听者重说；成熟者可自愿压缩 | 检查是否改进；不是全文照读 |
| 47–50 | 独立退出题／短回应 | 同一必要目标＋本人延伸目标记录 | 留证据，决定下一课支持；不当场精批27段录音 |

时间是试行预算，不是强制拖满。当组提前满足结果和交流要求，直接进该课备用或已约定阅读；不因为计划写14分钟就要求继续重复同一答案。

### D：深度输入与跨课交流，50分钟

| 时间 | 全班结构与路径差异 |
|---:|---|
| 0–5 | 说明本周问题与结果，教师示范一次真正的追问。 |
| 5–15 | 核心组取C卡必要信息；E组取得新增C卡＋本周对读／精选材料。老师给核心入门帮助后访问E。 |
| 15–32 | 按本周活动运行：服务展、消息编辑室、观点阶梯、叙事采访等。原则上按当前需要相近者成组，不要求高手照顾别人一整节。 |
| 32–42 | 向另一组解释结果；对方必须提出依据、缺失信息或适用条件的问题。 |
| 42–50 | 个人重述／小组修订后每人说自己的部分；记录一项待改语言。 |

E组若使用泛读合约，可把5–20分钟改成安静阅读，其后用12分钟交换书中一个感兴趣内容，再参加后续共享；不是额外添加15分钟。

### T：反馈、重复与迁移，50分钟

| 时间 | 执行 |
|---:|---|
| 0–6 | 听一个短示范或回顾前次典型问题，确定今天唯一的个人改进点。 |
| 6–18 | 第一轮表达／互动，听者记录实际听懂什么与一个待确认点。 |
| 18–24 | 教师和同伴反馈；不同时纠正十种错误。 |
| 24–34 | 同内容第二轮、换听者，验证是否更清楚。基础者不强迫加速。 |
| 34–45 | 改为新情境／新受众检验迁移；这是与“同内容熟练化”不同的目的。 |
| 45–50 | 个别退出检查、记下改进证据与下次材料。 |

**全班汇合不等于全班做同样简单的任务。** 可共享主题和结果，具体输入、讨论层次、反馈与输出长度不同。

## 五、活动选择菜单：避免17课都长一样

| 活动 | 关键结构 | 适用课 | 不能省略 |
|---|---|---|---|
| 电话澄清／信息审核 | 听记录→找不确定信息→询问→复述最终版 | 9、12、17、21、25 | 已知与推测分开；听者的复述 |
| 两文对读 | 各读一段→互教主旨→比较依据→有限定的结论 | 10、13、14、22、23 | 不共享全文直接抄；不能只说喜欢哪篇 |
| 口头重建 | 首听大意→记关键词→合作重建→对照→独立说 | 12、18、19 | 不要求逐字背稿；标明是dictogloss改编 |
| 观点阶梯 | 独立立场→两人比较→第三人提出反例→修订 | 14、22、23 | 复述反方立场；允许保留不同意见 |
| 语用角色扮演 | 请求／邀请→真实回应→澄清→适当结束 | 7–8、15、17、20 | 不能靠读完整台词；拒绝也是合理结果 |
| 叙事采访 | 一个经历→追问具体细节→第三人转述→核证 | 18、19、24 | 每个人都轮到主述，不能只有组长讲 |
| 同伴反馈诊所 | 先看标准→指出证据→一条改法→再表现 | 24、25及每周T | “很好／再努力”不算具体反馈 |

## 六、运行细节与教材覆盖

| 项目 | 固定执行 |
|---|---|
| 分组人数 | 27人优先9组三人；28人可14对，或8组三人＋1组四人，第四人须有追问与转述责任。不要用整节等待轮流上台。 |
| 角色卡保密 | 分别发A／B／C信息，不能把全套同时投在公屏。无打印可分角色拍照后回到共同任务页。 |
| 个人证据 | 每节一项独立信息答案＋一个可核实口语样本／观察。不是每次都交长作业。 |
| 教材词语 | 原书每个词至少安排有意义接触或理解检查；本案“核心范围”不是完整词表。正式PPT逐页制作时仍须逐项清点，不能只教与活动有关的几个词就算整课完成。 |
| 新表达 | 延伸表达是教师补充，允许从中选2项本人需要的；不要求为了凑数量每句话塞满连接词。 |
| 听力设备 | 本包提供原创朗读稿，不含MP3。没有分组音频设备时，由老师读核心稿、E先阅读；不要把各组同时外放当成可行方案。 |
| 拼音与文字 | 学生材料另有简体版。需要者可看局部拼音和句框；不因为HSK高就禁止查词，也不以繁体识读当隐形门槛。 |
| 评分公平 | 共同基本目标一致，重复练习量可以不同。E替代而非加作业；学习进步与延伸反馈另记，不擅自改变学校成绩比例。 |
| 医疗、隐私与校规 | 20课只练语言，全部病情虚构；不问真实病史。电话、价格、审批和到校规则均为模拟，不构成现实信息或法律意见。 |
| PPT执行 | 这里只交MD教案与任务包，未生成PPT。后续幻灯片保持学生简体、短指令；只标经核实的Audio编号，不插入音频按钮或假链接。 |

### 开始上课前只准备这些

每课按A／B／C标题分别复制或裁切当课学生资料（不含教师听力稿与答案），不要把含全部隐藏信息的整课母稿发给全班；原书标记要选用的1–2段听力；教师保存本课朗读稿、答案与观察名单。每周新增C卡一张。不要让学生先得到整包听力答案，再称之为独立听力检核。

## 七、第9–25课逐课设计

以下17课均为P课型50分钟；第15课另有一节实践。正常双课周另配D与T各50分钟。所有新脚本、对读和角色资料为`original_task`，不是出版社题目。

每对6分钟：两人各1分钟个人说明＋3分钟互动＋1分钟转换／记录。**不可能在同一节给27人每人10分钟口试**。首轮理解错误、回应、澄清与可理解性分别记录；正式成绩使用教师已经确认的量表。

## 十、让高程度学生真正继续学习

### E材料仍太简单时：不用再多做几张E卡

| 表现 | 下一步 |
|---|---|
| 很快看懂文本，但无法准确转述或回应质疑 | 保留文本，针对表达功能反馈；“看得懂”不等于互动已熟练 |
| 理解、精确转述、即兴回应都稳定且无新学习目标 | 直接换到E＋或约定的较长中文材料，不强制做完同类卡 |
| 阅读有很多生词，讨论变成查字典 | 选较易材料或只截取一段；把词汇支持与口说目标分开 |
| 持续两周都远高于所有核心目标 | 与学生约定明确的平行学习目标、材料和教师会议；若学校允许，再讨论分班／课程安置。不是自动放任整堂自习 |

### 自主学习合约（每次15–25分钟，替代而非额外）

| 字段 | 学生与老师填写方式 |
|---|---|
| 材料 | 写确实可访问的书／篇名与本次范围；可从已有教材精选、经试读合适的分级读物或本人已有中文书中选 |
| 本次类型 | 泛读享受内容／精读讨论／听读练习三选一，不混称 |
| 个人目标 | 泛读：顺畅阅读并理解；精读／听读：如区分事实与意见、完成90秒有组织转述 |
| 结束方式 | 泛读只记读到哪里、是否想继续；可偶尔作30秒推荐。精读／听读则按事先目标作短交流，不每次写长摘要 |
| 教师支持 | 每两周至少一次2–3分钟小会议，问材料难度、兴趣与下一步；教师巡视时实际听一段，不只看完成勾号 |
| 回到共同课的时点 | 老师说明的新必要内容、适合其水平的共享环节、个别退出证据；不要求再参加已免除的机械练习 |

从两项本人需要的新表达或一个新话语功能开始，只有真正需要时才增加目标；不能为了证明“高级”强制每次用六个连接词。
