# 第9–25课学生任务包

课堂使用说明：老师按标题分别裁切或复制当课片段；不把整课所有读本和隐藏信息完整发到公共群。听力逐字稿与教师答案不在本册。对读时A、B分别拿自己的文字；角色卡分别发，不把所有隐藏资料同时投在屏幕上。

这些是配合《博雅汉语听说·初级起步篇 I》的教师原创材料，不是教材原文，也不是真实访谈、现实商店价格或学校规定。

| 路径 | 你要做什么 |
|---|---|
| 核心 | 听懂本课信息，完成交流；需要时用句框 |
| 延伸 | 已掌握的重复练习可以免做；阅读新信息，解释、追问、回应 |
| 更高挑战／阅读 | 延伸仍无挑战时，与老师选一个更适合的目标或材料；不是加做同样的题 |

## 共同操作

两人先各自理解；三人交流时每个人都轮到发言、追问与核证。听的人先说自己听懂什么，再问真正不清楚的地方。反馈后再说一次，不要只背原稿。

## 第9课｜我们怎么去

### 核心任务

两人电话核对：A知道“周六09:30、东门、坐地铁”；B拿到错误记录“周日09:30、南门、骑车”。B先逐项询问，A纠正；最后B不看纸复述。第二轮换角色，用“周日14:15、西门、坐公共汽车”与“两点半、西门、地铁”。不要使用学生真实电话。

**需要帮助时：**我们……点在……见。／你坐……去吗？／不是……，是……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 说话人什么时候、在哪个门见小林？ |
| 2 | 他怎么去？现在有什么联系方式？ |
| 3 | 老师的办公室号码已经确定了吗？ |

### 延伸：A读本（只给A）

【学生服务员的留言】新同学第一次来学校，最需要的可能不是最短路线，而是容易认出来的集合点。上次我只说“在学校门口见”，对方却到了南门，我一直在东门等。后来我把“东门、图书馆旁边、九点半”写清楚，他很快就找到了。不过我不愿意把老师的私人手机号码直接发给不认识的人，最好先征得老师同意，或者提供办公室的公开联系方式。

### 延伸：B读本（只给B）

【新同学的回信】我并不是完全看不懂地图，而是不确定地图上的入口是不是可以进去。我更想知道：从哪个出口出来以后，能看见什么明显的建筑？路上需要多久？如果迟到，应该通知谁？别人一下子给我三个号码，我反而不知道先联系哪一个。我希望先收到一条简短明确的消息，有必要时再问细节。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：接待者 | 你要给新同学说明来校方式。你只有老师的私人号码，不知道老师是否同意转发；可以帮忙联系，但不能假装已获同意。 |
| B：来访者 | 你已到南门，正式入口是否开放不清楚。你不愿意盲目绕校一圈；要求对方用地标说明，并确认在哪里等。 |
| C：信息审核者 | 你看到活动通知写“东门09:30”。你必须指出一句仍然可能误解的话，问清后向另一组转述；不是只旁观。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 两段材料认为“清楚的说明”分别需要什么？ |
| 2 | 哪些信息已经知道，哪些必须询问或获得同意？ |
| 3 | 把接待者的说明缩成45秒，再回答来访者两个未预告的问题。 |

**交流前可选的表达：**为了避免误会……；我确认一下，你说的是……吗？；目前能确定的是……；关于……，还需要先问一下。。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**先用90秒向学校工作人员解释信息失误，再用30秒向新同学给出可执行说明。保留事实、删除推测；听者指出是否遗漏入口或联络责任。提高的是受众适配与信息精确度，不是增加路线数量。

**完成后：**备用8分钟：同一到校说明先给熟悉校园的同学，再给第一次来的人。听者画出自己理解的集合点，检查两种说法需要保留哪些不同细节。


## 第10课｜西瓜怎么卖

### 核心任务

顾客持需求卡“2斤苹果＋3瓶水”，店员持价签“苹果6元／斤、水2元／瓶、牛奶5元／瓶”。顾客询价、确认，再口头改一项。轮换时变成“1斤苹果＋2瓶牛奶”，店员必须复述订单，不能只报总价。所有价格为模拟，斤在本任务统一按500克使用。

**需要帮助时：**……多少钱？／我要……。／再加……。／一共……，对吗？

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 最初的订单是什么？一共多少钱？ |
| 2 | 最后改了什么？最终总价是多少？ |
| 3 | 说话人用什么付款？ |

### 延伸：A读本（只给A）

【买家甲的评论】这家店写着“满二十元免送货费”。我本来只要十二元的水果，为了免运费，又加了九元不需要的饮料。下单时觉得自己省了钱，收到后却发现饮料一直没喝。对我来说，真正要比较的是“买完一共花多少钱”和“这些东西会不会用到”，不是只看省了多少运费。

### 延伸：B读本（只给B）

【买家乙的评论】我和室友合并订单后，刚好超过二十元，两个人都买到了原来就需要的东西，所以免运费确实有帮助。但我们没有比较附近另一家店的价格，也没有记录水果重量，不能据此说这家店一定最便宜。评论里的“很划算”只代表这次购买经验，不等于所有人都适合。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：买家 | 你的必需品合计12元，送货费5元；可以自取。你只接受有理由的推荐，不会为了凑单买不需要的饮料。 |
| B：店员 | 同一店满20元免送货费；所有条件要说清楚。你知道室友需要9元商品，但不能替室友承诺购买。 |
| C：室友兼核账者 | 你确实需要9元商品，今天也可以去店里自取。先问清付款与取货安排，再提出是否合单；每个人的支出要能说明。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 甲和乙的经历冲突吗？为什么？ |
| 2 | 仅凭两条评论，能不能断言这家店最便宜？ |
| 3 | 提出一个推荐，说明它成立的条件，再回应“免运费一定更省”的观点。 |

**交流前可选的表达：**表面上……，实际上……；关键不在于……，而在于……；这个结论只适用于……；如果原来就需要……，那么……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**做一段120秒消费建议：先准确呈现支持与反对观点，再限定结论适用范围。另一组提出一个反例，发言者必须修改或捍卫自己的条件，而不是重复“便宜就好”。

**完成后：**备用10分钟：把一句“这家最好、最便宜”改成有依据但不过度承诺的推荐；同伴判断哪些词变得更准确。


## 第11课｜明天天气怎么样

### 核心任务

两人各听不同天气信息（无独立设备时由老师分组朗读，或改用不同阅读卡并明确这是阅读）。A周六上午晴24度，B下午可能下雨28度。先互相问清，再各向另一个同学给一条建议，听者说出建议依据。

**需要帮助时：**上午……，下午……。／我喜欢……。／现在还不知道……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 上午与下午有什么不同？ |
| 2 | 大家已经决定什么时候去了吗？ |
| 3 | 哪一句属于个人喜好或建议，而不是天气信息？ |

### 延伸：A读本（只给A）

【活动负责人】我们昨天安排了周六下午的户外活动。今天看到预报说“下午可能有雨”，有人立刻要求取消，也有人认为“可能”就是可以忽略。我认为这两种说法都太快。我们需要先确定什么时间作最后决定，以及如何通知参加者。天气资料只能提供部分依据，参加者是否愿意接受下雨的可能，也会影响选择。

### 延伸：B读本（只给B）

【参加者】我已经空出了下午，所以希望不要随便取消。不过，我不反对准备一个室内方案。我最在意的是通知是否清楚：现在是确定改地点，还是只在考虑？“应该照常”让我不知道要不要出门。请负责人把已决定的事项与尚未确定的事项分开说明，不要把个人乐观当成天气预报。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：负责人 | 活动14:00开始。你可以在12:00统一通知，但现在没有最终决定。不能把备选方案说成已确定。 |
| B：参加者 | 你13:00需要出门。你要求出门前明确通知；能接受室内方案，但要问清地点是否已确认。 |
| C：消息核证者 | 最新消息只写“下午可能有雨”；室内教室是否可用尚未确认。你必须区分事实、预测、意见，再转述给两人。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 将句子分成“资料／预测”“个人意见”“已作决定”。 |
| 2 | 哪些词容易让听者误以为事情已经确定？ |
| 3 | 写下三行提示，口头发布一则45秒更新，听者检查有无把可能说成一定。 |

**交流前可选的表达：**根据目前的信息……；这不表示……一定……；我们暂时保留……；最晚在……之前确认。。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**将同一更新分别改成给同学的语音和给学校负责人的口头汇报；指出自己哪些判断超出了资料，不讨论真实灾害处置。

**完成后：**备用8分钟：对四条模拟预报标题判断哪条表达过度确定，改写其中两条。


## 第12课｜我正在等公共汽车呢

### 核心任务

现在／平时双面卡：每人选一个角色，回答“现在在做什么”和“每天做什么”，听者在两栏记录关键词。第二轮加入“从周一到周五／从下星期开始”信息，听者须核实是日期范围还是每天的动作。

**需要帮助时：**他正在……。／他每天都……。／从……到……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 三个人现在分别在做什么？ |
| 2 | 哪件事是平时的习惯，不只发生在今天？ |
| 3 | 小王已经确定迟到了吗？ |

### 延伸：A读本（只给A）

【12:20项目群消息】我正在检查照片，还没有发给老师。小林负责选择三张照片，他说午饭后再看。我们每天都在群里报告一次，但今天的报告不代表所有事情已经完成。请不要只回复“好了”，最好说明完成了哪一步，还有哪一步需要别人配合。

### 延伸：B读本（只给B）

【12:35转述记录】有人把群消息转告老师：“照片已经选好，也发过去了。”负责同学听到后很着急。他只是说正在检查，没说已经交出；小林也只是计划午饭后看。一次转述把正在进行、将来打算和已经完成混在了一起，其他人因此以为不必再做什么。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：原发言者 | 你正在检查照片；尚未发送；需小林选3张。你要纠正转述，但不把对方说成故意骗人。 |
| B：转述者 | 你确实把“正在检查”说成“已经发了”。先复述你现在理解的事实，再修正消息。 |
| C：接收者 | 你必须问清是谁负责什么、现在在哪一步。听完修改版后，独立报告当前状态，不能看A原卡。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 转述改变了哪两项意思？ |
| 2 | 找出原文的进行中、日常习惯、未来打算。 |
| 3 | 用30–45秒给未读消息的同学说明状态，并回答“所以现在都做好了吗”。 |

**交流前可选的表达：**现在正在……，还没有……；他原来的意思是……；每天……不等于今天已经……；我刚才转述得不准确，应该是……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**不得直接复述原句；在45秒内传达三种时间状态，听者刻意提出一个错误推断。发言者用澄清而非完整重讲纠正。

**完成后：**备用10分钟：三人传递一条含“现在／每天／下星期”的消息，最后与原文比对误差；不得变成故意传错的游戏。


## 第13课｜你打算买什么样子的

### 核心任务

需求访谈：买家不能先看商品，只告诉店员“要放什么、喜欢什么颜色、多少钱以内”。店员有A蓝80元小、B黑90元大、C红70元大的资料，先追问两项需要再推荐。质量资料没有提供，须说不知道或提出核实，不能凭价格猜。

**需要帮助时：**我想买……的。／这个有点儿……。／有没有……一点儿的？

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 买家可以接受哪些颜色？ |
| 2 | 为什么没有立即买蓝色的？ |
| 3 | 他已经买了黑色的吗？ |

### 延伸：A读本（只给A）

【商品页面】轻便学生书包，适合上课、旅行与日常外出。页面强调“容量充足、做工精细”，照片里放了电脑、书和水杯，但没有说明电脑尺寸，也没有展示装满以后背在身上的样子。店员表示很多学生买，却没有提供这些学生的实际使用反馈。

### 延伸：B读本（只给B）

【使用者的评论】我买来装两本书很方便，拉链也顺。但把电脑、水杯和外套都放进去以后，空间就不太够了。我不能说广告完全不真实，因为我的使用需求可能和别人不同。对我而言，“适合学生”太宽泛，更有用的问题是：它是否适合我每天带的东西？

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：买家 | 你每天带电脑、3本书和水杯；可接受黑或蓝；预算100元。你要的是能用，不是只要好看。 |
| B：店员 | 你有两款样品，可让顾客试装，但不知道电脑尺寸。不能仅凭“很多人买”作保证。 |
| C：评论审核者 | 你指出评论只报告一位用户的情况；必须问一个能改变推荐的问题，并评价店员是否把未知说成保证。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 广告里的哪两个评价还缺少具体说明？ |
| 2 | 评论否定了整个商品吗？ |
| 3 | 做一次需求访谈；先问再推荐，推荐中说出一个仍需试用的地方。 |

**交流前可选的表达：**就你的使用情况来说……；与其只看……，不如先确认……；这条评论说明……，但不能证明……；我想找……一点儿的。。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**把广告改成60秒负责任的销售说明，既有吸引力又不作材料不支持的承诺；同伴提出“你怎么知道”的追问。

**完成后：**备用8分钟：把“好看／好用／质量好”分别换成可观察的描述；没有证据的地方明确保留。


## 第14课｜祝你生日快乐

### 核心任务

三人生日电台：A提议先吃饭再送礼物，B问清寿星喜好，C把建议顺序转述给寿星。每人须提出或回应一个建议；第2轮不增加人数，改为寿星更想安静聊天，重新解释活动是否合适。

**需要帮助时：**先……，然后……。／你想请谁？／好啊。／我想简单一点儿。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 原来的活动顺序是什么？ |
| 2 | 谁希望来很多人？谁想少一点人？ |
| 3 | 什么已经准备了，什么还没有？ |

### 延伸：A读本（只给A）

【朋友甲】我觉得生日应该给朋友一点惊喜。上次大家一起布置房间，寿星很感动，所以这次也想请全班参加。不过我没有问她，是因为担心问了就没有惊喜。我把上次别人的反应，当成这次也会成功的理由，可能忽略了每个人喜欢的方式不同。

### 延伸：B读本（只给B）

【寿星的留言】我很感谢大家记得我的生日，但不太喜欢在人多的时候成为注意的中心。我愿意和几位朋友吃饭，也愿意收祝福。让我不舒服的不是有人关心我，而是我说了想简单一点，别人还觉得我只是客气。希望朋友认真听我表达的偏好。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：企划者 | 你已通知3位同学，但还没有通知全班。你担心取消惊喜显得没诚意。 |
| B：寿星 | 你明确希望小范围吃饭，不同意叫全班。你愿意提出一个自己喜欢的替代方式。 |
| C：协调者 | 你要先准确转述两人的善意与顾虑，再提出兼顾的做法；不能用多数票推翻寿星明确意愿。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 甲用了什么经验支持自己的想法？这个经验有什么限制？ |
| 2 | 乙不喜欢的是生日、朋友，还是庆祝方式？ |
| 3 | 先向朋友说明改变原因，再向寿星表达祝福；两段语气怎样不同？ |

**交流前可选的表达：**我原来以为……，听你这样说才发现……；我不是不喜欢……，而是……；既然你更希望……，我们就……；最重要的是让……觉得舒服。。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**先替自己不同意的一方作最有说服力的90秒说明，再提出自己的结论。回应对方实际顾虑，不把反方简化成“他不关心朋友”。

**完成后：**备用10分钟：同一祝福分别给熟悉朋友和刚认识的同学；听者判断语气、亲密程度是否合适。


## 第15课｜我可以试试吗

### 核心任务

请求轮转：两人分别扮顾客／服务者，依次处理试穿、借笔、请人再说一次。回应卡各为“可以”“现在不能，但可以……”“需要先问负责人”。每轮换角色；合理结束可以是不买，不要求所有请求都成功。

**需要帮助时：**我可以……吗？／可以。／现在不可以，不过……。／我先看看。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 顾客先提出什么请求？ |
| 2 | 为什么没有买？ |
| 3 | 店员拒绝了试穿请求吗？ |

### 延伸：A读本（只给A）

【服务者】我愿意帮客人，但有些事情不是我一个人能决定。例如借走展示品，需要先问负责人。我以前只说“不行”，客人觉得我不想帮忙；后来我学会解释自己能做什么、不能保证什么，再给一个可行的下一步。我不应该为了显得热情，就先答应一个自己做不到的要求。

### 延伸：B读本（只给B）

【顾客】我能接受有规定，也不要求店员每次都同意。不过，“等一下”可能是一分钟，也可能半小时，我希望知道大概要等多久。若店员说可以帮我问，我不会把它理解成已经批准。拒绝本身未必让人不舒服，模糊承诺和没有后续才更容易造成误会。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：顾客 | 你想把样品带走一天比较；你15分钟后必须离开。可以接受现场试用，但要确认能试什么。 |
| B：店员 | 模拟店内规则：允许现场试用10分钟；带走需负责人批准，负责人20分钟后回来。不能擅自同意。 |
| C：观察者兼第二顾客 | 先记录是否说明限制、替代和等待时间；随后提出一个不同请求，让两人即兴回应，并给出一条反馈。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | “可以帮你问”与“可以借走”有什么不同？ |
| 2 | 如何拒绝而不显得敷衍，也不作虚假承诺？ |
| 3 | 演一次90秒服务对话，再针对一处含糊说法重演。 |

**交流前可选的表达：**这件事我需要先确认一下。；现在不能……，不过您可以……；我能保证的是……；谢谢，那我先……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**将同一拒绝分别用于朋友借物和正式服务场景；另一人只改变语气，不改变限制事实，检查听者能否准确理解许可范围。

**完成后：**备用8分钟：四句含糊回应改成明确又礼貌的回应；不以“必须答应顾客”为标准。


## 第16课｜来一斤饺子

### 核心任务

三人点餐：顾客A负责主食，B负责口味，店员C只收到分开的需求。A/B不能把整个清单直接给C看；C必须口头复述数量和口味。轮换店员，另一次加入“先不要／再来”，听者确认是追加还是暂缓。

**需要帮助时：**来……。／不要……。／先不要……。／还要……吗？

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 现在确定点了哪三样？ |
| 2 | 小李有什么口味要求？ |
| 3 | 有没有已经点面？为什么？ |

### 延伸：A读本（只给A）

【顾客的说明】我不是完全不吃肉，只是不喜欢这家菜放太多油。朋友把我的话转告店员时，说成了“他什么肉都不吃”，结果适合我的菜也被排除了。我希望点菜的人先问清楚，不要根据一句话替别人决定全部偏好。如果菜单没有写清楚做法，可以问店员，而不是靠菜名猜。

### 延伸：B读本（只给B）

【服务员的说明】客人常说“随便，都可以”，等菜上来却发现每个人理解的“都可以”不一样。我通常会先确认有没有明确不吃的食材，再问份量和口味。推荐不只是介绍最贵的菜，而是把对方的需要转换成厨房能执行的订单。遇到不确定的成分，我会先核实，不会随口保证。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：顾客 | 你吃肉，但希望少油、不辣；不要把自己的偏好说成医学过敏。你要问清做法。 |
| B：同行者 | 你吃得少，不想一下点太多。你认为A不吃任何肉，这个理解有误，须听完后修正。 |
| C：店员 | 模拟菜单：白菜饺子12元／半斤，青菜10元／盘，汤8元／碗；份量与是否加辣可问厨房，成分不详时不保证。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | B替A转述时，扩大了哪一项限制？ |
| 2 | 如果只是偏好不辣，怎样准确告诉店员？ |
| 3 | 完成一份口头订单；第三人只凭听到的内容，复核份量、口味与暂未决定的菜。 |

**交流前可选的表达：**他的意思不是……，而是……；这道菜能不能做得……一点？；先来……，不够再加。；我再确认一下，您要的是……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**同一需求先向朋友转述，再向店员转述，最后给厨房一句可执行的说明。保留限制，不添事实；面对店员反问即时澄清。

**完成后：**备用10分钟：听一段点单录音或老师朗读，记录三处自我更正，最后只报最终订单，不报已撤回的项目。


## 第17课｜喝茶还是喝咖啡

### 核心任务

先背对背路线核对：A描述，B画3步路线，交换角色；再做主人／客人30秒选择与帮忙对话。两段都要有个人证据，不能用一杯饮料问答代替路线。

**需要帮助时：**先往……走，到……再……。／你喝……还是……？／需要帮忙吗？

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 出东门以后先往哪边？第几个路口再转？ |
| 2 | 家与书店是什么关系？ |
| 3 | 客人必须喝茶或咖啡、必须会做饺子吗？ |

### 延伸：A读本（只给A）

【主人的回顾】客人第一次到我家，我希望他觉得受到欢迎。我问他喝茶还是咖啡，他说“水就好”，我却一直劝他试试茶。后来才想到，他已经清楚地表达了选择，我没有认真听。我还说“别客气，自己来”，但他不知道杯子在哪里，这种热情并没有变成实际帮助。

### 延伸：B读本（只给B）

【客人的回顾】我不是不喜欢主人准备的茶，只是那天想喝水。我说了两次，主人仍以为我在客气，让我不知道该怎样再拒绝。后来我问杯子在哪里，并直接说“谢谢，我今天喝水就好”，气氛反而轻松了。我认为待客时，给选择以后也应该允许对方真的选择。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：主人 | 你准备了茶、咖啡和水；杯子在桌子左边。你想热情，但要尊重选择。先给出清楚到访路线，再招待。 |
| B：客人 | 你已在第一个路口，不知道要不要再往右；到后只想喝水，可以帮忙摆杯子。 |
| C：观察者兼来电朋友 | 你先检查路线是否足够执行，再打一次电话要求主人简短说明。随后反馈主人是否倾听了客人的真实选择。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 两人对“热情”的理解有哪些差异？ |
| 2 | 材料能不能证明某个国家的人都这样待客？ |
| 3 | 先修复一次走法误会，再自然结束饮品选择；拒绝后不必强行提出另一杯饮料。 |

**交流前可选的表达：**谢谢，我今天……就好。；你不用特地……；需要我帮你……吗？；我理解你的好意，不过……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**先以第三方视角解释误会而不责备任何一方，再分别向主人和客人给一句不同的建议；每句建议说明针对的是哪个具体行为。

**完成后：**备用8分钟：主人连续提出三次好意，客人练习接受一次、拒绝一次、询问一次；观察者检查意图是否清楚。


## 第18课｜今天我七点半就起床了

### 核心任务

时间基准配对：A平常08:00、今天07:30；B平常06:30、今天07:30；C约09:00、08:50到；D约08:00、08:50到。先说事实，再选择就／才说明态度。搭档更换基准，不能背“7:30就是早”。

**需要帮助时：**我平常……点，今天……点就／才……。／以前……，现在……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 两人今天几点起床？ |
| 2 | 为什么一个说就、一个说才？ |
| 3 | 小陈以前与现在有什么不同？ |

### 延伸：A读本（只给A）

【学生甲】以前我把“起得早”当成自律的证明，每次听到别人六点起床就觉得自己做得不够好。后来发现，我晚上的工作结束时间和别人不同。现在我会具体说：原来几点做什么，调整后改变了什么，以及还有什么没改善。单独报一个起床时间，别人其实很难判断我的一天。

### 延伸：B读本（只给B）

【学生乙】我以前做计划时写得很满，但没把从宿舍到教室的时间算进去。现在我会提前准备书包，也减少早上找东西的时间。昨天我八点就到教室了，比自己平常早十分钟。不过一天做到，不等于已经养成习惯，我想再观察一星期。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：采访者 | 询问对方“以前／现在／为什么改变”，不评价对方健康或人格。至少问一个具体例子。 |
| B：受访者 | 用虚构经历：过去07:50出门，常找不到书；现在07:35出门，先准备书包。说明一次变化，不编长期成效。 |
| C：转述者 | 听完后以第三人称复述，保留时间基准；受访者指出一处不准确的转述。下一轮轮换。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 两段文字各反对怎样的过度判断？ |
| 2 | 用具体前后事件说明改变，不只说“变好了”。 |
| 3 | 同一经历先讲90秒，收到一个反馈后换听者再讲90秒；不要先缩短时间催快。 |

**交流前可选的表达：**以前……，现在……；对我来说，这已经算……；比起……，我更在意……；这一次……，还不能说明一直……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**在第二轮把叙述改成“变化—原因—例子—局限”四段短陈述，再回答一个质疑“你怎么知道不是偶然”。语言精确比说得快优先。

**完成后：**备用10分钟：比较第一次与第二次录音，找一处更清楚的时间关系及一处还要改的停顿，不计算生硬语速排名。


## 第19课｜你又熬夜了

### 核心任务

先拼时间线，再完成道歉：一人说约定与等候，另一人说明原因并提出下次做法；第二轮对方改变等待经历而不是只换名字。至少核对“多久”与“几点”的差别。

**需要帮助时：**我们约……点，我等了……分钟。／今天又……。／下次我会……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 原来几点见？实际几点到？等多久？ |
| 2 | 哪一个重复行为已经发生？ |
| 3 | 哪一件重复行为是将来的打算？ |

### 延伸：A读本（只给A）

【迟到者】我知道迟到让朋友不舒服，所以一见面就解释自己为什么没看见消息。可是我说了很多原因，朋友还是生气。回家后我发现，我一直在说明“不是故意的”，却没有回应他实际等了半小时、又不知道我要不要来的困扰。解释原因和承担这次影响，并不是只能选一个。

### 延伸：B读本（只给B）

【等候者】我可以理解偶尔有意外，但我最不满的是没有消息。我并不需要对方保证以后永远不会迟到，而是希望可能晚到时早点通知。听到“你等一下又不会怎样”，我觉得自己的时间不被重视；听到“这次让你等了很久，下次我先告诉你”，我更愿意继续谈。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：迟到者 | 你晚到30分钟，确实没发消息。说明原因，但不能说“你不应该生气”。 |
| B：等候者 | 你愿意听原因，但要让对方知道影响；你希望有提前通知，而不是不可能兑现的保证。 |
| C：调解者 | 分别复述双方最在意的一点，再让他们提出一个下次可执行的做法；不能判断真实同学谁有错。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 两段叙述是事实冲突，还是关注点不同？ |
| 2 | 哪些句子在解释，哪些在回应对方受到的影响？ |
| 3 | 做一次道歉与回应；观察者给一项具体反馈，再重演关键40秒。 |

**交流前可选的表达：**这次确实让你……；我不是想推卸……；我能理解你在意的是……；下次如果……，我会先……。只选自己需要的，不必全部塞进对话。

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**先用自己的话转述对方立场并获确认，才能提出反驳或解释。比较“说明原因”与“找借口”的语言差异，但不把某个表达永远贴成借口。

**完成后：**备用8分钟：把“对不起，下次注意”改成能执行的具体承诺；同伴问一次“具体怎么做”。


## 第20课｜我想请一天假

### 核心任务

学生／教师模拟：A要请周二上午半天，B给出需通知与补交作业的模拟要求；A复述。另用看病语言小情境“哪里不舒服／多久了／能不能……”，只确认语言意思，不选择药物或作真实判断。

**需要帮助时：**我想请……假。／如果……的话……。／我会在……之前告诉您。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 学生请哪一段时间的假？ |
| 2 | 下午是否已确定到课？ |
| 3 | 哪一项学习任务什么时候交？ |

### 延伸：A读本（只给A）

【学生草稿】老师，我最近有事，所以这几天可能不能来。作业以后再说吧。——这条消息虽然表达了困难，却没有说明具体日期、想请多长时间，也没有区分“提出请求”和“已经获得同意”。老师很难据此安排课堂与后续学习。

### 延伸：B读本（只给B）

【教师的回应】我希望知道请假的日期、时间范围以及你希望怎样补上学习内容，但不需要你在全班群里公开详细的私人情况。如果有些事还没确定，可以明确说“目前还不确定，我会在……之前回复”，而不是为了把消息写完整就编出确定答案。这里讨论的是模拟沟通要求，不代表学校正式请假制度。

### 交流角色（分开发）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：学生 | 你要请周二上午半天；下午是否能来未定；你愿意周五交练习。私人原因可以只说身体不舒服。 |
| B：教师角色 | 模拟要求：周五前交本周练习；当天12:00前通知下午能否到课。只审批本情境，不引用现实校规。 |
| C：班级联络员 | 你只需要转达是否到课和补交时间，不应在群里传播详细私人原因。请复述一则适合公开的通知。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 草稿缺少哪些决定所必需的信息？哪些私人细节并非必须？ |
| 2 | 怎样表达不确定但仍让对方知道下一步？ |

## 第21课｜每个人要说多长时间

### 核心任务

**需要帮助时：**……点开始。／一共……分钟。／每人……，每组……。

### 听力检查（先听老师，不看逐字稿）

| 题 | 问题 |
| --- | --- |
| 1 | 笔试和口试各多久？口试时长是每人还是每组？ |
| 2 | 口试几点开始？ |
| 3 | 电脑不能用时，什么改变、什么不变？ |

### 延伸：A读本（只给A）

【活动通知】口试分两部分：先作个人说明，再与同伴交流。每组共六分钟，其中每人个人说明一分钟，两人交流三分钟，最后一分钟用于转换与记录。通知写得很清楚，但学生转告时只说“每个人六分钟”，整个时间安排因此被放大。

### 延伸：B读本（只给B）

| 角色 | 你知道什么、需要做什么 |
| --- | --- |
| A：负责人 | 模拟3组：09:30、09:36、09:42开始，每组6分钟；只有一个考位。09:30设备故障，改用纸图，09:35可以开始。 |
| B：学生 | 你在第2组；希望知道新开始时间和是否缩短作答。规则是不缩短每组6分钟。 |
| C：公告员 | 你负责按同一规则重排3组并口头通知；核对每人／每组，不得新增第二个考位。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 通知里哪些时间是个人、哪些是整组？ |
| 2 | 故障后如何解释变化，而不让听者误以为作答时间减少？ |

**反馈：**听者说一件听懂的事，再问一件不清楚的事。说话者改进后，对新听者再说一次。

**更高挑战：**另一组质疑“延后5分钟就要少考5分钟”。用清楚的因果与单位说明反驳；不靠画满算式代替语言解释。

**完成后：**备用8分钟：一段故意省略单位的口头公告，听者只用三个问题补齐，不直接猜测。


## 第22课｜明天你下了课去哪儿

### 核心任务

建议接力：A说计划“先吃饭再还书”，B提供“图书馆17:00关，现在16:30”的关键信息，C提出建议并请A回应。第二轮不是换钟面而已，加入“朋友还未确认”的计划状态。

| C：评议者 | 你的标准是具体、可执行、尊重选择。指出建议中一句过度保证，再改说一次。 |

| 步骤 | 任务 |
| --- | --- |
| 1 | 哪条建议更具体？找出证据。 |
| 2 | “只要计划详细就一定做到”有什么未经证实的前提？ |

**更高挑战：**先建立三条“好建议”的评价标准，比较两段新建议，再回应一个真实反例。用条件与限定语，不把个人习惯当普遍规则。

**完成后：**备用10分钟：把“你应该努力一点”改成一条具体建议，听者说出明天到底要做什么。


## 第23课｜假期有什么打算

### 核心任务

旅行采访：A有“周六出发已定、住两天、交通未定”，B有“想看展览、地点未定、可以周末”。先问而不替对方决定，然后各以第三人称说清已定与未定。

**需要帮助时：**我打算……。／已经决定……。／……还没决定。／……还是……？

| --- | --- |

【甲的旅行想法】我喜欢出发前把每天安排好。这样能减少临时查资料，也比较不怕到了以后不知道做什么。不过我承认，计划太满的时候，会因为赶下一个地点而忽略眼前的体验。我不是认为所有时间都不能改变，而是希望至少把交通与住宿确认好。

**更高挑战：**反向立场：先准确替对方论证，再提出折中。给出反例后调整自己的概括；不以“我喜欢，所以最好”结束。

**完成后：**备用8分钟：对三条旅行宣传语区分事实、评价、保证；未知真实资料不要现场编造。


## 第24课｜学得怎么样

## 第25课｜准备好了吗

### 核心任务

**完成后：**备用10分钟：把五句“好了”改成不同结果状态；听者判断还有没有必要追问。

新资料C卡：客人在东门；从东门右转，第一个路口左转，书店旁是主人家。客人要水、不辣；同行者想喝咖啡。主人有三种饮品，菜品做法须问服务者。

| 路径 | 任务 |
| --- | --- |
| 核心 | 三人轮换主人、客人、餐饮服务者；分别完成路线询问、饮品选择、订单确认。每个角色都要提问、听取并回应。 |
| 延伸 | 将客人偏好准确中介给第三方，分析“热情地劝”和“认真地听”的区别；同伴从完整性、得体性给反馈。 |
| 最后要留下 | 每人独立画出听到的路线，再口头转述一位客人的需求。 |

### W09｜故事采访圈：同一事件的两个视角

新资料C卡：甲平常08:00出门，今天07:40；与乙约08:10，但车08:25才到。甲08:05发“车还没来”，乙08:30才看到。甲不一定故意不通知；双方都缺对方的信息。

| 路径 | 任务 |
| --- | --- |
| 核心 | 用就／才与又／再讲一则虚构早晨故事；听者问清平常时间、今天时间与下一次做法，第三人复述。 |
| 延伸 | 讲一次习惯改变或迟到误会，分清原因、影响和后续行动。可以虚构，不要求披露真实关系冲突。 |
| 最后要留下 | 保存前后两版短叙事，标出一处更清楚的时间关系和一处有效回应。 |

### W10｜学生服务台：请假、补交与口试说明

新资料C卡：周三上午请半天假，下午未定；周五交练习。补做口试周五14:00开始，2人一组共6分钟，不是每人6分钟。

| 路径 | 任务 |
| --- | --- |
| 核心 | 学生、教师、公告员分别持日期、补交、时长资料；完成一次请求及复述，核对每人／每组单位。 |
| 延伸 | 把同一信息分别传达给老师、同学与活动负责人；比较哪些细节应保留，哪些私人信息不必公开。 |
| 最后要留下 | 每人独立说明日期、时长与下一步，再回答一个随机澄清问题。 |

### W11｜计划听证会：先计划好，还是保留弹性

新资料C卡：两天行程；住宿与返程需出发前确认；白天活动可自由选择。甲希望上午固定一个活动，乙希望至少留半天空白；两人都同意先确定住宿。

| 路径 | 任务 |
| --- | --- |
| 核心 | 比较两种日常活动安排，分别说已定一项、备选一项，询问对方并回应建议。 |
| 延伸 | 先定义双方所说的“计划”，找到真实分歧再论证；每人有陈述、复述对方观点、回应反例三个回合。 |
| 最后要留下 | 每人说一个有条件的建议，明确什么已决定、什么还在考虑。 |

### W12｜学习作品诊所＋活动交接会议

新资料C卡：资料写完但未核对名字；饮料买了但未收到；负责人联系过但还没明确答应；桌子已摆好。三人分别掌握不同信息。

| 路径 | 任务 |
| --- | --- |
| 核心 | 听两段老师原创表现样本，给一项具体反馈；再核对活动“已写／写对”“已买／收到”等结果。 |
| 延伸 | 根据同一目标比较前后表现，区分流利、准确与信息完整；做一段交接语音，让新负责人不必重问所有事项。 |
| 最后要留下 | 个人改进前后录音＋一份口头交接；每条下一步说明负责人及何时核对。 |
