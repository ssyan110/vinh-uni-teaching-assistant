### 目前最重要的課程目標

學期總覽要求學生在不依賴逐句翻譯的情況下：

1. 聽懂新材料的主旨、關鍵細節、說話者立場與支持答案的證據。
2. 在訪談、討論、角色任務與小組決策中提問、回答、追問、確認、改述與協商。
3. 依對象和任務完成約 60 秒至 3 分鐘的說明、敘述、比較、推薦或提案。
4. 聽到不同意見後回應，並依同伴或教師回饋重說一段話。
5. 以聽力記錄、口語表現、調查資料、錄音、出口卡與反思建立學習檔案。

這些是目前課程設計的學習結果，不是學校已公布的正式能力證書或 ACTFL 等級。

## 4. 現行教學方法與課堂架構

### 4.1 目前課程循環

目前文件共同描述的課堂循環是：

`課前預習 → 先做理解／互動任務 → 觀察表現 → 只修補高影響問題 → 重做或變式任務 → 出口證據`

課前最低要求包括快速讀指定頁面、聽指定音檔、標記一個卡點，並準備個人資料、問題、調查或微研究。未預習學生使用約 3–5 分鐘的 recovery route（看簡短卡片、聽一次、說一句、問一題），之後回到原任務，不把整節課退回逐字講解。

### 4.2 第一課的六節架構

| 節次 | 主要教材／動作 | 學生主要產出 |
| --- | --- | --- |
| P1 | 聽說（一）、詞語理解；回收姓名預習、聽力主旨與細節、姓名訪談 | 聽力答案與依據；介紹一位同學的姓名；出口卡 |
| P2 | 語句理解、語段理解、句式；跟讀、替換、遮稿重建與句式使用 | 個人替換句；不看稿對話重建；句式情境回應 |
| P3 | 語段理解、文化知識；填空、判斷、開放回答、閱讀與同音字短講 | 關鍵資訊與證據；文化觀察；約 60 秒成段表達 |
| P4 | 拓展練習；起名兒公司、電影演員中文名、姓名分類／調查 | 90 秒姓名提案；客戶追問；小組報告 |
| P5 | 聽說（二）；本國姓氏比較、姓氏對話、替換與重建 | 比較型訪談；主旨與細節；不看稿對話重述 |
| P6 | 句式、文化知識、拓展；姓氏信息站、歷史人物、姓氏互聽、對話總結 | 三個句式任務；文本重點互教；人物介紹；五句總結與報告；課末檢核 |

第一課學生 PPTX 的 section 順序依教材安排，包含「聽說（一）」「詞語理解」「語句理解」「語段理解」「口語句式」「文化知識」「拓展練習」，再進入「聽說（二）」並重複相應架構。投影片只呈現學生當下動作、音檔按鈕、教材頁碼與必要材料；教師時間、分組、答案政策和來源追蹤留在教師手冊或 speaker notes。

### 4.3 語言形式如何被使用

- 詞語與句式不是先講完再開始課堂；先讓學生理解或完成任務，再處理阻礙任務的讀音、詞序、詞語或句式。
- 跟讀、替換、選擇、填空、判斷與遮稿重建保留作為支架，之後要接到個人資料、同伴追問、情境選擇或報告。
- 「總不能……吧」等句式先放回教材的看牙、接孩子或姓名選擇等情境，再要求學生表達一個立場、結果或底線。
- 開放題與文化題不補造唯一標準答案；教師依任務完成、理由／證據、互動與可理解度評量。

| 受控練習 | 各課反覆出現選擇、填空、判斷、跟讀替換、對話重複、句式完成 | 高 | 主要服務聽力辨識、形式準備與安全支架，不應單獨當作能力終點 |
| 溝通式語言教學 | 個人姓名、朋友調查、文化比較、討論、訪談、報告、追問與客戶回應 | 中至高 | 在第一課重組包中特別明顯；其他課尚未完成教學設計 |
| ACTFL PBI | 明確使用 Interpretive、Interpersonal、Presentational 三模式，並為第一課每項練習記錄 observable evidence | 高（設計層面） | 是目前批准的設計框架；尚無全班正式 ACTFL 能力判定 |
| 行動導向／TBLT | 起名兒公司有隱藏客戶條件、顧問提問、姓名提案、客戶追問與小組產出；姓名訪談有角色、追問與觀察記錄 | 中（第一課已實作；全課程未知） | 第一課已有 genuine task；第 2–8 課目前只有教材來源快照 |
| 輸入導向 | 每課大量聽力、短文、對話、第一遍抓大意、第二遍找細節與證據 | 中至高 | 輸入是主軸，但輸入難度與個別支援尚未用學生資料校準 |
| 明示語言教學／focus on form | 課本句式、跟讀替換與教師 just-in-time repair | 中 | 明示形式存在，但政策要求每節直接講解原則上不超過 5 分鐘 |
| PPP | 受控內容常呈現「示範／跟讀 → 練習 → 說」，但現行 PBI 規則要求先做任務、再依表現修補與重做 | 混合 | 不能把整門課簡化成嚴格 PPP；目前是教材支架與 PBI 任務的混合架構 |
| Pair／group work | 第一課活動使用兩人、三人或三至四人角色分組；課程手冊要求每人仍留下個人口語證據 | 高 | 分組是常態，但實際班級人數與分組可行性未知 |
| Information gap | 客戶卡不給顧問看、姓氏互聽記錄、訪談者依回答追問、資料交換 | 中；第一課高於原始教材 | 是把教材題目轉成互動的主要設計手段 |
| 教師主導講解 | 文件明確限制直接講解；但沒有實際觀課或錄影資料 | 目標為低；實際頻率未知 | 不應把政策誤寫成已驗證的課堂行為 |
| 專題式學習 | 調查、人物研究、報告與音樂／環境田野調查類活動存在 | 低至中 | 有短期研究與報告，不足以證明是長期 project-based course |
| 自發／轉移使用 | 第一課有追問、客戶反應、重做；期中與期末設計新聽力、陌生情境與新限制 | 正在建立；實際成效未知 | 課程目標已指向 transfer，但尚缺學生表現資料 |

## 6. 以 TBLT 觀察現有活動

| 活動類型 | 現有例子 | 分類 | 目前作用 |
| --- | --- | --- | --- |
| 受控練習 | 聽力選擇、填空、判斷、跟讀替換、句式改寫 | drill／controlled practice | 建立辨識、注意形式與理解證據；本身通常沒有資訊差或真實結果 |
| 有支架的說話 | 「用三至五句回答問題並使用畫線詞語」 | guided communication | 有個人內容，但選擇與聽者回應有限；適合銜接到追問或短講 |
| 對話重建 | 遮住課本、聽後複述並交換角色 | controlled → guided | 把輸入轉成口語記憶與連貫表達；若不加變式，仍偏排練 |
| 姓名訪談 | 先問姓名讀音／意思／來歷，再追問；觀察者記錄一項回饋 | communicative activity | 有真實個人資訊、追問理由、角色與可留下的訪談記錄 |
| 起名兒公司 | 顧問不知道客戶卡；先問條件，再提案、說理由、回答追問 | genuine task | 有目的、資訊差、條件限制、學生選擇、聽者與可觀察提案結果 |
| 姓氏信息站 | 句式卡、文化比較卡、課文重點互教、姓氏互聽、五句對話總結 | guided information-gap task | 有互相說／聽／記錄的結果；部分題目仍依教材提示，支架較強 |
| 調查／研究／報告 | 姓名調查、歷史人物、朋友或音樂調查、環境議題報告 | presentational／project-like task | 有資料與聽眾，但需確認每次是否有個人選擇、觀點差與真實回應 |
| 討論／辯論 | 朋友、城市／農村、環境、音樂等文化或觀點題 | communicative activity；有條件時可成 genuine task | 需要明確立場差、理由、回應與結果；不能只停在輪流造句 |

受控練習在這門課有合理的支架功能，不需要因為受控就全部刪除。設計重點是確認它之後接上意義協商、個人選擇、聽者反應、任務結果與重做，而不是把它當作最終能力證據。

## 7. 能力與表現發展分析

| 分析面向 | 學生目前被要求做什麼 | 文字類型與證據 | 判斷 |
| --- | --- | --- | --- |
| Interpretive | 抓主旨、找細節、判斷說話者態度、引用音檔／文本依據 | 音檔、短文、對話題目、填空／判斷／開放回答 | 已明確寫入課程與第一課設計 |
| Interpersonal | 問、答、追問、澄清、確認、改述、協商、回應客戶或同伴 | 4-turn 訪談、角色任務、文化比較、資訊卡、客戶追問 | 第一課已有具體觀察證據；全班實際表現未知 |
| Presentational | 介紹、敘述、比較、解釋、推薦、報告、提案 | 30 秒人物介紹、60–90 秒短講／提案、2 分鐘報告、期末 2–3 分鐘表現 | 目標清楚；仍需用學生樣本驗證可行難度 |
| Context／content | 身份與姓名、人際關係、地方與生活、環境、音樂、挑戰、職場、漢語學習 | 八課主題與文化材料 | 題材廣；需要跨課回收，避免每課變成孤立詞彙島 |
| Text type | 從詞語、句子、填空與模仿，走向三至五句、五句總結、成段口語與短報告 | 教材練習＋第一課任務 | **合理推論**：目標正在從句子層次走向多句連貫表達；未有實際錄音可定級 |
| Accuracy／comprehensibility | 以可理解度、任務完成、理由／證據、互動和組織為主；形式錯誤只在影響任務時修補 | 第一課 0–3 觀察表、同伴回饋、重做 | 已批准的評量取向，不以單一語法正確率作主要標準 |
| 排練與轉移 | 熟悉教材任務有明確支架；期中／期末加入新材料、新限制、陌生情境與追問 | 期中、期末課程設計 | **合理推論**：課程正試圖從 rehearsed performance 走向 transferable proficiency；尚無結果資料 |

目前沒有足夠證據為學生或課程貼上正式 ACTFL Novice／Intermediate／Advanced 等級。未來規劃應使用「學生能做什麼」與實際表現樣本，而不是由課本標題反推等級。

## 10. Information Needed From Teacher／尚需教師提供的資訊

1. **班級實際資料**：人數、分組方式、缺席率、學生主修／年級，以及是否有明顯程度分層。
2. **學生能力基線**：不看拼音閱讀能力、聽力主旨／細節、可持續口語時間、追問與澄清能力、中文使用信心；最好提供幾份匿名口語或聽力樣本。
3. **正式評量規定**：學校／系上的成績比例、期中期末形式、是否有統一考試或必考題型。課程手冊的 30% 形成性、20% 中期、30% 期末、20% 學習檔案目前是建議比例，不是已確認的正式規定。
4. **實際課表與教室條件**：每週上課頻率、休息安排、投影與音響、網路、是否可用手機或錄音、列印條件、座位與分組限制。
5. **預習與課堂觀察資料**：學生實際完成預習的比例、最常卡住的音檔／詞語／句式、哪些活動時間不足或互動不自然。
6. **配套權威決定**：確認預習卡、評量表、出口卡是否已另存為目前 authority；若尚未存在，決定是否補入第一課 release，再沿用到後續課次。
7. **後續來源批准**：第 2–8 課逐課確認 OCR、拼音、題目、音檔對應、答案政策與教材疑誤後，才開始該課教學設計。

## 11. Recommended Planning Framework／未來課程設計的推薦架構

每一課或每一個 50 分鐘單位可以使用以下骨架；時間與教材覆蓋依課次調整：

`能力結果／Can-Do`
→ `可觀察證據與成功條件`
→ `真實或模擬溝通情境`
→ `課前低負擔輸入與個人準備`
→ `第一次聽／讀：主旨`
→ `第二次聽／讀：細節、立場與證據`
→ `短時間語言支援：只處理高影響問題`
→ `教材受控／引導練習`
→ `有角色、資訊差、選擇與結果的溝通任務`
→ `每個學生的成段口語或個人證據`
→ `同伴／教師聚焦回饋`
→ `同一任務重做或換限制重做`
→ `陌生資訊、意外追問或新聽者的 transfer`
→ `出口卡與下一課回收`

設計時應同時做到：

- 保留教材必要的題目、音檔、內容順序與 35/35 coverage（第一課及後續批准課次）。
- 讓填空、判斷、選擇和跟讀成為理解／形式支架，而不是唯一終點。
- 把句式連到「學生要解決什麼問題、最後要說出或問出什麼」。
- 每個小組任務都保留個人可觀察證據。
- 每 50 分鐘保留一個明確學生產出；直接講解原則上不超過 5 分鐘。
- 以實際學生表現調整詞語負荷、支架、組合與重做，而不是假設全班程度相同。

## 12. AI Lesson-Planning Instructions

1. 先寫學生要完成的可觀察行動與證據，再選詞語、句式和活動。
2. 只使用已批准的 canonical source；對 `pending_review` 課次不要把 OCR、推測答案或舊輸出寫成教材事實。
3. 對第一課保留所有已要求的教材練習與活動，並維持可檢查的 coverage record。
4. 把語言形式和交際功能分開寫：句式是完成任務的工具，不是課堂終點。
5. 先安排課前快速預習與帶進教室的證據；未預習學生使用 3–5 分鐘 recovery route 後回到同一任務。
6. 聽力通常先抓主旨，再找細節、立場與證據；避免把每次播放變成逐句翻譯或聽寫。
7. 保留受控練習作支架，但要接上個人選擇、資訊差、聽者反應、任務結果或重做。
8. 每個 genuine task 都要明確寫出角色、溝通目的、資訊／觀點差、學生選擇、限制、聽者與完成結果。
9. 小組任務不能只評小組紙張；安排每位學生的提問、回答、短講、錄音或觀察證據。
10. 教師修補只處理影響理解、互動或任務完成的問題；修補後必須讓學生再說、再聽或再做一次。
11. 讓高價值功能跨課回收，例如介紹、比較、說理由、說因果、追問、澄清、協商與回應不同意見。
12. 逐步加入新聽者、意外資訊、不同限制或陌生情境，檢查學生是否能轉移，而不只背熟教材對話。
13. 評量優先看任務完成、可理解度、互動／修補、內容組織與理由／證據；不要把單一語法錯誤當作唯一能力標準。
14. 教材沒有提供答案的開放題，不製造唯一標準答案；示例、教師提示與教材答案必須分開標記。
