# 第一课《中国人的姓名》Visual storyboard

状态：已批准（2026-08-20）

本版对应当前 60 页原生 PPTX。内容顺序以教师手册和教材 section 为准；视觉设计使用已批准的教材式插画 contact sheet，不另换成企业发布会或产品宣传风格。

## 设计系统

| 项目 | 规格 |
| --- | --- |
| 画布 | 16:9；13.333 × 7.5 英寸；所有图片、形状和文字都在画布内 |
| 风格 | 教材式线稿插画；灰蓝细线；低饱和粉彩；浅色背景；留白清楚 |
| 图片 | 使用 ChatGPT／Chrome 已确认的 4×4 contact sheet；图片承担情境、比较、证据或记忆功能 |
| 文字 | 学生画面使用简体中文；只写学生当前要做的动作；不放教师备注、制作分类或内部编号 |
| 版式 | 依内容变化：分段页、图片加任务、听力题、对话重建、句式卡、资料交换、报告与回顾页分别设计 |
| 听力页 | 需要播放的页面都有清楚的音频按钮；同一音频的连续题目在一页仍清楚时合并，不同任务类型分开 |
| 材料页 | 需要活动卡、预习卡或其他材料时，投影片直接写材料名称；材料本身按活动分文件夹独立发放 |
| 课本 section | 分段页直接使用教材名称：听说（一）、词语理解、语句理解、语段理解、口语句式、文化知识、拓展练习、听说（二） |

## 页面判断标准

- 一页只要求学生完成一个清楚的课堂动作；同一音频、同一题型的连续内容可以合并，前提是后排学生能读清楚。
- 题目、活动卡和音频的名称直接写清楚，不要求学生猜 E 编号或寻找没有提供的卡片。
- 图片不能遮住文字，也不能超出投影片边界；图片框统一留出安全边距。
- 视觉素材不放英文、越南文、假 UI 或无法辨认的文字；中文文字由 PPT 原生文字完成。
- 教师提示只写入 speaker notes 和教师手册，不出现在学生投影画面。
