# 六乘六连线长度分析

分析建议六乘六采用四格连线。五格在几何上能成立，但简化模型中两队会阻挡时偏难。用户已批准游戏采用6–8边四格、9边五格；下表仅为六乘六模拟证据，并非七、八边或真实课堂的胜率验证。

| 六乘六规则 | 可获胜的连续线段 | 简单防守模型分出胜负 | 平局 |
|---|---:|---:|---:|
| 三格连线 | 80 | 100% | 0% |
| 四格连线 | 54 | 88.06% | 11.94% |
| 五格连线 | 32 | 16.46% | 83.54% |

线段数是精确计数：每个方向逐一列举，包含横、竖与两种斜线。边长n、连线k时，数量为2n(n−k+1)+2(n−k+1)²。因此六乘六四格连线有54段，五格只有32段，前者多68.75%。这些线段会重叠，不是独立获胜概率。

表中的模拟每种规则5000局。双方交替占一个空格，全部口语任务视为通过；优先完成自己的连线，否则阻挡对方下一步能完成的连线，若没有直接威胁则随机下。多个同优先选项随机选择，直到一方获胜或棋盘填满。四格分胜负4403局、平局597局；五格分胜负823局、平局4177局。“分出胜负”是任一队获胜，不是某一队的胜率。

敏感性检查：完全随机各10000局，六乘六四格平局0.49%，五格26.28%；另一种较积极的潜在线段评分模型各2000局，五格全部平局、四格全部先手获胜。结果高度依赖策略，不是最优博弈证明，也不是学生真实胜率。三格在积极模型中5步即结束，不适合避免太快结束的需求。

九乘九五格共有140段可连线；相同简单防守模型5000局，81.34%分出胜负。可以作为大棋盘保留五格的参考，但积极防守模型也可频繁平局，不能保证总有人赢。六乘六改四格、九乘九保留五格，是课堂设计建议；七、八边的最终规则还需单独决定或再模拟，不从未经测试的尺寸推出结论。

限制：未模拟学生词汇熟悉度、选词偏好、未通过后换队、时间限制或小组讨论；没有估算课堂分钟数。真实课堂要观察是否过早结束或互相堵死。若先手连续占优，下一局交换先手可改善公平性，但不改变本次概率。

可复现脚本：`qa/analyze-win-length.py`；完整计数与随机种子：`qa/win-length-analysis.json`。
