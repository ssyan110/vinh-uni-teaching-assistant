# 宫格连线游戏：唯一来源

这个文件夹只保留当前的全册游戏。请以线上版本为准：

<https://ssyan110.github.io/vinh-uni-teaching-assistant/>

离线入口是同一文件夹中的 `博雅准中级-全册词语连线.html`。首页先选择教材，再选择课次；准中级使用 `public/content/class-content.json`，初级拼音训练使用 `public/content/boya-elementary-i-l01-l03-pinyin.json`，教材目录为 `public/content/textbooks.json`。

初级起步篇只包含第一至三课的拼音发音题。标调位置题已删除；功能格只做找错、改正、朗读，教师确认后占格。

旧的单课 HTML 已移除；`teaching_games/nine-grid-game` 是旧通用模板，不是本游戏的来源。后续修改请从 GitHub `main` 的 `classroom-tools/nine-grid-lesson-01/` 开始，并在发布后重新检查上面的线上地址。
