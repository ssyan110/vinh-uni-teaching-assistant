# 博雅准中级全册词语连线

双击本文件夹的 **博雅准中级-全册词语连线.html**，用浏览器打开即可离线游戏。

1. 按“开始游戏”，勾选本次复习的课，可选一课、多课或全十二课。右侧会显示棋盘大小、词语数和例句格数。
2. 选择“课堂分队”，开始后由蓝队先行。画面上方用红／蓝色大字显示“轮到哪队”。每回合换一位同学，先独立读词并解释意思。
3. 教师确认通过后，点击该词占格，游戏自动换队。未通过时按“未通过，换队”，不占格；按错可用“撤销上一步”，恢复占格和原来的队伍。
4. 点到“例句”功能格，学生先读出 PPT 例句并解释意思，再用相同词语或句式说一句自己的话。教师按该队的“完成并占格”，或“未通过，换队”。“返回棋盘”保留原队伍与空格；30秒计时结束不会自动评分。
5. 6–8列棋盘连成四格、9列棋盘连成五格后，立即判胜并显示全屏八哥犬庆祝，无须再次确认。占格数不是学生成绩。误按时关闭庆祝后可撤销获胜一步。
6. 庆祝画面按“保存比赛结果图片”下载PNG，包含获胜队伍、课次、轮次、最后棋盘、占格数及记录时间，供教师另行登记加分。按“查看棋盘”或 Escape 关闭庆祝，再按“下一轮”继续。课堂每轮交换先手；重新选课开启新比赛时蓝队先行，电脑模式始终由学生蓝队先行。

单独第一课固定6×6，31词加5个例句格。其他选择自动选6×6、7×7、8×8或9×9，每轮至少7个例句格，上下左右不相邻（斜角可以相邻）。每轮最多74词，超出时平均分轮。词语先混合再分轮，整个分轮过程不重复。例句只来自所选课，用完后才轮换。

| 所选范围 | 棋盘 | 本轮词语 | 例句格 |
|---|---|---:|---:|
| 第一课《丽丽是独生女》 | 6×6 | 31 | 5 |
| 第二课《王红的一天》 | 6×6 | 29 | 7 |
| 第一课＋第二课 | 9×9 | 60 | 21 |
| 全册 | 5轮9×9 | 前4轮各65，最后64 | 前4轮各16，最后17 |

全册324词条（313生词、8专名、3成语）。词语使用宽格与大字，最多三个汉字一行，超过三个汉字分行（例如“西红柿／炒鸡蛋”）；“上（菜）”等短词括号不拆开；小屏幕可在棋盘内左右滑动，保持大字和完整词语。Tab可选择控件，空格勾选课次，Enter操作按钮，Escape返回棋盘。

功能题来自十二课在线预习 PPT 中明确标注的完整例句，共958个课内去重例句。第1–9课读取已批准位置的PPT，第10–12课读取现有草稿PPT；不改动原PPT或改变审批状态。不读取旧《中级冲刺篇 I》内容或旧版浏览器暂存。

图片保存：按保存后显示PNG预览并发起下载。若下载位置不明确，Chrome可按“选择保存位置…”并选“下载”文件夹；也可右键预览图片选“图片另存为…”。只有写入和关闭文件成功才显示已保存；取消或失败会保留预览。请重新打开最新离线文件使用更新后的保存方式。

来源记录见 `docs/lesson-01-source-map.md`，验证见 `docs/qa-report.md`。开发：`npm ci`，然后依次运行 `npm test`、`npm run validate-content`、`npm run validate-source`、`npm run build`、`npm run validate-offline`。
