# 华语口语练习题库：来源与使用说明

适用范围：跨年级华语课堂口语练习资源。按能力程度组织，不绑定任何年级、教材或开课实例。本文件是课堂练习资源，不是正式考试、成绩换算表或教材批准记录。

## 2. 选题原则

跨班级以“能否完成交际任务”为共同目标，按表现证据即时调难度。先让学生独立表达，再提供语言支架；熟练者需要新的听力／阅读输入、受众、限制或观点回应，不只是多说几分钟。小组表现不能代替个人口语证据。

HSKK听后重复可作为短热身或发音／听辨诊断，不作为口语能力主证据。主要练习安排应涵盖理解输入、互动回应、个人成段表达、反馈后重说与新情境迁移。

## 3. 程度对应：最低至最高

| 面板序 | TOCFL口语等级 | HSKK参考对应 | 课堂任务复杂度 |
|---:|---|---|---|
| 1 | 准备一级 | 初级起步 | 极短熟悉话题回应、基本信息表达 |
| 2 | 准备二级 | 初级延伸 | 熟悉生活问答，补充一项细节 |
| 3 | 入门级 | 初级至中级过渡 | 简短个人经验与简单情境描述 |
| 4 | 基础级 | 中级基础 | 连贯描述、复述并回答追问 |
| 5 | 进阶级 | 高级起步 | 说明观点、理由和例子 |
| 6 | 高阶级 | 高级延伸 | 多角度分析、解释条件与取舍 |
| 7 | 流利级 | 高级以上挑战 | 多轮回应、角色协商、整合材料 |
| 8 | 精通级 | 高阶综合挑战 | 综合多来源、评价证据、复杂论述 |

说明：TOCFL官方介绍口语为四等八级；HSKK只有初、中、高三级。上表是课堂选题的近似任务梯度，不是官方换算或成绩等值关系。各人可依具体技能在不同题目选择不同程度。

## 4. 题库：基础进入题（HSKK初级／TOCFL准备级风格）

每题先要求说完整句；能顺利完成者再加“为什么／举例／追问”。建议准备时间10–20秒，回答15–30秒。下列均为教师原创题。

| ID | 主题 | 题目 | 可观察表现 |
|---|---|---|---|
| A01 | 个人学习 | 你什么时候学习汉语？你常在哪里学习？ | 说清时间、地点，至少补充一个细节。 |
| A02 | 同学 | 你常和哪一位同学一起学习？你们通常做什么？ | 介绍人物及共同活动。 |
| A03 | 日常安排 | 你上课以前通常做什么？ | 按时间顺序说两件事。 |
| A04 | 兴趣 | 你喜欢做什么？你多久做一次？ | 说明兴趣和频率。 |
| A05 | 饮食 | 你最常吃什么？你喜欢自己做还是在外面吃？ | 作出选择并给一个理由。 |
| A06 | 校园 | 你最常去学校的什么地方？你去那里做什么？ | 说明地点、目的。 |
| A07 | 交通 | 你平时怎么来学校？大概要多久？ | 说明方式、时间或条件。 |
| A08 | 周末 | 这个周末你想做什么？和谁一起？ | 说明计划及同伴。 |
| A09 | 物品 | 你每天带什么来学校？你最需要哪一样？ | 列举并说明用途。 |
| A10 | 天气 | 天气很热或下雨的时候，你会怎么安排一天？ | 把天气和行动联系起来。 |

## 5. 题库：经验描述与看图／情境描述（HSKK中级／TOCFL入门基础级风格）

建议准备30–50秒，回答45–60秒。看图题可用任意课堂图片或教师绘制的无文字情境图；不要把他人受版权保护图片擅自复制入公开材料。

| ID | 题型 | 题目／提示 | 追问或升级 |
|---|---|---|---|
| B01 | 经验描述 | 说一次你和同学一起完成事情的经历：你们要做什么？怎么分工？结果怎么样？ | 如果再做一次，你会改变什么？ |
| B02 | 经验描述 | 说一次你迟到、找不到地方或错过约定的经历。后来怎么解决？ | 你如何确认对方收到新消息？ |
| B03 | 经验描述 | 说一次你买东西或点餐时需要询问、比较或更改的经历。 | 你最后根据什么作决定？ |
| B04 | 经验描述 | 介绍一次让你印象深刻的校园活动。 | 哪个部分最成功？为什么？ |
| B05 | 看图描述 | 图中几位学生在校园里讨论一张活动海报。请说说人物、地点、他们可能在做什么。 | 你会问他们什么，才能确认活动时间和地点？ |
| B06 | 看图描述 | 图中一位学生在公交站看手机，另一位学生拿着地图。描述情境并提出下一步。 | 如果公交车快到了，但路线还没确认呢？ |
| B07 | 看图描述 | 图中几个人在餐桌旁看菜单，其中一人不吃辣。描述他们需要确认什么。 | 请模拟服务员与顾客的一段问答。 |
| B08 | 看图描述 | 图中有人把包交给同学保管，旁边还有一张写着时间的纸条。描述可能发生的事。 | 哪些信息还不能确定？你会怎样问清楚？ |
| B09 | 影片／动作描述 | 教师现场做一个“找教室、问路、确认地点”的无声短动作。学生依顺序描述看见的动作。 | 不使用第一人称，补上先后顺序和结果。 |
| B10 | 事件复述 | 听教师读一段40–60字的校园小故事，记下人物、问题和结果后复述。 | 换自己的话说，并回答同伴一个细节问题。 |

## 6. 题库：互动、协商与信息差（通用课堂口语核心）

每个任务要有明确结果。教师给A、B学生不同资料，学生必须询问、回应、确认；结束时每人独立复述决定或说明依据。

| ID | 任务 | A／B资料或角色 | 完成条件／追问 |
|---|---|---|---|
| C01 | 约见面时间 | A周三下午有空、周五晚上有课；B周三有课、周五下午有空 | 商定双方都可行的时间与地点；复述确认。 |
| C02 | 找同学 | A要找一位会说越南语、周二有空的同学；B持有三位同学不同的语言和时间信息 | 找到合适对象并说明排除其他人的理由。 |
| C03 | 归还物品 | A捡到一本书，不确定主人；B有失物启事及两条不完整线索 | 先核对物品特征，再决定归还方式；不能猜测未给的信息。 |
| C04 | 校园路线 | A知道目的地名称但不知道路线；B持简图及两个地标 | 说明走法；A复述并指出一个仍需确认的问题。 |
| C05 | 点餐协商 | A预算有限且不吃辣；B是点餐伙伴，菜单有价格、口味和份量 | 选出双方可接受的餐点并核算总价。 |
| C06 | 礼物选择 | A想送实用礼物；B知道朋友兴趣、预算和不可接受的物品 | 选一份礼物，给出符合资料的理由。 |
| C07 | 天气改计划 | A准备户外活动；B看到天气信息并知道一项室内备选 | 商定原计划、替代计划及通知其他人的方式。 |
| C08 | 请求与回应 | A需要同学帮忙搬书，但对方有其他安排；B可提供两个不同时间 | 礼貌提出请求、说明需求、协商并确认。 |
| C09 | 查明迟到经过 | A听说集合地点改过；B收到一条不完整消息 | 用追问厘清谁、何时、何地改了安排；明确哪些仍未知。 |
| C10 | 采购核账 | A要买两件必需品；B持价格与运费表 | 按预算选方案并解释；不为凑优惠购买不需要的物品。 |

通用互动检查：有没有主动提问、回应对方信息、追问或确认、遇到误解时修补、最后说清共同决定。若任务只需背台词或单人轮流发言，不算完成互动证据。

## 7. 题库：成段表达与观点题（HSKK高级／TOCFL进阶高阶级风格）

本组适合能稳定完成基础任务者，或在共同主题中选择挑战卡的学生。建议准备45–60秒、表达60–120秒；允许用关键词提纲，不要求背稿。题目是教师原创，不是官方题目。

| ID | 题型 | 题目 | 必须包含 | 进一步追问 |
|---|---|---|---|---|
| D01 | 观点表达 | 大学生安排活动时，应该先按多数人的时间决定，还是尽量照顾每个人？ | 立场、两个理由、一个具体例子。 | 如果有人因此不能参加，你会怎样处理？ |
| D02 | 观点表达 | 学习外语时，课堂练习和自己看视频，哪一种更重要？ | 比较两种方法，说明适用情况。 | 你会怎样把两种方法配合起来？ |
| D03 | 观点表达 | 小组作业应该由组长分配工作，还是成员自己选择？ | 立场、理由、可能的问题和解决办法。 | 如果有人没有完成任务呢？ |
| D04 | 观点表达 | 朋友约好时间后迟到，什么情况下应该等，什么情况下应该重新约？ | 条件、理由、沟通方式。 | 你会发什么信息确认？ |
| D05 | 观点表达 | 买东西时，价格、质量和方便，哪一点最重要？ | 选择标准、举例、承认一种例外。 | 换成给家人买东西，你的选择会变吗？ |
| D06 | 观点表达 | 大学生是否应该参加社团或志愿活动？ | 说明好处、代价和适合的人。 | 如何判断参加活动不会影响学习？ |
| D07 | 方案提案 | 学校想让新生更容易认识同学。请提出一个活动方案。 | 目标对象、流程、时间地点、预期结果。 | 预算或时间减少时，保留什么？ |
| D08 | 对比分析 | 住在宿舍和住在校外，各有什么方便与困难？ | 两种选择的比较、个人建议和条件。 | 对第一次离家的学生，你会建议哪一种？ |
| D09 | 问题解决 | 小组讨论时总是同一两个人发言，其他人很少开口。你会怎么调整？ | 判断原因、提出两项做法、说明如何检查效果。 | 如果安静的学生不愿被点名呢？ |
| D10 | 立场回应 | 同伴说：“口语好的人不需要课堂练习。”你同意吗？请回应并举出实际例子。 | 明确回应、理由、例子，必要时承认对方观点的一部分。 | 你怎样区分“知道很多词”和“能在对话中使用”？ |

## 8. 更高阶选用卡（TOCFL流利精通级题型启发的课堂题）

这些题型要求更复杂输入与长时间论述。此处是教师原创的课堂题，不是官方样题；教师须提供短文本、角色资料或相反观点，不能只提高计时要求。

| ID | 改编题型 | 课堂任务 |
|---|---|---|
| E01 | 角色扮演 | 学生A是希望延后小组报告的组员，学生B负责协调且需要按时交作业。协商一个双方能执行的安排，并说明责任。 |
| E02 | 观点评议 | 听取同伴关于“课堂上能不能使用手机查词”的观点，先准确复述对方理由，再提出回应并维持自己的立场。 |
| E03 | 短文摘要 | 教师提供一段约100–150字的校园通知或短文，学生用自己的话说出主旨、两条重要信息和一项行动建议。 |
| E04 | 多方论证 | 学校要安排一次班级活动，给出预算、天气、时间和参加人数等资料；学生提出方案、回应另一方案并作结论。 |

## 9. 分层用法：同一题目，不同表现要求

| 路径 | 学生任务 | 教师提供／记录 |
|---|---|---|
| 支持 | 先用完整短句答题；可看关键词卡；同伴只问一个清楚的追问。 | 记录是否切题、关键信息是否正确、声音能否理解。必要时给句首或选项。 |
| 核心 | 独立组织一段表达，提问、回答、确认；根据反馈重说。 | 记录任务完成、信息准确、回应修补、组织流畅、可理解度。 |
| 挑战 | 使用新资料或受众，解释选择、比较方案、回应不同意见，最后复述决定。 | 观察能否综合输入、展开理由、适应追问并维持连贯立场。挑战不是单纯延长发言。 |

所有路径使用同一主题或核心任务，学生可依据当次独立表现换路径。HSK证书和自我评价可作为背景信息，不能代替现场口语证据。

## 11. 原题、改编题与原创题标记

每条导入共享题库时保留以下字段：`item_id, exam_family, official_level, task_type, source_url, source_version_or_access_date, source_status, classroom_adaptation, textbook_week, estimated_response_time, individual_evidence, copyright_note`。

- `official_sample`：官方页面／官方文件中的原样样题，只在许可范围内链接或课堂使用。
- `adapted_from_official_format`：只借用题型结构，题干或情境已改写；不得称为官方题。
- `teacher_original`：教师原创题。
- `pending_review`：词语范围、情境可行性、答案边界或来源尚待教师核对。
