# 第4–15课既有开放口语问题摘录

本表摘录与文字抽题有关的个人表达、选择和理由问题；完整PPT问句及教师备注另见本run的ppt-question-extract.md和ppt-text.json。听录音后的事实理解题、词语例句、角色卡里的问地点／时间等短问句不混作独立两分钟个人表达题。第11–15课当前实体课格式为HTML，因此另列实际格式，不称为PPT原句。

## 第4–6课实体PPT（逐页图像核对）

- 第7页：第一次认识一个人，国籍重要吗？为什么？
- 第11页：同屋最好不要是自己国家的人。你同意吗？
- 第15页：发现别人的东西，自己找主人比较好，还是交给老师比较好？
- 第19页：室友是越南人，还是外国人？你选哪个？为什么？

TBL-答案.pdf的第2页明确：同屋安排没有唯一答案，满足条件并说明理由即可。答案PDF中没有这些开放问题的统一标准立场。

## 第7–8课实体PPT（逐页图像核对）

- 第34页：你想约朋友周末一起出去。你想约谁？几点？去哪里？为什么？
- 第35页：集合地点在哪里最好？选一个集合地点，说明为什么对大家比较方便。
- 第36页：两个活动撞时间了：18:00朋友约你吃饭，18:30另一个朋友约你看电影。你去哪个？怎么跟另一个朋友说？要不要改时间？
- 第37页：周末计划：决定做什么、哪一天、几点、在哪里；为什么？
- 第38页：住在学校附近比较好，还是住在市中心比较好？为什么？
- 第39页：朋友常常迟到，你还会继续约他吗？为什么？
- 第40页：约朋友见面，地点近比较重要，还是环境好比较重要？为什么？
- 第41页：和朋友出去玩，应该先计划好，还是到了以后再决定？为什么？

## 第9–10课实体PPT（可编辑文字核对）

- 第5页：交通方式四种选择：你们选哪一种？为什么？（须搭配原页交通资料）
- 第10页：全组重新决定：不改交通方案？为什么？改交通方案？为什么？（须搭配原方案）
- 第16页：说说你常怎么付钱，为什么？
- 第23页：最后说：你们怎么选？为什么？（须搭配动物园任务）
- 第28页：从荣市市中心可以怎么去炉门海滩？哪里好？哪里不好？你会选什么？为什么？
- 第34页：欢迎会在哪里比较好？（须搭配地点条件）
- 第40页：第一次去朋友家，应该自己找路，还是让朋友来接？为什么？
- 第42页：朋友常常迟到，你还会继续约他吗？为什么？
- 第44页：买东西时，价格重要还是质量重要？为什么？
- 第46页：一起吃饭怎么付钱？应该AA制，还是一个人先付钱？你选哪个？为什么？为什么你不选另外一个？

## 第11–12课当前实体HTML

- 第3页：选时间去胡志明广场：几点？天气怎样？为什么？（须搭配天气听力）
- 第5页：看天气表，每人选一天：去哪儿、做什么、为什么？
- 第8页：上午天气怎么样？多少度？下午呢？下午去公园好吗？为什么？你想几点去哪里，做什么？（须搭配新天气听力）
- 第10页：选一个越南城市，查天气。介绍哪天去、做什么、带什么、为什么。
- 第11页：晚上八点常做什么、为什么。
- 第20页：周末和朋友出门，你会怎么安排？为什么？
- 第21页：周末去学校旁边买水果。朋友说“这么近，我们走路去吧。”你同意吗？下雨或买很多东西时，会改吗？

## 第13–14课当前实体HTML

- 第8页：两人讨论，推荐一件衣服，并说明理由。（须搭配价格／质量／预算表）
- 第13页：在荣市买衣服，你比较喜欢去服装店，还是在网上买？为什么？
- 第15页：农历春节的时候，台湾朋友在河内过生日，你想带他去哪里？送什么礼物？为什么？
- 第17页：生日的时候，你正在台北旅游，你打算如何过生日？请你安排一天的计划。

## 第15课当前实体HTML（既有材料，不推定已经上完）

- 第8–9页：试衣、说合不合适，最后决定买不买，说明理由。（须搭配衣服表）
- 第11页：两人各推荐一座城市，比较后选一座，介绍理由。（须搭配天气、交通、预算表）
- 第13页：河内半天怎么玩？选一个活动，说交通、几点回酒店、为什么。（须搭配活动表）
- 第15页：岘港下雨了，怎么办？改去哪里、几点回来、为什么。（须搭配活动表）
- 第19页：河内、胡志明市或岘港，哪里适合周末去？怎么去？可以做什么？有什么要注意？
- 第21页：介绍一个适合和朋友练中文的地方，说清可以做什么、为什么适合。商量周六几点、在哪里见面、做什么。

## 本次取用判断

单独抽文字题时不搬运依赖表格、音频或角色卡的信息题。价格／质量、守时和AA制题原本讨论负荷较高，未直接放入本次12题。保留选择＋一条具体理由，删去必须比较多项优缺点、反驳或连续完成多个交际任务的要求。各题具体引用与改写见question-review-20261026.md。
