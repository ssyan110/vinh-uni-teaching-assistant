# 中文口语自练

先选择学期与年级／题库，页面会标出题库类型、状态和题目数量。每次随机抽一道问题和一张六格图片，自己看题、准备和回答。

1. 按“开始抽题”，问题和图片会一起揭晓。
2. 按“开始准备”，有1分钟看题并记关键词。
3. 准备结束后，自动进入2分钟作答。先回答问题，再按顺序说图片里的事。
4. 准备时可跳过准备，直接开始回答；答完可提前结束。计时中也可暂停／继续。结束后按“再练一题”，重新抽出一组题。

一年级练习题库有30道问题和12张原创六格图片；二年级审阅稿有30道问题和20张六格图片。问题和图片分别随机抽选，可能重复。图片按1—6顺序讲述，页面提供一句开头提示；手机上可按“放大”横向查看。题目为自编练习材料，不是官方考试原题。

网站：https://ssyan110.github.io/vinh-uni-teaching-assistant/oral-practice/

页面使用本地HTML、CSS、JavaScript和WebP图片，可直接打开index.html离线练习。无需账号；没有录音、提交或自动评分功能。

GitHub Pages工作流程会复制页面引擎、`banks/` 下的题库脚本，以及 `assets/` 下的所有图片到九宫格构建产物的 `oral-practice/`；原九宫格入口仍在网站根目录。

计时逻辑检查：`node --test classroom-tools/speaking-challenge/exam/test-logic.mjs`。

2026-10-26：题干及提示依教师手动修改的30题总表更新。12张图片用 ChatGPT 图片生成重做为六格故事图，开头提示由题库文字准确显示，避免图片内文字错字；问题与图片仍独立随机抽取，每次各抽一题，共360种组合。


## 学期与题库

选择器从 `bank-catalog.js` 读取题库清单，并按学年／学期分组；每个选项显示年级、题库名称和状态。选中的题库会写入网址参数 `bank`，并保存在当前浏览器；复制网址可直接打开对应题库。抽题后选择器会锁定，准备或作答时刷新页面也会提示确认。浏览器不支持本地存储时，网址选择仍可使用。

新增学期、年级或同班不同考试时，按以下步骤登记一个题库：

1. 复制一份现有题库脚本，在 `banks/` 新增对应文件；文件名使用“年份-学期-年级.js”，例如 `2027-spring-year1.js`。替换完整题目和图片资料，数据不可留空；脚本将题目数据写入与清单 `id` 完全相同的编号：

   ```js
   window.ORAL_EXAM_BANKS = window.ORAL_EXAM_BANKS || {};
   window.ORAL_EXAM_BANKS['2027-spring-year1'] = { questions: [], pictures: [] };
   ```

   这行仅展示数据结构。复制题库后要填入完整的 `questions` 和 `pictures`，空数组无法开始抽题。

2. 在 `bank-catalog.js` 新增一条记录，填写唯一 `id`、`academicYear`（题库所属年份）、`semester`（该学期的短名称）、`semesterOrder`（同一年内按校历排序的数字）、`termLabel`（页面显示名称）、`cohortId`、`cohortOrder`、`cohortLabel`、`title`、`status` 和 `source`（内容脚本相对路径）。清单会按年份、学期顺序、年级顺序自动排列；同学期的多个题库会放在同一组。
3. 若内容脚本使用图片，把图片放在 `assets/` 下，并在题目数据里引用相对路径。Pages 工作流程会自动复制 `banks/` 中的题库脚本和全部图片，不用修改 `index.html` 或部署工作流程。
4. 保存后检查题库选择器显示的学期、年级、题库状态和实际题目数量。只有一个记录应设置 `isDefault: true`；旧的 `?year=1`、`?year=2` 链接继续由原题库的 `legacyYear` 字段兼容，新题库通常不需要这个字段。

选择器会跳过资料不完整或重复 ID 的记录，并在状态栏提示数量。题库 `id` 必须唯一，且内容脚本中登记的 ID 必须与清单完全一致；这样复制题库链接时，`?bank=题库ID` 才能稳定打开对应内容。同一学期、同一年级可登记多份不同测验。

当前清单含2026年秋季一年级口语练习题库，以及二年级期中口语审阅稿。审阅稿状态会在选择器中显示，避免与已确认的练习题库混淆。
