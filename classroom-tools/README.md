# 课堂共用工具

这里保存跨课次复用的教师课堂工具。它们不属于任何一课的 PPT、教师手册或不可变交付包，也不能反向覆盖 `lessons/*/20-approved/`。

## 工具入口与使用范围

2026-10-04 确认保留的两套系统：

- `student-tracker/`：学生管理系统；网页名称为「荣市大学_学生管理系统」。

旧桌面名称已停用；不要将学生管理系统原始码当作废弃工具删除。

后续新增入口如下；存在代码或本机验证不表示已部署或已在课堂使用，实际状态查各工具 README 与验证记录：

## 其他已保存工具

- `speaking-challenge/`：离线口语任务游戏。核心引擎与课次内容分开，适合投影、计时、随机抽题和全班发表。
- `nine-grid-lesson-01/`：第一课《听说》9 × 9 词语连线。可从下拉菜单选择听说（一）或听说（二）；一般格练词语，功能格固定 30 秒练造句、对话和改写。
- `presence-attendance/`：本机／局域网现场点名。结合短效动态 QR、现场码、个人 PIN、私有网来源、装置异常和可选定位覆核，降低校外代签风险；它提供多层现场证据，不宣称能绝对证明实体位置。
- `classroom-randomizer/`：离线课堂随机助手。管理本堂出席、随机分组、随机抽人、重复配对控制、发言记录和 CSV 导出。
- `live-check/`：本机／局域网即时投票与理解检查。学生用手机作答，教师控制开题、关题和揭示，可查看未作答名单、共同卡点并导出 CSV。

各工具独立启动，资料范围与真实课堂待测项目请见各自的 `README.md`。这些工具不写入课程权威教材目录。
