# 華語課堂抽問

給榮市大學華語聽說課教師使用的課堂抽問與口語評分工具。每堂課建立獨立紀錄；學生回答後完成本輪，尚未回答的學生仍會保留在可抽名單中。課堂資料以 Supabase 教學資料庫為主要保存位置。

線上入口：<https://classroom-randomizer-opal.vercel.app>

## 教師使用

1. 用 Chrome 或 Safari 開啟 `index.html`，先按「連線同步」登入教師帳號。
2. 從班級選單選擇 `LT_01`、`LT_02` 或 `LT_03`；名單會從教學資料庫載入。
3. 選擇教材與課次；目前《準中級加速篇 I》提供第 1–12 課。
4. 如本堂有加退選，可直接編輯名單；也可以匯入其他名單檔（CSV）。
5. 選擇這堂課是否計分。
6. 如需投影，按「開啟學生畫面」，把新視窗移到投影機。
7. 可搜尋姓名、座號或學號，也可篩選本輪狀態。學生主動回答時，直接按該學生旁的「自願發言」。
8. 需要隨機抽問時，提問後按「抽一位」；姓名揭曉後會依設定開始思考計時。
9. 學生回答後，填寫口語評分表；可以「儲存並抽下一位」，時間不夠時也可以先按「回答完成，稍後評分」。
10. 尚未回答時按「記錄未回答」，這位學生之後仍可再抽。
11. 完成本輪後，如需繼續，再按「開始下一輪抽問」。

學生畫面是獨立視窗，只顯示班級、教材、課次、輪次、目前抽到的學生、回答要求與思考時間。教師評分、備註、學生狀態、備份和課堂紀錄只留在教師操作台。

同一堂課可以直接切換教材或課次；切換只影響後續抽問，已保存的回答仍保留原來的教材與課次。按「學生成績」可以依班級與學生查看日期、教材、課次、分數和備註。

課堂紀錄會保存到 Supabase 教學資料庫；若課堂中暫時離線，會先放入本機待同步佇列，連線恢復後自動保存。課後可以下載課堂紀錄（CSV）或課堂備份檔，之後也可以重新匯入。開始新的課堂不會刪除過去的評分。

每筆回答紀錄會保留班級、日期、教材、課次、輪次、學生、評分與備註；不再要求輸入每一個小問題的題目。

自願發言與隨機抽問會分開標示。自願發言可照常評分和留存，但不會讓該學生離開本輪隨機抽問名單。

目前內建三班名冊：LT_01 27 人、LT_02 30 人、LT_03 14 人。名冊只保留抽問與評分所需的學號、姓名和座號。

## 評分說明

工具提供教師使用的課堂口語評分，不會自動判斷學生是否回答，也不會把單次分數換算成正式 ACTFL 等級。學生沒有回答時不會記成 0 分。

學生查詢中另外提供「形成性指數預覽」：品質 60%、隨機回答率 20%、自願參與 10%、證據完整度 10%。準備充分的自願回答每課最多計 3 次，原始紀錄不會被改寫；這個指數只協助教師整理課堂表現，不是學校正式成績。

全站字體使用同一套混合字體規則：中文由 `KaiTi`／標楷體系列顯示；越南文、英文、數字與其他拉丁字母由 `Times New Roman` 顯示。

## 開發者資訊

此工具是 `classroom-tools` 下的獨立頁面，不依賴教材課次 authority；它與 `student-tracker` 共用 Supabase 教學資料庫，但使用自己的抽問紀錄資料表。
