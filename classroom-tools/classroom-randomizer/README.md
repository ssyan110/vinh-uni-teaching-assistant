# 華語課堂抽問

給榮市大學華語聽說課教師使用的課堂抽問與原始紀錄工具。每堂課建立獨立紀錄；抽到學生後，教師只需記錄回答狀態或未回答原因，就能繼續抽下一位。這個工具不提供、不保存，也不同步分數；評分由另一個系統處理。

線上入口：<https://classroom-randomizer-opal.vercel.app>

## 教師使用

1. 用 Chrome 或 Safari 開啟 `index.html`，按「連線同步」登入教師帳號。
2. 選擇 `LT_01`、`LT_02` 或 `LT_03`；名單會從教學資料庫載入。
3. 選擇教材與課次；目前《準中級加速篇 I》提供第 1–12 課。
4. 如本堂有加退選，可直接編輯名單；也可以匯入 CSV 名單。
5. 提問後按「抽一位」；姓名揭曉後會依設定開始思考計時。
6. 學生回答後，選擇回答狀態與回答情境（可留在「未記錄」），再按「記錄回答並抽下一位」或「只記錄這筆」。不需要輸入分數。
7. 學生沒有回答時，按「記錄未回答」後選擇原因。一般未回答仍留在抽問名單；選「缺席」會保存缺席並停止抽問。取消不會保存。
8. 名單可直接勾選「缺席」，不必先抽到學生；取消勾選改為到課。缺席會同步到學生管理工具的本堂點名紀錄。學生回答後按「自願發言 +1」立即加記一次，不必先完成目前的抽問，也不占用隨機抽問名額。每按一次記一筆，誤按可用「返回上一步」撤銷。
9. 本輪所有可抽學生都完成回答後，按「開始下一輪抽問」。

學生畫面是獨立視窗，只顯示班級、教材、課次、輪次、目前抽到的學生、回答要求與思考時間。教師的原始紀錄、備註、備份和同步狀態只留在教師操作台。

同一堂課可以切換教材或課次；切換只影響後續抽問，已保存的紀錄仍保留原來的教材與課次。按「學生課堂紀錄」可以依班級與學生查看日期、教材、課次、回答狀態、回答情境與備註。

課堂紀錄會保存到 Supabase 教學資料庫；若課堂中暫時離線，會先放入本機待同步佇列，連線恢復後自動保存。課後可以下載原始紀錄 CSV、學生參與匯總或完整 JSON 備份；開始新的課堂不會刪除過去的紀錄。

每筆紀錄會保留班級、日期、教材、課次、輪次、學生、事件來源、回答狀態、未回答原因、回答情境、題目／活動（選填）、協助狀態（選填）與教師備註。這些是課堂原始紀錄，不是正式出席或成績資料。

班級名冊由教學資料庫管理；目前可用 LT_01、LT_02、LT_03 與大一新班 NNTQ1（28 人）。名冊只保留抽問與原始紀錄所需的學號、姓名和座號。

隨機抽問會在有其他候選人時避開剛才發言或剛被抽到的學生；只剩一位候選人時，會先請教師確認是否再次抽問。自願發言不影響隨機抽問資格。

2026-09-22 核准的 Apple 風格介面使用系統無襯線字體、白灰底與藍色主要操作。學生只顯示座號與姓名，不使用照片或頭像；此變更僅適用課堂工具，不修改教材字體規範。

課堂上方的「记录自愿发言」可隨時開啟本班名單。輸入座號（例如 `02`）、姓名或學號，按該學生的「＋1」即可記錄；面板保持開啟，可連續記錄不同學生，也可撤銷最近一次自願發言。原本抽到的学生、思考計時與未送出的回答備註均保留。缺席學生須先在名單改為到課，已結束課堂不能新增紀錄。

## 開發者資訊

此工具是 `classroom-tools` 下的獨立頁面，不依賴教材課次 authority；它與 `student-tracker` 共用 Supabase 教學資料庫，但只使用自己的抽問原始紀錄資料表，不寫入學生評量事件。

執行邏輯測試：

```bash
npm test
```
