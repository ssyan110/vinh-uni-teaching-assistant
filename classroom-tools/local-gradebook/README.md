# 教师评分（电脑与手机）

日常使用双击桌面上的「教师评分.app」，无需打开或保留终端窗口。评分系统会在后台运行，重复点击会复用同一个服务。

备用入口：双击 [启动教师评分.command](./启动教师评分.command)，浏览器会打开 `http://127.0.0.1:8765`。首次启动后保留终端窗口；按 Ctrl+C 关闭服务。之后再次双击即可继续，成绩保存在本机。当前 Mac 已具备所需 Python 和 openpyxl，不需要 npm、GitHub 部署或 Supabase。

1. 选择班级，点击“新增考试”。每次有考试才建立记录，不固定考试次数。
2. 输入考试名称和日期。选择教材及一课或多课，或选择“课外口语活动”并填写活动名称。
3. 选择总分 10 分、原表五项标准或自定义分项，填写本次任务要求。不同考试、不同年级分别保存标准。
4. 从左侧选学生，点击分数，记录备注，再点“保存并评下一位”。⌘＋Enter 也可保存并评下一位。
5. 在“成绩总览”查看本班各次成绩；点击某次成绩可修改。“考试设置 → 编辑考试”可修订名称、日期、课次和说明，已有成绩的评分标准不能被换掉。
6. 课后在“备份与恢复”下载完整备份，另存到 U 盘或其他设备。需要提交成绩时用“考试设置 → 导出本班 Excel”。

## 资料与恢复

- `private/gradebook.sqlite3`：本机成绩数据库，附修改历史。
- `private/backups/`：初始快照、每日开始前快照、每次保存后更新的当天最新快照、手动备份及恢复前快照。
- `private/seed.json`：首次导入资料。已有数据库时不会重新导入、覆盖成绩。
- `private/import-report.json`：名单核对、来源哈希与导入统计。
- `private/sources/`：三份原始 Excel 副本。

正常迁移电脑请使用 App 下载的 JSON 完整备份，并在新电脑恢复。不要在程序运行时直接复制 SQLite 文件；其 WAL 中可能仍有新记录。恢复前会自动另存当前资料，恢复会替换全部班级和评分记录。JSON 备份含评分数据与原表证据，数据库修改历史留在当前数据库，不随 JSON 转移。

手机使用：在电脑页面点击“手机评分”，用手机或 iPad 相机扫描弹窗里的二维码，即可打开评分页面；专属链接仍可手动打开。手机与 Mac 须在同一 Wi-Fi，或让 Mac 连接手机热点。Mac 须开机、不休眠，评分服务须持续运行。手机与电脑共用本机数据库，已有的旧页面覆盖保护继续有效。重启服务后访问链接会更新；换 Wi-Fi、热点或恢复联网后，无需重启服务；在电脑上再次点击“手机评分”，用最新链接连接手机。旧网络地址不会继续有效。服务监听局域网，非本机访问须用专属链接验证，链接不要转发。使用可信网络；此入口使用 HTTP，不提供公网或加密远程访问。校园 Wi-Fi 的设备隔离可能阻止连接。网页、字体和资源全部本地加载，评分时不需要网络。没有浏览器缓存作为成绩唯一保存位置。`private/` 被 Git 忽略，禁止提交学生资料或备份。浏览器中打开多个页面时，旧页面保存会被拒绝，须先重新载入。
