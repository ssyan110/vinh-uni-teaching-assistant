# 音频播放台

打开 `index.html`，先选教材和周次／清单，再勾选课次。默认是初级起步篇 I、Week 5、第11–12课听力测验v3（15段音频：6段课本原音、9段TOCFL官方音频；25题100分）。播放清单按15个单音频题组显示，共15个播放入口，每个题组对应一段不同音频。每题只对应其题目范围内的音轨；跨课题目会在勾选任一相关课次时显示。Week 4仍可在清单中选择。点击列表中的音段即可从头播放；上一段／下一段只切换，不弹播放次数确认。W04 的完整主持页面保留播放遍数和计时。

网页与音频使用项目内相对路径，可在本机离线打开；不要单独移动网页。中级冲刺篇 I 尚无登记清单，页面会说明。其他周测音频保留审阅状态；页面可播放不表示教师亲听或教室音响验收。

W07 现行v4审阅清单依难度播放49段音频、覆盖50题：第1–8题为TOCFL准备级，第9–20题为基础图片，第21–35题为图片与短对话，第36–50题为细节与信息整合；第40–41题共用第15课 Audio 15-11。题组顺序由该卷 `audio-manifest.json` 生成，不按音档文件名排序。当前仍未发布，教师亲听及教室音箱验收另记。

## 测验开启台

已登记的W04、W05清单会显示各自学生作答二维码及「放大二维码／投影」按钮。二维码使用 Google Forms API 返回的 `responderUri`，不是教师编辑链接，也不是本机服务器地址。学生手机需要联网，但不必访问教师电脑。勾选课次只筛选音频，不改变本卷题目范围。W05 v3 的表单题目、选项、答案键与分段标题尚待线上 Form 逐项读回；只有 `form-sync.json` 为 `SYNCED_VERIFIED`、版本一致，且 `verification.input_hashes` 中的题库与分段表 SHA-256 均匹配当前文件时，dashboard 才会显示 W05 学生链接和二维码；任一内容变更都会使入口重新隐藏。现存 `form-entry.json` 是旧版发布状态快照，不可据此认定 v3 已同步或发布。

`form-entry.json` 保存与测验 ID 绑定的链接及发布状态核对时间；后续新卷须登记自己的学生链接，不能复用 W04 链接。没有已登记入口的清单显示「此清单尚未登记学生作答入口」。发布状态为核对时快照，教师在 Google Forms 关闭作答后仍以线上状态为准。

二维码由现有 Python `qrcode` 库本机生成；`check-qr.swift` 使用 macOS Vision 解码验证。没有发送测试答卷或修改表单。

## 周测检查

选择本卷后点击「周测检查」，可查看现行题号与分值、题库答案键、教师答案卷、题组与音频映射、音频文件哈希、播放台文件与顺序，以及本地成绩表题目列。每项显示检查结果和下一步；页面及缓存不包含答案、逐字稿或学生成绩。点击返回会保留所选测验。

检查由 `assessment-management.json` 的现行目录及 `form-sync.json` 的版本目录生成，排除已被取代的测验。修改资料后，在项目根目录运行：

```sh
python3 classroom-tools/audio-dashboard/build.py
```

页面显示本地检查时间。若既有播放器构建因其他资料错误中止，可单独运行 `python3 classroom-tools/audio-dashboard/closeout.py` 刷新检查；此模式不核对播放台缓存。随后重新打开或刷新「周测检查」。

「本地检查通过」只描述列明的本地项目。Form／Sheets 只检查已保存的记录、输入哈希与证据文件是否存在，未实时连接线上；没有完整证据时显示「尚未核实」，输入哈希改变时显示「记录已过期」。教师亲听、教室播放和作答后台另列，不自动批准或发布。当前 W04 保存的六个 Section 对应十五段音频，会提示与现行单音频题组规则不一致；本功能不修改历史卷或作答。

读回记录也支持现有的合并证明：测验身份、题库哈希与 Form revision 必须一致，Form 与 Sheets 的不一致数必须都明确为整数零。音频库检查不替代 Sheets 题库逐题读回；旧证明缺少身份或其输入哈希与现行题库不同，会显示具体限制。
