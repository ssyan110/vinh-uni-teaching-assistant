# 第一課遊戲來源對照

來源權威：

`textbooks/boya-intermediate-i/source/derived/extractions/structured-lesson-01.json`

## 早期包

`lesson-01-early` 在完成「聽說（一）」口語句式後使用，範圍集中在：

- E01-003：發音、頭等大事、別扭、課堂處理的三至五句口語回答。
- E01-004：姓名讀法、姓名順序與名字意思。
- E01-006–008、T01-001：老常與「常殊」的聽力理解、理由與討論。
- E01-009–012、G01-001–004：總不能、才怪呢、到時候、話說回來的情境使用。
- V01-014–018：發音、頭等大事、別扭、糟、低調等課內詞語。

## 全課包

`lesson-01-complete-suite` 在完成第一課聽說（二）後使用，另外覆蓋：

- E01-016–018：起名兒公司、中文名字提案與調查報告。
- E01-019、E01-021、E01-023、E01-026：常見姓、稱呼、初次交往與誤會修補。
- E01-027–033、G01-005–007：不然、是……還是……、怎麼……怎麼……、姓名順序、單姓／復姓、歷史人物與對話體會。

遊戲中的情境是把已核准教材內容重組成口語任務；它們不增加學生未學的課堂語言，也不把教材開放題改成唯一答案。
