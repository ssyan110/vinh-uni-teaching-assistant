# 第一課口語遊戲套件

這是一套給榮市大學第一課《中國人的姓名》使用的離線課堂遊戲。教師用一台電腦打開後投影即可，不需要登入、學生手機、網路或本地 server。

## 開啟

雙擊本資料夾中的 `index.html`，用 Chrome 或 Safari 開啟。

首頁先選擇課程階段，再選擇遊戲。建議只選學生已經完成的階段：

- `第一課：聽說（一）後`：姓名、發音、理由與前半課四個句式。
- `第一課：全課口語綜合`：完成第一課聽說（二）後，加入姓氏、稱呼、文化比較和成段表達。

## 八種玩法

| 玩法 | 主要口語動作 | 建議時間 |
| --- | --- | ---: |
| 隨機口語挑戰 | 提問、回答、追問、全班發表 | 8–12 分鐘 |
| 情況有變 | 回應新限制、調整原決定 | 8–15 分鐘 |
| 開箱任務 | 抽一個短口語任務並完成 | 5–12 分鐘 |
| 團隊挑戰板 | 小組完成口語題，教師手動加分 | 10–20 分鐘 |
| 排名並辯護 | 排序、說理由、協商 | 10–15 分鐘 |
| 侦探／猜猜看 | 描述、提問、澄清、猜答案 | 5–10 分鐘 |
| 任務解決 | 分工、討論、面對限制、報告 | 15–25 分鐘 |
| 快速回憶賽 | 短時間口頭回收教材內容 | 5–10 分鐘 |

## 課堂原則

- 先讓學生完成溝通，再做短時間修補。
- 口語題由教師按任務完成、理由、聽者反應與可理解度判斷。
- 開放題不自動判錯，也不製造教材沒有提供的唯一答案。
- 團隊挑戰板的分數可以撤銷；不使用金幣、排行榜或答錯懲罰。
- 侦探模式顯示答案後，按「藏起來，開始猜」才進入猜題；答案不會留在學生畫面上。
- 每個模式都可以使用快捷鍵：空格計時、R 重置、N 完成並進入下一題、H 顯示提示、F 全屏。

## 內容與來源

內容包使用第一課 canonical source 的 `record_id` 追蹤教材依據；內容檢查位於 `qa/validate-content.mjs`。這個工具屬於 `classroom-tools/`，不會覆蓋 `lessons/boya-intermediate-i/lesson-01/20-approved/`，也不會取代第一課 PPTX、教師手冊或活動卡。

## 開發檢查

在本資料夾執行：

```bash
node --check app.js
node --check content/registry.js
node --check content/lesson-01.js
node qa/validate-content.mjs
```

教師課堂實測和後續內容調整應另行記錄，不把未實測結果寫成課堂已驗收。
