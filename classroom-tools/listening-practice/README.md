# 荣市大学听说课听力练习 MVP

这是当前课程项目中的独立课堂工具，不是 PPTX 生成器，也不取代 `course/`、`textbooks/` 或 `lessons/` 的教材权威来源。

## 现在可以做什么

- 学生入口：选课程、选班级、输入学生编号、选题组、播放音频、填写答案、提交。
- 教师入口：按课程、班级和题组查看提交次数、学生人数、提交次数和逐题作答记录。
- 班级管理：教师可以新增、改名、封存班级；已有提交的班级不会被删除。
- 题库：从 JSON 批量导入，不需要逐题修改网页。
- 数据：课堂共用模式保存在教师电脑的 JSON 文件；单机开发模式才使用浏览器 `localStorage`，两种模式都可以导出 CSV。
- 当前课班：配置了「听说三」及 3 个班级下拉选项（第1班、第2班、第3班）；之后可由教师新增选项。
- 云端：`supabase/migrations/0001_listening_practice.sql` 已按 BRD v1.0 预留长期资料结构，但尚未连接任何真实 Supabase 项目。

## 实际操作方式

### 课堂共用模式（推荐）

这种模式让学生手机和教师电脑看到同一份提交记录。教师电脑就是课堂服务器，课堂期间需要保持终端和程序运行。

在此文件夹执行：

```bash
npm install
npm run classroom
```

教师电脑打开：

```text
http://localhost:4173/#teacher
```

取得教师电脑的局域网 IP：

```bash
ipconfig getifaddr en0
```

如果没有输出，再试 `ipconfig getifaddr en1`。学生使用同一 Wi-Fi 后，打开下面的地址：

```text
http://教师电脑IP:4173/#student
```

教师入口是：

```text
http://教师电脑IP:4173/#teacher
```

教师可在「教师入口」复制某一题组的学生链接，再制作 QR Code。学生扫码进入后提交，教师按「刷新」即可查看记录和每题作答。

### 单机开发模式

如果只是自己在一台电脑上制作或测试，可以使用：

```bash
npm run dev
```

此模式默认使用浏览器 `localStorage`；同一题组在不同手机上提交时，记录不会自动汇总到教师端。正式课堂请使用上面的课堂共用模式。

课堂正式使用前，必须用三台以上手机同时测试音频、提交、重复提交、不同班级筛选，以及教师端查看作答。

## 教师实际操作

1. 打开「教师入口」→「导入新的题库」→「下载模板」。
2. 复制 JSON，按照每个题组的 `lessonKey`、音频 URL、题目和答案修改。
3. 确认教材来源、答案和音频状态后，选择 JSON 文件完成导入。课堂共用模式下，题库会保存到教师电脑的共用服务器。
4. 在「发布练习」选择指定班级，复制班级专用入口，再把链接制作成 QR Code；也可以选择「通用入口」。
5. 学生确认课程和班级、输入学生编号、听音频、回答并提交。
6. 教师回到「教师入口」，按课程、班级和题组查看记录，展开「查看作答」，或导出 CSV。

### 新增班级

在「教师入口」的「班级设置」区域新增下拉选项即可。学生端不需要输入班级名称，只选择下拉选项。系统会生成稳定的内部班级 ID，并在提交时同时保存课程 ID、课程名称、班级 ID 和当时的班级选项文字。修改选项不会改变历史提交；封存后不会再出现在学生选择项，但历史记录仍保留。

## 目前的数据限制

- 课堂共用模式的记录保存在教师电脑的 `data/attempts.json`，班级配置保存在 `data/classroom-config.json`，不是云端数据库；这台电脑必须持续运行服务器。
- 如果教师电脑故障、数据文件损坏或没有备份，记录可能无法恢复；课后应定期导出 CSV。
- 尚未连接 Supabase，因此目前不能让多台手机跨网络共用在线数据库。
- 目前本机教师入口还没有 Supabase Auth；不要把区网服务器公开到互联网。正式版必须接入教师登入、RLS 和服务器端学生提交接口。
- 内置题组只是技术测试题组；正式课次题目要从对应 `lesson_key` 的批准资料导入。
- 开放题目前标记为教师查看，不自行捏造教材没有提供的标准答案。

## Supabase 上线前的必要工作

1. 建立本课程专用 Supabase project。
2. 执行 migration，并为教师 Auth、学生身份、班级范围和提交入口建立正式 RLS、RPC 或 Edge Function。
3. 不把 service role key 放进前端；不让学生读取其他人的 attempts 或 responses。
4. 先用假数据测试三班、重复作答、题目版本、教师批阅和 CSV 导出，再接真实学生资料。
5. 将原始作答与分析摘要分开保存；分析资料必须去识别化，不能直接把姓名和原始答案当成公开教材。
