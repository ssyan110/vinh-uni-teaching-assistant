# 听力练习正式共享服务技术验证

日期：2026-10-04。范围：`classroom-tools/listening-practice` 软件，合成测试题组 `demo-textbook:lesson-01`；没有使用真实学生资料，没有修改教材 authority、批准或 release，也没有部署。

## 已实现并验证

- 保留 Node/Vite 架构，生产页面与 API 同源。默认绑定 loopback，生产必须明确配置 HTTPS origin；没有声称 Supabase/云已连接。
- 教师环境变量密码、8 小时 HttpOnly/SameSite 会话、生产 Secure Cookie、POST 来源校验、登录与学生身份节流。教师 API、名单、答案键与作答历史需教师身份。35 名合成学生共用代理/socket 地址可以分别登录。
- 不可预测练习码 + 名单中的稳定学生编号 + 私发进入码；进入码使用随机盐的 scrypt 摘要。学生只能查询本人所在练习和提交反馈。
- 客观题限定有明确答案的选择题，评分由服务器根据已保存题组计算。学生 payload 中伪造编号、得分不能改变服务器身份或得分。学生题组响应剥离正确答案，模板从教师认证 API 下载，不把答案或题库放入公开 bundle。
- 完整 lessonKey、来源状态与批准引用字段随题组版本保存；模板标为合成 demo。正式教材内容仍由教师核对实际批准证据；软件元数据不是新的批准。
- `id + version` 只追加、不覆盖；练习固定绑定版本及名单。客观错误统计按该练习全部尝试计算。未提交按该练习名单和稳定学生编号判断。
- 开放题没有虚构标准答案。未批阅分数 `null`，待批阅不会冒充 0 分。每次教师分数和反馈追加独立审阅记录，原作答保持不变，学生可查看本人反馈。
- 同一个学生、练习和提交编号的并发/网络重试返回同一回执；变更答案复用旧编号返回 409。明确重新练习才新增一次提交。关闭/过期限制新增提交，相同已存重试仍返回原回执。
- 新存储 `formal-state.json` 与 legacy JSON 分离；写入排队、临时文件 fsync、原子替换、替换前备份和单进程写锁。正常重启保持题组、提交和批阅；损坏 JSON 启动失败，不静默清空。静态与数据路径拒绝符号链接。旧数据没有自动迁移。

## 界限与待真实部署核实

单教师、单进程、持久化磁盘的小班托管方案；没有多实例、密码找回、离线自动同步或自动 legacy 迁移。真实 HTTPS 域名、代理、站外/加密备份、服务器崩溃恢复和真实外网手机访问仍待授权部署后核实，不能把本地浏览器测试称为线上课堂验收。服务器突然退出可能遗留写锁，恢复操作已在 README 明确要求先确认原 PID 已停止。备份会累积，运营人员须监控磁盘和确定保留规则。

README 含启动、环境配置、Caddy 同源 HTTPS 示例、操作流程及恢复条件。没有读取真实凭证、云密钥或学生个人资料。

## 最终复核补充

- 待批阅开放题的 CSV 分数导出为空，浏览器实际下载断言不含字符串 `null`。
- 浏览器拦截一次提交，在服务器已保存后丢弃响应，再修改答案并重试，触发 409 恢复页面。页面展示本人已存答案，并明确说明原记录不会覆盖。验证该阶段只有两次已存提交，冲突没有新增记录；点击“开始新一次练习（清空草稿）”后草稿清空，重新答题才产生第三次提交。
- 以上恢复流程与 CSV 下载通过已有 Chrome 的实际浏览器验证；生产 build 与 diff 检查通过，部署边界不变。
