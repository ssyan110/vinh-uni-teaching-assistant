# 跨学期教材流程复核（2026-10-27）

本次核对规则、课程需求、生产技能、审批与发布工具及其测试。二年级第 4—5 课的具体完成状态不在本次范围；原材料、批准和交付记录不因本次调整改变。

三项独立复核分别检查了规则冲突、工具执行路径和跨学期批准隔离。结论是：学期前先制作线上预习，实体课通常在上课前约一个月至一周按实际进度设计；具体时间可调整。各版本独立核对来源、审批和发布，其他课的 release 不再成为实体课的前置条件。详细流程和记录结构分别见 `canonical-workflow-contract.md` 与 `classroom-html-lifecycle.md`。

新版内容记录绑定学期、班级、课次、用途、版本、所用来源、来源核对报告、审阅稿及实际用户决定。OpenSlide 的成品和教师材料可以由一次明确决定共同批准；只有同时明确指定 release ID 并授权发布，才能由该决定覆盖发布。未要求的实体试教和音响测试记录为 `not_requested`；周测音频规则不变。测试使用合成数据，不生成任何真实批准或交付。
