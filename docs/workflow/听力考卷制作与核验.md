# 听力考卷制作与核验

适用于本项目的课堂测验、期中考和期末考。考试题量、时间、范围和题型按每次考试单独确定；已有考试版本、学生作答及发布状态不得因套用本流程而改变。

## 表单名称与说明

各年级、班级和学期的课堂听力测验沿用范本「一年级 W07 第4–15课累计听力测验」：`<年级> W<两位周次> 第<课次范围>课<必要的范围或题型>听力测验`。期中、期末等没有课次范围或周次时，按实际考试名称填写；需要区分同名测验时加入实际学期或班级。审阅稿保留「（审阅稿）」状态，正式与草稿不可混淆。Drive 文件名用相同内容，以半形连字符替代空格；内部 ID、原链接及历史记录保持不变。

笔试和口试合并的按课测验使用「<年级> 第<课次>课综合测验」，没有确认的周次不自行添加；教材与版本用于区分同名测验。其说明按实际保留笔试及口试的题数、分数和考场规定，不能套用纯听力测验的作答指示。

表单说明以「共25题，每题4分，满分100分。每段录音播放两遍。请先看题目，再听录音并选择一个正确答案。」为例，按实际题数、分值、播放次数和题型改写。填空、可留空、人工评分及其他作答必要条件须如实保留；来源、制作过程和审阅备注放在教师材料。教师专用且尚不可施测的草稿保留清楚的限制说明。不要为了套模板修改题目、作答、权限或发布状态。

## 1. 确定考试条件与语言范围

记录课程、班级、教材及实际已教学课次、考试日期、每班人数、考试时间、分值、播放次数、设备及答题形式。查阅已学教材的词语、句式和语法参考资料，再对照教材原文、教师记录和各班实际进度。数据库缺漏、OCR错误或未命中均不能证明学生没有学过；存疑内容回到教材与教学记录核实。不要只用主题或考试级别判断题目难度。

## 2. 选取可追溯的原题和原音

优先使用官方提供的 HSK 或 TOCFL 真题、样卷或模拟题及其配套原音。逐题记录考试类别、级别、试卷或辑数、原题号、题本及页码、听力文本、答案、音源及访问日期。分清真题与模拟题；不得把新编题称作官方原题。核对题目、图片、选项、听力问题和答案属于同一套、同一版本；保留原选项顺序和答案对应。需要改为简体或重新编号时，检查是否影响意思、音图对应或答案。

审查录音和选项中的关键字、语法、语速、信息量、干扰项及学生是否有机会学过相关语言。主题可以不同于教材，只要任务和语言适合。核对同卷内不同编号的实质重复，以及学生此前可能接触过的试题；登记风险。需例外使用超出已教范围的语言时，先交教师决定。

确认官方材料的教学、剪辑和使用条件。免费下载不等于取得所有剪辑、公开发布或计分用途的权利；用途不明时记录并核对，材料先留作内部审阅。

## 3. 音频制作

1. 优先使用官方对应题目的原音。对话题绝不由教师朗读或由单人代替多角色；没有可用的对应对话音频时，换题或继续寻找合适来源。若适合的官方题不足，用户授权时可参照题型新编，并用 Google AI Studio 等经授权方式生成不同说话人的对话音频；新编题和合成音频必须如实标记，不冒充官方原题或原音。
2. 独白也优先使用原音。确实找不到可用音频、无法换题且仍须保留独白时，才考虑教师朗读；先写明原因及考场操作，并核实对全部考生条件一致。
3. 如需裁剪，先保存来源与原文件，记录题号、裁切起止、格式、时长、文件哈希和播放次数。只移除题号引导、重复播放或无关等待，完整保留考生必须听到的对话、问题、口头选项及有效语义，不把原本听见的选项变成无法作答的缺失信息。每题单独核听裁切前后，防止截断、串题或重复。
4. 按本次考试要求组织每段播放次数和读题、答题间隔；不要默认所有来源原音的内部重复结构一致。检查播放顺序、响度、静音、杂音、文件解码和备用播放方式。

## 4. 考卷与教师材料

建立统一的题目清单，至少包含新题号、来源和原题号、题型、题本页、脚本页、答案及依据、题图、音频文件、播放次数、语言范围证据、风险、审阅状态。学生卷显示作答所需的图片、选项、题号和说明，不暴露答案；教师卷提供答案、依据和来源定位。原音包含口头题干或选项时，学生卷和考试说明必须与实际播放形式一致。

选择纸本、表单或课堂音频面板时，检查每题与对应音频、图片、答案和分值的映射。跨表单、成绩表及音频面板同步后，分别读取核对题数、顺序、链接、图片与答案；本地文件存在不代表线上已同步或发布。已有考试及学生结果必须保留，不擅自覆盖。

## 5. 完整核验与时间试跑

- 逐题对照官方题本、音频、文本和答案；检查唯一答案、选项顺序、图文清晰度与内容重复。
- 逐题教师亲听，确认人物、语言、问题、所有口头选项完整；音频能解码或哈希一致不能代替听觉检查。
- 对照全部已学教材和实际课堂记录检查关键语言；列出待确认项，不将推测记作已教。
- 用最终音频实际从发题、说明、看题、播放、两遍间隔、答题到收卷完整试跑并计时；课堂音响或等效设备另行检查。记录自动检查、人工试听、设备试播分别完成与否。
- 公布前完成教师内容审阅和该项目要求的批准、发布门槛；未完成时只标为审阅稿，不对学生开放或称为正式版本。
