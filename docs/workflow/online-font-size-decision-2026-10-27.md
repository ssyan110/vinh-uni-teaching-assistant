# 線上預習 PPTX 正文字級修訂（2026-10-27）

Adam 在本次對話要求今後的投影片主要內容最小 25 pt，明確舉出詞語的意思、用法、補充和例句。本專案將此數值用於新製作或修訂的線上預習 PPTX；詞類、目標、任務指令、題目、表格文字和作答提示也屬學生主要內容。標題可以更大。頁眉、投影片編號、教材頁碼與右上角純文字 Audio 標記是輔助文字，沿用該課原有的 20/23 pt 下限。實體課 OpenSlide 以 1920×1080 畫布的 CSS px 驗收，現行正文約 45–48 px，不將 PPT 的 pt 數值直接換成 CSS px。

舊規則把線上詞義和例句的 20–23 pt 當作可生產字級。這些數字只保留為已批准歷史成品的唯讀記錄；今後不能從第 25 課或其他定稿直接複製較小的正文尺寸。若 25 pt 放不下，先調整文字框、圖片、欄寬或分頁，再檢查渲染後的可見文字。

規則所有者：`AGENTS.md` 與 `PROJECT_REQUIREMENTS.md`；操作方法：`docs/workflow/online-pptx-lifecycle.md`、Boya PPTX reference；機器檢查：`scripts/build_scoped_online_pptx.py` 和 `tests/test_scoped_online_builder.py`。生成器預設把文字和表格當作主要內容。只有明確標記 `text_role: chrome` 且實際位置與文字符合四種輔助標記的元素，才能使用較小字級；假冒標記會在寫檔前被拒絕。

驗證：一年級下學期《初級起步篇 II》第 1 課的獨立試跑 V5 共 68 頁。原核准內容和插畫未改；307 個主要文字框均至少 25 pt，228 個輔助框保留其角色字級。PPTX 原生字級與文字、68 頁 PDF 可見字、實際 PowerPoint 開啟和暫時編輯後撤銷、版本 QA 與只讀 release plan 都已核對。舊版本、批准證據和主專案正式課次保留。
