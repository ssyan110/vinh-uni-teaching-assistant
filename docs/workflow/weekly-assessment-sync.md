# 一年级周测整理与同步流程

Adam 确认：2026-10-16。适用于本学期大学一年级 `2026-fall / boya-elementary-i`。每周制作、改题、改答案、调整 Section 或更换音频，都执行本流程。规则入口为 [AGENTS.md](../../AGENTS.md)，执行 skill 为 [boya-weekly-assessment](../../.agent/skills/boya-weekly-assessment/SKILL.md)。

## 1. 确定本次测验与唯一现行版本

- 从 [assessment-management.json](../../lessons/boya-elementary-i/assessment-management.json) 解析本次 `exam_id`、目录、完整 `lesson_keys`、Form ID 和现行版本。用户指定的卷优先；“下周”“最新”须对照实际日期、课表和登记资料，不能仅凭默认审阅指针或同一个 Form URL 判断版本。
- 核对本班实际程度、已教内容及教材来源。题数、每题分值、总分、播放次数以本卷决定为准。W05 的 25 题、每题 4 分、15 段音频是该卷配置，不自动套用所有周次。
- 修改前保存本地快照：Form 内容与 revision、题库／组卷／音频相关行、公式与现有作答数量。快照只作历史证据，不进入现行题库或 dashboard 默认入口。
- 整理一份现行题目清单和题组清单，作为所有输出的共同输入。记录题号、question_id、版本、题干、按顺序排列的选项、答案内容及选项位置、分值、来源、audio_id、播放顺序与次数。不得分别手改多套互不关联的题目。

## 2. 先核对内容，再同步

1. 优先使用适合本班程度的课本原音及可用官方音频；逐段核对实际内容、说话人、题干、全部选项和答案依据。出版社／官方原稿及原音为依据；自动转写只作辅助，不能凭无角色标记的转写猜谁说了什么。
2. 一段独立音频对应一个题组和一个 Form Section；同段音频的题目连续放置。不同题组不混在同一 Section，同一题组不拆散。身份信息／作答说明可单独成 Section。
3. Section 名称包含题号范围、准确来源类别和对应音频编号；独白不误称对话。题目本身只显示题号和题干，不显示 Audio 编号。dashboard 依相同题组顺序显示题号范围及音频。
4. 检查只有一个可辩护的正确选项、答案与选项顺序相符、题号连续、分值合计正确。保留来源编号，不按展示顺序猜音轨编号。生成语音须在另有授权的范围内使用，不自动替换现成原音。

## 3. 同一次工作同步所有位置

| 位置 | 必须一致的内容 |
| --- | --- |
| 本地题库与题组清单 | 现行题目、选项顺序、答案、分值、来源及音频映射 |
| 教师答案卷 | 题号、完整答案、分值、音频内容／说话人和逐题答案依据 |
| Google Sheets | 题库、组卷明细、音频库、测验总表及相关使用说明 |
| Google Form | Section 名称与顺序、题号、题干、选项顺序、评分键、分值、必填和作答路径 |
| 音频 dashboard | 本卷入口、正确 Form 链接、题组名称与顺序、题号范围、实际播放文件和播放次数 |

- 优先用现有结构化 API／工具同步 Form；更新前读取 revision，保留既有 item/question ID、Form ID 和作答，使用 revision 条件防止覆盖并发编辑。新增题目才新增 ID。不要用删掉整份 Form 重建的方式更新已发布测验。
- Google Sheet 沿用同一测验中心和共享题库／组卷／音频表；每次测验独立一个清楚命名的成绩 sheet，原始作答留在学期后台，成绩总览只列各卷统计。链接统一用可点击格式。
- 组卷明细由 question_id＋版本查题库。保留现有数组公式、验证规则及统计公式；当前模板 I:O 为公式展开区，不手写覆盖，先检查公式锚点与完整展开结果。
- 按实际登记目录重建 dashboard。现有构建器或检查若含 W04／W05 固定课号、题数或音频数，下周新增测验时先适配本卷配置；旧卷检查通过不能证明新卷完成。
- 已获准的整理、同步和修正直接执行，不重复索取同一授权；全新内容和发布仍按实际授权及项目 gate 执行。不伪造内容批准、教师亲听或课堂验收。已有作答时若评分键改变，记录受影响题号及复核／重评分需求，保留原始作答。

## 4. 删除被取代的现行资料

替代版本已写入并读回无误后，按本卷 exam_id、版本与 question_id 列出差异，再执行删除：

- 从现行题库和组卷明细直接删除被本卷新版取代的旧题行；不用隐藏、加“旧版”标签或另建线上 archive 分页来保留混杂题目。
- 删除不再被任何现行卷引用的旧音频库记录、失效映射和旧入口。同一题目或音频若仍被其他有效测验使用，保留该引用，不能按相似名称批量删除。
- 删除行时重新核对位置，按从下往上的顺序处理，避免行号移动误删。保留公式及其他卷的内容。
- 已实施的其他测验、学生原始作答、成绩、批准与修订证据保留。旧版本地快照可留在历史证据位置，不作未来生成输入。删除音频库记录不代表获准删除出版社原始音档或用户文件；文件删除仍遵守路径安全规则。

## 5. 逐题读回与完成条件

不能以“写入成功”、链接相同或构建成功报告全部完成。必须保存逐题比对结果与逐段音频证据：

- 从线上重新读取 Form 和 Sheet，与本地现行清单、教师答案逐题核对：题号、题干、全部选项及顺序、正确答案、分值、版本、来源与 audio_id。
- 检查所有 Section 及 dashboard 题组：名称、顺序、题号范围与实际音频完全对应；无遗漏、重复、跨组或错配。实际打开学生表单检查可见顺序和作答路径。
- 在 dashboard 逐段实际播放，确认文件可加载、播放时间推进、声音与本组题目及答案对应。文件存在／可解码只算技术检查；语义核对、实际播放、教师亲听与课堂验收分别记录，不互相代替。
- 现行题库和组卷的本卷题数等于清单题数；音频引用全部可解析；被取代的旧题 ID／版本不再出现在本卷现行资料。Sheet 无数组展开错误、查找错误或失效链接；其他卷、作答数量与成绩数据未受误改。
- 保存 Form revision、现行题库／题组输入 hash、同步时间、逐题结果、播放结果和清理数量。`form-sync.json` 的 `SYNCED_VERIFIED` 只在对应输入完成真实读回后设置；输入改变即须重新同步验证，不更新 hash 冒充通过。

最终报告列明本卷题数、总分、题组／音频数、同步位置、删除旧资料数量和实际核对范围。有未完成位置或无法播放的音频，明确列出，不能称“全部同步完成”。

固定顺序：**确认范围与版本 → 核对原音及答案 → 同步全部位置 → 读回替代版本 → 删除旧资料 → 全量读回及播放 → 记录结果。**
