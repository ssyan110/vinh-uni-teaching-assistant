# Teacher Read-Aloud PDF Standard

Status: active project default, 2026-11-04. Unless Adam specifies otherwise, deliver future teacher read-aloud scripts as a printable PDF using the Year 1 teacher-script style.

## Page design

- Use A4 portrait, white background, generous margins and readable Chinese type. Keep the Year 1 visual language: navy text, modest teal headings and rules, light neutral story panels, and a separate warm-toned teacher-answer panel.
- Start each activity with course/lesson, activity name, relevant classroom-slide pages, story title and source status (for example, textbook passage, teacher-created story, or adapted scenario).
- Keep the complete script visible and easy to read aloud. Include the practical read-twice guidance and a short `读法` section. Put answer cues under a separate `教师核对要点` heading; do not project or merge them with student-facing text.
- Prefer one activity/story per page when the full text and teacher notes fit at a readable size. If the content does not fit, continue it onto another page instead of shrinking it excessively or dropping text. Use page numbers and a teacher-only footer.
- Keep the source document or Markdown master intact. The PDF is a layout/export derivative, not a replacement for the source or its approval record.

## Source and content

Resolve the offering, textbook and lesson keys. Use the current source version and map each script to the actual activity and slide pages. Preserve the full read-aloud text, sequence, questions and answer basis. Do not invent plot details, convert a teacher-created story into a claimed textbook passage, or remove a supported answer nuance during formatting. Record any content edits separately from layout changes.

## Verification

Render and inspect every PDF page. Check that Chinese fonts render and are embedded, page order and slide references are correct, text is complete, there are no blank/near-empty pages, clipping, overflow or missing glyphs, and teacher answers remain clearly separated. Compare extracted PDF text to the source script. Technical QA does not imply teacher approval, classroom rehearsal or release.
