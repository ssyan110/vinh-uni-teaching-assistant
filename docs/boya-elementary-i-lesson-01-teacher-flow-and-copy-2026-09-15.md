# 第1课：教师流程与学生指示候选

教材：《博雅汉语听说·初级起步篇 I》“拼音和日常用语（一）”。身份：`boya-elementary-i:lesson-01`，开课实例：`2026-fall`。2026年9月21日学校第2–4节，共150分钟；第5节接第2课。教室B3_504。

这是供教师审阅的内容草案，不是正式教师手册、已批准storyboard或已生成PPT。具体教材覆盖及音频状态见[第1–3课分配表](boya-elementary-i-l01-l03-content-map-2026-09-15.md)。本稿不复制二年级版式中的长篇理解、成段报告要求。

## 学生完成后能做什么

1. 听教材录音，选择或写出相应声母、音节与声调；不会的项目能保留疑问并订正。
2. 三人练习时，能读出教材中的声音，让另外两人记录；听者能核对并指出哪里不同。
3. 看相遇、感谢、道歉和告别提示，能向同学说出合适的短句并回应。

这些分别提供听力理解、同伴交流和简短口头表达的证据。不要求零起点学生完成成段报告；不把一次听写正确率当作正式能力等级或学期成绩。

## 上课前准备

学生：教材P1–5、笔、笔记本。学校系统中的预习PPT已由其他老师制作，本任务只负责Adam使用的实体课PPT，不制作或修改预习版，也不以取得预习文件为前提。不假定学生已掌握拼音；用开场示范检查实际准备情况。

教师：先逐段核听1-1至1-9，逐题核对答案PDF，再记录音轨中的暂停位置；无这些记录时不可宣称已可直接播放上课。完成PPT后还要用实际PowerPoint测试每个音频按钮。打印或打开P1–5即可，不额外发一套重复听写卡。课前检查后排是否看得清23 pt文字。

初学者先看教师做一次“听—指—写—核对”：教师指教材所在题，播放一项，用笔写，再示范核对。动作演示承担操作理解，不能只投一段中文让学生自行猜测。需要越南文支架时先核对译文，不把未审核翻译直接放学生页。

## 三节课堂流程

### 学校第2节：声母，50分钟

| 分钟 | 教师如何带 | 学生如何做／完成检查 |
|---|---|---|
| 0–5 | 指出P1；示范听、指、写与订正。此段也作为未预习恢复入口 | 找到P1、笔记位置，跟做一次 |
| 5–15 | 播放1-1，先观察学生听后指认，再对实际易混音短示范 | 全部21个声母听读；圈自己不确定的音 |
| 15–23 | 展示题型，播放1-2；第一次独立选择，再听检查 | 做完8题，保留原选项并订正 |
| 23–35 | 播放1-3，分段暂停给书写时间；用已核实答案核对 | 完成15项，不会的留空并在核对后补写 |
| 35–45 | 示范三人角色；读者用教材，听者写笔记本。每人选读3个声母，然后换人；这是教师对教材开放任务的执行安排 | 每人都读一次、听写两次；把不同处圈出，核对后重读 |
| 45–50 | 针对巡视中最多的1–2类错误，播放对照再做 | 改正刚才的错音，教师简记仍需帮助的学生 |

### 学校第3节：单韵母、声调、拼写，50分钟

| 分钟 | 教师如何带 | 学生如何做／完成检查 |
|---|---|---|
| 0–7 | 1-4，按学生实际反应示范u/ü等差异 | 六个单韵母全部听读并指认 |
| 7–12 | 1-5，示范四声；解释轻声短而轻、无调号 | 模仿四声，找到教材调号 |
| 12–15 | 补充练习“听声音，选声调”：从P2带调单韵母中选6项读，读时不做提示手势；全班同时回答后核对并跟读 | 用1–4根手指表示听到的声调；听教师示范，改正再读。只选四声，轻声另按教材练习 |
| 15–18 | 1-6，按行播放与暂停；保留六个单韵母的全部四声 | 全部24个带调读音各跟读一遍；此处是首轮，不要求立即熟练 |
| 18–21 | 补充练习“听音画调，再跟读”：选本课易混的4–6项示范，先配手势，再撤掉提示 | 第一轮边听边比音高变化并跟读；第二轮先听再读。第三声手势用于单独发音，不概括所有连读情况 |
| 21–25 | 补充练习“你读，我来找”：两人用教材P2带调单韵母表；先示范读者不指答案 | A选一项读，B指出听到的项目；核对后换人，每人读3次。有分歧请教师示范再读，不把同伴判断当标准答案 |
| 25–43 | 1-7，分批作答、重听和核对 | 完成20题，找出自己混淆的是声母、韵母还是声调 |
| 43–47 | 借错项回到P3注意事项；只讲j/q/x与ü、i上标调两点 | 对照教材检查自己的写法 |
| 47–50 | 请学生重读自己刚改的一项，抽听 | 保留一项订正并重读，不追加新题 |

### 学校第4节：音节补全与日常用语，50分钟

| 分钟 | 教师如何带 | 学生如何做／完成检查 |
|---|---|---|
| 0–22 | 1-8，按教材四组8、12、6、13项停顿核对；先P3再P4 | 全部39项补全，包括声调；不是只示范前几题 |
| 22–30 | 三人活动同前：每人从已核对练习中选3项读，听者写；巡视 | 每人轮到读者，核对笔记并订正 |
| 30–38 | 1-9，六句全部播放、跟读；用动作提示感谢、道歉、告别 | 听读六句，再看提示说合适短句 |
| 38–47 | 教材P4–5四组问答，先示范一组，再两人完成全部并交换角色 | 每人都做开口者和回应者；教师抽听是否回应得当 |
| 47–50 | 请同桌不看答案完成一组简短交流；收回一个仍不确定的声音 | 说短句与回应；在书上保留疑问。告知下一节用P6 |

以上为初次实施预算。每节直接讲解累计原则上不超过5分钟；表中的示范、跟读和核对时段主要由学生听、读、写完成。少数错误在巡视时修补，不把整节改成发音术语讲解。

## 学生可见指示候选

下表是按教材任务组织的文案库，不代表已批准的投影片顺序或最终页数。每段只出现于相应任务；不把整张表放进一页PPT。中文简体、至少23 pt；零起点操作配教师示范。若投影需要拼音支架，须逐项核对后加入，不能靠缩小字塞下两种文字。

| 使用位置 | 学生可见文字 | 教材标记／声音 |
|---|---|---|
| 学习路线 | 听声母 → 读韵母和声调 → 听音节、补拼音 → 和同学打招呼 | 纯流程，可不标教材页 |
| 目标候选 | 我能听声音，选出或写出拼音。／我能读给同学听，并核对写得对不对。／我能打招呼、道谢、道歉和告别。 | 不把教师证据术语放学生页 |
| 课堂听读入门 | 打开教材P1。听一个，指一个，再读一个。不确定的声母，先圈起来。 | 教材P1；1-1，由教师播放 |
| 声母听辨 | 先看每题的声母。听录音，圈出你听到的声母。再听一次，检查答案。 | 教材P1；1-2 |
| 声母听写 | 听录音，写出声母。没听清的地方先留空。再听一次，补上答案。 | 教材P1；1-3 |
| 三人读写 | 三个人一组。一人选三个声母读，另外两人写在笔记本上。一起核对，再换一个人读。 | 教材P1；无音频 |
| 单韵母跟读 | 看教材里的六个单韵母。听一个，指一个，再读一个。 | 教材P2；1-4 |
| 四声跟读 | 看声调标记。听一遍，再跟着读。用手比一比声音的高低变化。 | 教材P2；1-5 |
| 带调朗读 | 按行听，按行读。六个单韵母的四个声调都要读。 | 教材P2；1-6 |
| 补充：听声音，选声调 | 听老师读。用1、2、3或4根手指表示你听到的声调。核对后，再读一次。 | 教材P2；教师选读 |
| 补充：听音画调，再跟读 | 听老师读，用手比出声音的高低变化，再跟读。下一轮，老师不做手势，你先听，再读。 | 教材P2；教师示范 |
| 补充：你读，我来找 | 两个人看教材P2。A选一个音读，B指出听到的音。核对后换人，每人读三次。不确定时，请老师示范。 | 教材P2；同伴选读 |
| 音节选择 | 先看两个音节哪里不同。听录音，圈出你听到的音节。再听，检查声调。 | 教材P3；1-7 |
| 音节补全 | 打开教材P3–4。听录音，补全当前这一组的拼音，包括声调。核对后，再做下一组。 | 教材P3–4；1-8；当前组另显示 |
| 音节互听 | 从刚才的练习中选三个音节读。另两人写在笔记本上。一起核对，再换人。 | 教材P4；无音频 |
| 六句听读 | 听一句，跟读一句。看老师的动作，说一句合适的话。 | 教材P4；1-9 |
| 两人问答 | 两个人一组。A读教材中的第一句，B回答。做完四组，再交换角色。 | 教材P4–5；无音频 |
| 本课回顾 | 和同桌说一句今天学的话，请同桌回答。在书上圈出一个还想练的声音。 | 纯回顾，可不标教材页 |

### 日常问答的教师示范，不冒充出版答案

相遇：A“你好！”B“你好！”；道谢：A“谢谢！”B“不客气！”；道歉：A“对不起！”B“没关系！”；告别：A“再见！”B“再见！”。对应教材四组开放回应。短语拼音正式进入PPT时从原页逐项核对；声调变化的系统说明留第3课，第1课先跟录音使用，不额外展开。

## 怎么知道做完了

- 教材覆盖：8道声母选择、15项声母听写、20道音节选择、39项补全都有学生作答与核对；21个声母、6个单韵母、四声、轻声、拼写说明都已实际处理。
- 每人参与：两次三人任务都有读者轮换，日常问答四组全部做并换角色。不用几个学生上台代表全班完成。
- 教师只记“已完成到哪题、常见混淆、需要的帮助、下次从哪里接续”，不生成综合分数。已覆盖不等于全班已熟练。
- 若22分钟无法完成39项补全，记下剩余组和预计时间，后续课顺延；先取消额外挑战，不删原题，也不压掉必要的听后回应。

## 六页样稿的内容选择建议

待逐课分流与本课文案确认后，选择六种代表性内容测试版面：学习路线、声母听辨、四声跟读、音节补全、六句用语中的情景示范、两人问答。这只是样稿测试范围，不是整课仅做六页；实际PPT仍须覆盖本课全部内容。

样稿验收看三点：后排可读且所有可见字有效字号至少23 pt；学生看完能开始并完成任务；音频按钮和教材页码对应正确。图片、音频实播、原题答案核对和教师审核仍各自记录，不由文案完成代替。

学校第3节调整为7＋5＋3＋3＋3＋4＋18＋4＋3＝50分钟。三项加练合计10分钟，融入原来的四声教学与带调跟读18分钟中：四声示范5＋听选3；全部24项首轮跟读3＋手势跟读3＋同伴互读4。学校第2、4节各50分钟不变，全课仍150分钟。

备用“错音再挑战”约3分钟，仅在实际进度有余裕时做：选当天易混的一组，先听选、再跟读、最后独立读。没有余裕则不做，不挤占教材原题、订正或日常问答。如果首轮24项跟读实际超过3分钟，优先保留完整跟读与必要纠错，记录超时；不能把时间加总正确当成课堂可行性已验证。

可观察的变化：原“同伴指一项，另一人读”改为“读者不指答案，听者找出听到的项目”，让听者也必须听辨；各角色完成次数写明。教师巡视用于发现误读并提供准确示范，不计算综合分数。
