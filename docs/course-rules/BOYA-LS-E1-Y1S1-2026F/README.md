## 第四课起的制作逻辑

任务结果决定课堂顺序，教材清单保证内容覆盖。公共PPT按以下功能编排，页数随内容，不把每个环节限制为一页：

1. 本课结果与学习路线：学生知道最后需要找到谁、确认什么或完成什么。
2. 短检查：判断已会内容和需要帮助之处。
3. 必要听力与语言支持：提供完成本轮所需输入、词语、可选表达。
4. 第一轮任务：显示共同规则、材料名称和完成条件；私有资料分别发放。
5. 结果核对与语言反馈：检查结果，处理两三个实际语言问题。
6. 换条件再做：更换人物、物品或限制，必须重新听取、回应与确认。
7. 个人检查：独立听力答案或短问答；小组完成不代表每人完成。

核心任务必须有结果、交流必要、听取回应、表达选择、人人参与、核对依据和改条件重做。照完整台词演出或指定词句计数不能代替任务结果。

全班完成同类核心任务；支持者使用图片、必要拼音与半句，熟练者处理额外信息、矛盾和限制。一套公共PPT加可选支持／挑战即可，不生成三套完整PPT，不按自报HSK永久分组。每周在200分钟内留10—15分钟集中支持；所有人有轻量个人证据，教师轮换重点观察约7人。

每课逐项登记词语、重点句子、教材练习、听力、任务功能、个人证据与后续复现。可分配到课前接触、课堂核心、按需补练或后续复现；不得无去向地删除教材内容，不默认每一道机械练习都在课堂齐步做。来源区分 textbook_verified、original_task、teacher_reported、external_method_reference、pending_verification。

## PPT与配套规则

- 沿用本册白底、16:9、KaiTi／Times New Roman和已确认四步横向流程图的布局，只替换本课步骤及插画。所有学生可见文字有效字号至少23 pt；不采用附件12 pt底线。
- 教材练习页保留“练习n-n＋教材印刷页码”；无编号项目保留原题名，不自造编号。新增任务若教材没有说明，投影须写清动作、材料和完成条件，不能只留教师备注。
- 私有角色信息不得同时投影；共同规则可投影。每名学生每次200分钟原则上最多一张A4记录材料，优先单面；角色资料与记录合并或使用可回收卡，超量须说明具体发放需要。黑白仍可辨认。
- 学生中文使用简体。既有本册越南文流程图按已确认例外保留；新增双语任务说明列入逐页文案待决项，不据附件自动扩展语言政策。
- 教师时间、答案依据、支持条件与纠错提示写备注／教师材料。公开画面不提前泄露本轮答案。
- 音频须核实文件、课次、语义与播放；未取得时可准备完整的教师原创固定朗读稿，标明来源、读几遍、停顿、问题和答案依据，不冒充原书录音。第四课现有音频manifest缺失记录不能因本规则而改为通过。
- 个人表现与小组成果分开；无证据记NE，不等于0。附件观察量表不自动形成课程成绩、总分或系统评分功能，正式比例待学校／教师明确。
- 先规划全学期映射，再制作近期周次；不把旧50份PPT计划当作硬性生产配额。线上／实体分流和具体交付仍逐课确认。
