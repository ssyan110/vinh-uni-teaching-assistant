## 查找与操作

- 测验总表是入口。学生作答、查看题目、播放音频、查看成绩采用同类文字与原生HYPERLINK公式。教师编辑／评分与原始答卷另有入口。系统编号列默认隐藏。
- 成绩总览只显示每卷提交数、作答人数、待复核数、补录数、当前均分、已批改数、最终均分和本卷成绩链接。学生明细只放对应成绩表。
- 每卷成绩表自动按exam_id筛选系统数据，保留所有提交，并显示学号、姓名、提交时间、当前分数、满分、得分率、批改状态、记录类型、原分数、备注及原始答卷链接。没有答卷时显示尚无作答。
- 题库以question_id＋版本为主键，组卷以exam_id＋题序为主键，音频以audio_id为主键。追加题目／音频行，沿用预设格式；历史版本不覆盖。

## 数据流与成绩边界

原始答卷文件 `1659bS7DT-Ko-jJoUeEgpt3RnI2yTQ4dVG9Bg6Lt-k6c` 每卷独立标签。后台答卷索引登记满分、Form、gid及身份和分数列号；汇总输出由公式合并。主中心隐藏系统表用IMPORTRANGE读取，各卷成绩表按测验编号显示。Google重算可能有延迟。

原始答卷不得排序、删除或插入中间行；attempt_id由测验编号及原始行号组成。重交独立保留，教师决定采用哪次。历史补录标待核验，不混入正式作答人数。当前未接正式应考名单，不据作答人数计算缺交。均分按正式提交计算；最终均分只计已批改记录。

批改在Form逐题完成。后台批改记录保存教师核定总分、状态、备注和时间；不自动回写或公布Form成绩。派生的各卷成绩表不直接输入分数。
