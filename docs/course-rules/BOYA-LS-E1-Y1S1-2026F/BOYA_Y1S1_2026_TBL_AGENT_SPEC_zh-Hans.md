## 3. 教学模式：任务主导，教材保证覆盖

本班采用**教材约束下的任务型听说课**：先确定学生要完成什么事情，再安排理解输入、尝试交流、结果核对、语言反馈和再次完成。教材规定需要覆盖的主题与语言，课堂不以“先讲完所有生词和语法、最后有空才做活动”为默认流程。

任务型活动主要让学生为获得信息和完成结果而使用语言；单纯展示指定句型的练习不等于任务。[R1] 本方案保留必要的短语音、词汇和语法教学，但区分它们与核心任务。它不是声称所有语言都只能临时生成的纯开放课程，也不把任务退化为课末点缀。

### 3.1 每项核心任务必须具备什么

| 检查项 | 本班的具体要求 |
|---|---|
| 结果 | 找对主人、确定时间地点、完成订单、解释并改正误会、确认未完成事项等。不能只写“练习口语”。 |
| 交流必要 | 学生掌握不同信息、有不同需要／偏好，或必须通过比较与推理作决定；不能不交流就从一张公开表上抄完全部答案。 |
| 听取与回应 | 任务结果至少依赖听到的一项必要信息；回答要回应对方，不只是各讲各的。 |
| 表达选择 | 可用已学语言和可选句框，不强制每人照同一完整台词说，不用指定词句数量作为任务成功的唯一条件。 |
| 人人参与 | 每人有必要信息、提问和回应责任；不能只有组长说。 |
| 结果核对 | 教师有条件表、答案依据或可接受结果范围；开放任务不必只有一个答案。 |
| 改进 | 获得反馈后换搭档、数据或条件再完成，不能仅把同一份稿子重新念一次。 |

| 活动 | 在本方案中的定位 |
|---|---|
| 拼音听辨、词语配对、句型替换 | 诊断／短练习，服务后续任务。 |
| 照完整台词角色扮演 | 受控练习，不单独当作核心TBL。 |
| 用6个词、4个句式编一段对话 | 形式练习；不是默认的主任务成功标准。 |
| 持不同课表与地点资料，约成见面 | 有信息差与可核对结果的任务。 |
| 自由聊吃什么 | 话题交流；加入顾客需要、可用菜品及最后订单，才形成清楚的任务。 |

### 3.2 一个任务循环

**看懂结果 → 获得必要输入与少量帮助 → 第一次完成 → 准备并报告结果 → 处理真实语言问题 → 改条件再做 → 个人检查。**

循环参考任务准备、执行、计划、报告、语言分析和后续练习的框架。[R2] 本方案的时间分配、分层与改条件重做是本班设计，不是引用来源规定的固定分钟数。报告优先对另一对／另一组说，不让7组轮流长讲占掉整节课。

## 4. “完成25课”必须如何记录

**完成教材覆盖，不等于每页机械练习都在课堂做，也不等于每个学生已熟练掌握全部内容。**本方案压缩已掌握内容的重复教学，不压缩为只保留课名。

| 每课要求 | Agent交付中的证据 |
|---|---|
| 内容清点 | 列出教材词语、重点句子及必要说明；每项都有来源和处理方式。完整词语清单需在制作该课材料时从正文逐项核对。 |
| 不遗漏 | 所有教材词语至少有意义理解、辨认或情境接触安排；核心交际表达有实际运用。不能把不熟项目永久放进“以后再说”。 |
| 分层目标 | 分清全班核心运用、需要者补学、熟练者延伸；不是要求基础学生第一遍就熟练使用所有词。 |
| 听力 | 至少一项意义理解活动，能查主旨／关键信息；有可核对材料和答案。 |
| 任务运用 | 核心交际功能进入任务，每个人有机会听取、提问和回应。 |
| 语言反馈 | 必要的发音、词语、结构或语用处理，有实际问题或教材覆盖依据。 |
| 个人证据 | 独立听力答案、观察到的问答、简短口头回应或合适录音；小组成果不能代表每个人。 |
| 后续复现 | 记录在哪一周再用，并跟踪未稳固项目。 |

同一任务可以整合两课，但覆盖表必须分别说明两课的输入、交际功能和证据。已学过者仍参加共同任务，只免重复基础讲解。新词／新表达确有需要时照常短教，不把“任务型”理解为“不教语言”。

第1—3课以语音和日常应答证据记录；不要求每项音韵规则都人为包装成大型任务。拼音之后仍在真实听说中短复现。

## 7. 每周四节的执行安排

### 7.0 常规200分钟框架

常规双课周使用T1—T4；W01、W02、W07、W13、W14用其专门安排。下表环节时长是初始设计，可在本周200分钟内按表现调整，但每节实际计划必须合计50分钟。

| 模板 | 环节及分钟 | 总计 |
| --- | --- | --- |
| T1｜输入与小任务 | 旧目标提取5＋本课意义听力10＋必要帮助5＋双人小任务15＋反馈8＋换资料短重做7 | 50 |
| T2｜第二课输入与小任务 | 连接上节5＋本课输入12＋必要帮助5＋双人小任务15＋语言聚焦8＋个人检查5 | 50 |
| T3｜主任务 | 结果与规则5＋分层准备7＋主任务20＋准备并向另一组核对结果10＋反馈8 | 50 |
| T4｜改进与迁移 | 必要语言补练8＋加入新条件再做18＋同伴结果核对8＋个人退出检查10＋下次准备说明6 | 50 |


双人／小组意义交流机会每个常规周以约80分钟以上为设计目标；它包括听取和回应，不表示每个学生连续说80分钟，也不是研究规定的达标线。老师讲解、等待轮流报告和独立抄写不计入。

前置帮助只提供开始任务所需的少量支持；不把整个T1、T2变成词汇／语法讲授。听力也可以是完成辨认、排序、选择的小任务，而不是必然先做一整张题再允许开口。

|---|---|
| 必须听取 | 姓名／姓氏、身份或国籍、人物关系、物品和主人。不能只靠图片颜色配对。 |

这一周若基础缺口较多，优先保留第4—6课输入和最小任务，不用“接待中心”外包装增加阅读量；第1—3课补强采用短点练，不另占整周。

### W13｜12/14—12/20｜全册补强与200分钟缓冲

| 节次 | 正常进度时的安排 | 有进度损失时的安排 |
|---|---|---|
| 49 | 10分钟缺口定位＋15分钟分层支持＋15分钟小任务＋10分钟重做检查 | 用50分钟补尚未完成课次的输入与关键运用。 |

| 51 | T3式综合任务：餐饮、改约、时长、活动与准备核对 | 用50分钟补后半册必要任务或复现；保留每人说话。 |
| 52 | 15分钟格式演练＋15分钟反馈与短重做＋10分钟个人缺口检查＋10分钟覆盖清单收束 | 优先完成缺口，但仍留简短评量格式说明；更新实际覆盖状态。 |

这是200分钟实际缓冲，不是额外的第五节。未停课时用于迁移和个别补强；发生进度损失时，综合活动规模随之缩小。不能把同一周同时算作200分钟补课、200分钟综合任务和200分钟预演。

期末预演只练形式，不提前公开正式数据或答案。没有录音设备也可用个人纸面听力和教师现场问答取证。

| 节次 | 50分钟内／连续两节的安排 |

| 54—55 | 两节共100分钟：组织说明10＋14对口头评量各6分钟84＋机动6。 |
| 56 | 共性反馈10＋改进后再完成一轮任务20＋个人进步与下一步10＋归档与未结项目10＝50分钟。 |

每对6分钟内：两人各约1分钟个人简述，共2分钟；即时互动约3分钟；转换和评分记录约1分钟。个人简述可依据陌生但难度合适的图卡／资料，不靠提前背稿。其他学生做独立整理或未涉及正式试题的复习，不围观、拍摄或看到正在使用的题卡。

若学校考试另有日期，只调整本课程周次映射和分钟预算。28人为容量估算；27人到课时，单人可与教师互动，或三人轮换并调整时段，确保每人机会相近。不能临时给28人逐个安排10分钟口试却仍写只占一节。

## 8. 分层：同一任务结果，不同支持和交流要求

不按自报HSK长期贴标签，不叫“差组／好组”。学生在某主题走挑战版，在另一个主题也可以用支持版。利用同一素材提供帮助与延伸、按需要切换配对方式，是混合程度教学的一种做法。[R3]

| 维度 | 支持版 | 核心版 | 挑战版 |
|---|---|---|---|
| 任务目标 | 完成同一类核心结果 | 完成同一类核心结果 | 在额外信息或条件下完成同类结果 |
| 输入 | 图片、少量词语、适当分段／重复 | 正常资料与完整关键信息 | 同主题新增信息、关联或矛盾消息 |
| 准备 | 半句提示、先双人试说、必要时简短母语规则帮助 | 关键词，不写完整台词 | 规划澄清、比较和替代策略 |
| 输出 | 提供自己的信息，提出必要问题，作出可理解回应 | 独立交换、核对信息并报告结果 | 追问依据、回应变化、修复误解，表达更准确得体 |
| 反馈 | 每轮抓一到两个阻碍沟通的问题 | 理解准确性与独立互动 | 语气、逻辑组织、精确性和更自然的协商 |
| 禁止 | 只抄写、一直记录、旁观、被取消任务资格 | 只背标准对话 | 只是多做十题、只是更快音频、整节替别人完成 |

### 8.1 把教师时间安排进去

每个常规周在已有200分钟内安排一次约10—15分钟的集中支持窗口，可由T1/T2短帮助和准备时间组成。教师带基础需要者，其他学生做有明确结果的独立或挑战输入；之后教师必须也给挑战学生短反馈。

按28人可先14对再7个四人组。每人持有必要资料，每轮改变角色；不能固定让熟练者当发言人、基础者当记录员。挑战输入替代机械练习，不全部作为额外作业叠加。

每周教师重点观察约7人，四周覆盖一次28人，再加急需帮助者；所有人留下轻量个人证据。不得设计成教师每周必须逐条精批28份长录音才能维持课程。

### 8.2 用表现决定支持，不用“学过没有”决定跳课

短检查同时看三件事：**听懂关键意思、独立问答、换一点资料后仍能完成。**能完成者免重复基础说明，进入挑战输入；需提示者保留句框；尚不能进入者先简化信息并带练，再参加任务。

不得只凭10题拼音分数给学生永久分层。某一轮完成并不等于长期掌握，需在不同资料和时间点再观察。[R4] 常规任务难度过高时先减少条件数量，而不是首先降低全班每周课次或取消低程度学生发言。

### 8.3 新生课堂沟通支持

教师可在PPT固定角落提供：“请再说一次。”“请说慢一点。”“我听不懂这个词。”“你的意思是……吗？”支持版只取当前能用的两三句。必要时用简短越南文澄清任务规则，但核心交换用中文。此项为本课程设计，不自动改变其他年级语言政策，也不新设惩罚制度。

## 9. 听力、词语与课前课后材料

| 项目 | 必须执行的材料规则 |
|---|---|
| 听力功能 | 每周至少包含意义输入和同伴信息交换；不能全部只测拼音，也不能全部改成自由讨论。 |
| 先听什么 | 先理解情境／目的，再抓完成任务的关键信息；看全文后的正确回答不能记成独立纯听力表现。 |
| 教材录音 | 核实文件可播放、课次匹配、片段范围与答案。只有二维码时，不编造文件名、时间戳或听到的内容。 |
| 无音频替代 | 用固定教师原创朗读稿，明确角色、读几遍、停顿、题目、答案与依据；不冒充课本录音原文。无需强制寻找网络音频或付费语音服务。 |
| 模型与答案 | 可给相似情境示范，但不要先提供本轮全部任务答案。完整示范台词不成为所有学生的唯一说法。 |
| 词语清点 | 每课完整核对，再区分必须运用、理解辨认、后续复现。每项都有去向，额外词语另标“教师补充”。 |
| 形式处理 | 任务后优先处理两三个真实问题，并补齐本课必要语言；保留短练习，但不让句式计数取代沟通目标。 |
| 拼音 | 前3课后根据实际问题短复现；支持卡可用拼音，不默认全学期每页汉字都加满拼音。 |
| 课前准备 | 建议10—15分钟，少量听辨／识别／预览。已掌握者换挑战；不得以每周额外数小时自学作为完成25课的隐藏条件。 |
| 课后巩固 | 建议一项5—10分钟改进任务，如重听后纠错、换信息短录音或下次课口头补答。 |
| 未预习 | 给3—5分钟关键图词恢复后进入任务；不以没有预习为由取消整节听说机会。此方案不自动改动学校既有出勤或纪律规定。 |
| 设备 | 纸卡、PPT和教师朗读即可运行；需录音时提供无设备替代，不要求学生为本课购买软件。 |

任务材料要成人化、贴近日常，但中文短而清楚。复杂的是需要处理的信息和互动，不应只是难词堆积。基础学生的角色资料不能比任务本身更难读。

## 10. 评量：个人证据、共同核心、另记挑战表现

### 10.1 学期证据安排

| 时间 | 检查内容 | 使用方式 |
|---|---|---|
| W01—02 | 语音／号码时间听辨、短意义听力、基本问答 | 初始样本；不只用自报HSK定级。 |
| 每周 | 轻量个人听力或回应、受观察的问答、结果核对 | 全员有证据，教师轮换重点观察，记录下一步。 |
| W07 | 第1—14课个人听力和双人即时互动 | 使用未练过的数据，不考刚接触的第15课新内容。 |
| W12—13 | 25课覆盖与个人困难清单 | 补取遗漏证据；熟练者做迁移挑战。 |
| W14 | 全册范围个人听力、个人简述、双人互动 | 不能用小组精美PPT或背熟对话代替个人能力。 |

阶段评量100分钟预算：说明5＋个人听力20＋14对口头互动各4分钟56＋机动9＋回顾10＝100。4分钟时段包含转换与记录，双人必须各有可观察的提问和回应。正式评分百分比尚未提供，Agent不得自行写入教务系统或全局配置。

### 10.2 本班原创观察表

下面不是官方HSK／ACTFL量表。Can-Do可以帮助描述表现，但不是一张可直接决定课程成绩的官方打分表。[R4]

| 维度 | 0：本次未完成 | 1：较多帮助下完成部分 | 2：基本独立完成 | 3：独立且能处理小变化 |
|---|---|---|---|---|
| 理解信息 | 尝试后仍未取得必要信息 | 多次提示后理解部分 | 理解大部分任务必要信息 | 能确认关键点并发现小误差 |
| 交际功能 | 尝试后未完成自己的功能 | 在带领下完成部分 | 完成自己的核心功能 | 换信息后仍能完成并处理小问题 |
| 互动回应 | 无有效问答 | 依赖逐句提示 | 能提问、回应与必要确认 | 能追问、澄清和修复误解 |
| 可理解性 | 主要信息仍无法理解 | 经帮助可理解部分意思 | 主要意思清楚，错误不阻断结果 | 表达清楚且较准确、符合情境 |

**无证据标记为`NE`，不等于0分。**缺席、紧张而没有取得样本、技术故障等另记原因并安排补证。求助“请再说一次”本身是交流策略，不自动扣分。

同时记录支持条件：图片／句框／文本／重播／教师逐句提示。核心评量允许什么帮助须事先统一说明；不能临时按自报HSK对某些学生提高及格线。挑战表现单独作反馈或在教师批准的制度下处理，不成为基础学生通过共同核心任务的隐藏条件。

### 10.3 个人检查要轻量且有用

每次可以只收一个关键听力答案和一段很短的互动样本。下一轮能改进什么比累计大量无反馈分数更重要。小组结果表只证明小组产出；每个人的判断和表达需要单独记录。

## 11. Agent每周产出什么

| 交付物 | 最少内容 | 不能出现 |
|---|---|---|
| 四节教师教案 | 每节50分钟、来源、可观察目标、教师动作、分组与材料 | 只有大标题，没有具体怎么运行。 |

一套公共材料加可选支持和挑战即可，不默认制作三套完整PPT。先建立全学期映射，再按近期周次制作最终学生材料；不要一次批量自动批准56节未核对内容。

## 13. 一份可检验的任务规格示例：W03见面约定

下面是**原创资料示例**，用于说明Agent必须把信息差和可行答案写到什么程度。它不是原书题目，不要求每周任务都变成时间安排。

### 13.1 公共信息与私有资料

公共说明：星期五下午四人见面30分钟。在14:00、15:00、16:00三个开始时间中选一个；地点从图书馆、食堂、教室中选一个。所有资料都是教学模拟。初学者可以看数字和图，不必使用尚未掌握的复杂时长结构。

| 私有角色卡 | 仅该角色知道的信息 | 他必须让别人知道什么 |
|---|---|---|
| A | 14:00—15:00有课；其他候选时间有空 | 自己不能参加14:00开始的见面。 |
| B | 15:00—16:00有课；其他候选时间有空 | 自己不能参加15:00开始的见面。 |
| C | 图书馆16:00—17:00不能使用；教室三个候选时段都可使用；自己三个时段有空 | 图书馆的限制，以及教室可用。 |
| D | 食堂16:00—17:00不能见面；自己三个时段有空 | 食堂的限制。 |

学生版必须拆成四份，不能直接把这张教师总表投在屏幕上。角色C／D仍需询问A／B时间，A／B仍需询问地点。每人至少提出一个必要问题并回应，不设永久记录员。

### 13.2 第一轮与第二轮

| 项目 | 教师版规格 |
|---|---|
| 第一轮结果 | 16:00—16:30在教室见面，四人都能参加。 |
| 验算依据 | A排除14:00；B排除15:00；16:00时C排除图书馆、D排除食堂，教室可用。 |
| 支持 | 时间数字、地点图片；可选“你……有时间吗？”“……可以吗？”等半句；允许先双人试问。 |
| 核心听力检查 | 听同伴后个人记录一位同伴不能参加的时间；不能只抄小组最终答案。 |
| 第二轮新增消息 | “教室16:00不能用了；图书馆16:00可以用。”由教师用固定简短中文说两遍，必要时明确标注为支持条件。 |
| 第二轮结果 | 16:00—16:30改在图书馆，其余条件不变。 |
| 挑战 | 不给整句稿，请学生核实到底改变了时间还是地点，并向另一组说明改变和保留的部分。 |
| 成功标准 | 选择符合全部条件；个人能说明一项限制并回应对方；第二轮确实修正地点。 |

若改资料后无解，要么修正资料，要么明确将“发现无法满足并提出替代”设为本轮目标，不能误把无解表发给基础学生却要求找唯一正确答案。

## 14. 停课、落后与课堂差异的调整规则

| 情况 | 本课程内的处理 |
|---|---|
| 内容已熟练 | 快速检查后压缩重复讲解，用同主题挑战替换，不提前取消全班任务。 |
| 一部分学生跟不上 | 先减少信息量、加图片／句框、双人带练，再加入同一任务；不永久分成各学不同课。 |
| 大约三分之一学生经示范仍不能进入 | 作为需要调整的提醒，简化条件并增一轮支持；该比例只是本班管理建议，不是科学统一门槛。 |
| 落后不足一节 | 优先削减等待汇报、抄写和已熟练机械练习，在后续200分钟内调整。 |
| 损失1—4节 | 使用W13最多200分钟缓冲，更新主覆盖位置；保留个人评量。 |
| 损失超过4节 | 重新计算可用分钟；压缩已掌握部分的重复教学和展示，向教师提交补课／重排方案。不能仍声称实际有56节。 |
| 后半册内容比预期难 | 保留首轮语言与听力覆盖，缩小主任务条件，安排W13复现；不只跳过难点赶到第25课。 |
| 学校要求逐页课堂全做 | 与当前选择练习的覆盖方式不同，应单独核算时间并报告；不偷偷增加大量课外任务或忽略学校要求。 |
| 正式考试日期变化 | 只调整本课程映射，并核对不超过截止日与实际课时；不得改动二年级。 |

原教材《使用说明》允许按需要选择练习，但其内容范围仍需负责覆盖。[S1] 本方案不预先把“自报高程度”当作后半册也可全部跳过的证据。
