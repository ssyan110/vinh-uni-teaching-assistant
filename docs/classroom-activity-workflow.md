# 每周实体课活动制作流程

2026-10-15 按 Adam 的逐次修改及第11—12课核准 v04 整理，替换此前互相冲突的活动结构说明。只适用于今后实体课 HTML／OpenSlide 及其 PPTX 备份；不改变线上课程 PPT、词语教学、分节或原有线上生产规则。身份、来源、批准及发布仍遵守项目合同。

## 制作方向

操作简单，思考有深度；投影少字，但任务完整。学生应从画面知道现在看什么、听谁、说什么、对谁说，最后完成什么。完整性是内容要求，不是每页必须出现“目标／步骤／完成标准”三个栏目。

- 优先直接听说：听老师读并记关键词、整理后介绍；共看资料问答；比较真实选项并作选择；独立看图讲故事。不要默认设计多张角色卡、转身、背对屏幕、预先抄写、换站或多轮交换资料。
- 用简单词语、简单句式说明操作；保留明确对象及必要条件。不能把“听记、核对、追问、协商”几个标签当作活动说明。简化的是执行方式，语言运用与思考仍要有挑战。
- 默认基础 HSK1—3／挑战 HSK4—6两档，用相同资料和同一操作流程。基础完成具体表达；挑战增加比较、利弊、理由、依据、判断或回应不同意见。不得用更多角色、更多手续或单纯多说几句代表更难。已核准的统一任务、看图说故事不强塞两档框。
- 本类漫画固定标题「看图说故事」，默认单人讲述，六格完整同屏一页，配必要短指令与「可用词句：」，不放分组步骤或 HSK 两档提示。背景、图中事实与可想象内容分清；不预先给整篇故事。
- 综合口语使用已学课次的真实生活选择、说明与讨论。参考 TOCFL／HSKK 时查证适用官方题型并记录出处，自编题明确为借鉴，不冒充官方题；不增加难执行的辩论或角色流程。

## 页数与视觉

默认一页完成一个活动，最多两页。只有必要资料确实需要独立呈现时，才拆为任务页＋资料页；不为凑两页重复目标、步骤或问题，不设额外纯标题活动页。任务和成果能用一句话说清，就不另加标签或重复总结。

封面与版式沿用当前第9—10课实物参考。第一页封面配相关图片；第二页「今天我们会做什么」用相关图标＋短语，不堆文字或重复漫画；第三页进入活动。活动编号、名称与路线一致，两页活动沿用同号同名。

封面文字统一格式（Adam于2026-10-15要求）：页眉「第N课 · 实体课」或「第N—M课 · 实体课」；主标题用准确的课次主题名词，如「天气与日常活动」，不写含义模糊的活动口号。说明限一句具体学习情境，主题标签只保留相关短词。沿用已定版式，不每次重问格式。本次第11—12课封面另行生成主题插画，不裁切或拼接既有漫画；以后新课封面默认新生成相关插画，已锁定课件不追溯重做。

活动改序、增删后，按最终展示顺序重新编号（本课11-1→11-5）；不得编号倒退或留删除活动的空号。同步学生页、路线、教师朗读稿PDF、教师说明、数据源、动画标识、缩略图、首页与包内清单，并读回逐项核对。旧编号对照仅留内部修订记录。

正文用短句、要点及必要信息，不贴教案。表格尽量放大、居中，提供任务所需的完整时段、日期、人物或选项；短问题需要时放下方，不再堆右侧说明。若指定“只保留表格”，就不补重复指令。提示统一标「可用词句：」。不要为减字删去任务对象，也不要靠缩小字、挤边距解决密度。
- **图标统一：**天气、时间、地点、交通、动作等可视化内容可以使用图标；同一套实体课从路线页到表格和提示都使用同一套极简教材风格图标（海军蓝、青绿、少量暖黄）。不混用 emoji、不同风格素材或装饰性图标。图标不能替代完成任务所需的日期、温度、风力和地点等文字资料。
- 漫画页通常用「看图说故事」配六格图；若 Adam 指定只留标题和图片，就移除说明、词句提示与覆盖图面的附加标签，并把漫画在可用空间内尽量放大、居中。


## 每周执行顺序

1. **确定输入。**核对教材、完整 lesson_key、学生范围、实际课时及最新用户修改。用户亲改的文件优先于旧 JSON、生成器与旧草稿；核对版本及 hash，先同步数据再生产。参考 v04 的清晰程度，不复制其活动数、页数、主题或课时分配。
2. **先把活动做完整。**写清实际资料、学生动作和口头成果；补齐教师朗读稿、答案与必要背景。问题须能从材料回答，开放问题标明开放范围；推断须有依据。模拟天气／日程标明模拟，不能当实际预报。
3. **再写学生短文案。**优先具体句子，例如“听老师说小安的一天，记下时间和活动。看记录，介绍他的一天。”目标与完成方式已包含其中，不再补三遍。两人活动清楚交代双方说什么、听什么；不要求每活动机械凑2—4步。
4. **先自行核对理解。**分别作为教师及没看过聊天的学生读一遍：能否立即开始、资料在哪里、怎样完成？删掉无必要流程，补回缺失信息，再检查简单中文。词汇表只能辅助，不能证明学生已经学过或理解；不能凭国籍解释困惑。
5. **一次提交具体内容。**学生可见文案、必要资料与教师稿一起审阅，获得该版本明确批准后生产。不重复询问已确认的风格与结构，不添加例行审批；也不能把旧版批准冒充新版批准。删除活动时同步删旧说明、教师稿、路线及计数。
6. **同步制作与检查。**学生页和教师材料使用同一套核准数据。含教师朗读的课件同步导出教师朗读稿 PDF，标活动号／对应页、全文、朗读方式、问题和答案，实际可找到。完整听力稿留教师侧，学生页只保留必要背景、问题或记录表；不提前泄露答案。原创朗读写“听老师读”，不编出版社 Audio 编号。
7. **自行修完再交付。**逐页对照核准内容并渲染，检查文字、图片、完整资料、字体字号、重叠与留白；核对 PDF 每页及稿件与活动映射。通过统一首页检查全页前后翻页、索引、动画与资源，再同步构建、检查包内文件。改页序就更新所有映射。不能让用户承担第一轮找错。

已验证且适用的研究与活动方法可以复用，不每周重新发明。当 Adam 指定使用 ChatGPT 研究时，必须实际使用并保存会话／回复与来源，区分研究结论和后续编辑；不能以自身设计或旧记忆冒充本次研究。

## 提交前拦截条件

出现以下任一项，制作者先修正，不能以“排版通过”交付：

- 只写“看问题／听消息”，实际没有题目、消息、朗读稿或材料位置。
- 学生需要教师重新讲一套隐藏规则才能开始；无必要的转身、预写、换卡步骤。
- 表格只给部分日期、天气没有时段、问题依赖材料中不存在的事实。
- 为填模板添加第二页、分级框或重复目标；把教师稿堆进投影。
- 漫画被拆开、强行分组，或听力答案在听之前已公开。
- 用户删掉的旧活动仍存在于教师稿、路线、索引或打包文件中。

检查证据包括逐项内容对照、全页渲染、教师稿对应、全程翻页及构建记录。自动查字段、字数或几何只能辅助；没有实际学生试教，不宣称学生已理解。内容批准、技术检查、教师播放／试教、正式发布分别记录。
