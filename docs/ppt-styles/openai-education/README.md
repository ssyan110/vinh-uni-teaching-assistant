# OpenAI Education

This is Adam's name for the visual style shown in his finalized 23-slide lessons 4–6 deck. It describes that supplied reference; it does not claim an official OpenAI brand template.

## Visual profile

- 16:9, near-white canvas with faint paper texture.
- Very large, heavy black Chinese titles, aligned left; short rounded underline with a purple-to-blue-to-green-to-yellow-to-coral gradient.
- Small course label at upper left and a small rounded status or timing pill at upper right.
- White rounded cards with soft shadows; lavender, light blue, mint, peach and pale coral surfaces distinguish steps and information groups.
- Sticker-like, softly rendered 3D classroom icons and people; small stationery decorations sit near the bottom corners.
- Dark, high-contrast Chinese text; bold labels and large numerals organize activities. Divider and process pages use short captions and four-step visual flows.
- Keep the visual hierarchy, spacing, card radii, icon scale and quiet margins visible in the reference deck. Reuse its embedded artwork when the same artwork is needed.

## Working design tokens

These values are practical starting points sampled from the reference. The source was flattened, so its original theme and editable font settings were not recoverable.

| Role | Reference setting |
|---|---|
| Canvas | 16:9, `#FDFDFD` / near-white |
| Main text | near-black, about `#101014` |
| Headline | heavy Chinese sans; usually about 44–58 pt, left aligned, one or two short lines |
| Body copy | Chinese sans, typically about 18–26 pt; keep labels and action text readable |
| Header / badge | about 12–18 pt, regular weight, quiet contrast |
| Card surfaces | pale lavender `#ECE9F8`, pale blue `#EAF2FB`, mint `#E2F5ED`, peach `#FFF0DF`, pale coral `#FFE8EC` |
| Accent rule | thin rounded rainbow stroke: purple → cyan → mint → yellow → coral |
| Shapes | rounded cards and pills, subtle cool-gray outline, soft shadow; no hard dark borders |

Use generous outer margins (about 0.7 in), a small upper-left course label, a compact upper-right pill, and the title/rainbow rule as the opening hierarchy. Reserve the lower corners for small stationery art and the page marker. Use one main student action per page; select among title/divider, four-step route, card grid, comparison, discussion, evidence, report, and reflection layouts rather than repeating one template.

For new content, keep the visual language and replace the reference's wording, roles, examples, numbers and illustrations with the current lesson's approved material. Do not copy this deck's student text into a different lesson unless Adam asks for it.

## Use in this project

The style is a selectable project-wide option alongside `boya-classroom`. Before producing a new deck, ask Adam which registered style to use unless his current request already selects one. A selected style controls visual presentation; lesson identity, source coverage, student language, approval gates, audio checks and course-specific requirements still apply.

The supplied year-one deck is an explicit reproduction exception to that cohort's 23 pt minimum: matching this finalized visual reference preserves its existing type sizes. This exception applies to the editable reference copy only. Future year-one decks continue to use the 23 pt minimum unless Adam directs otherwise for that deck.
