1來源教材分析：6 堂課完整結構

來源：Pinyin lessons/ 資料夾，AI Mandarin 獨立拼音教材（非漢語教程語音部分）。每堂課 21 頁 PDF，結構固定。

Pinyin L1 — 基礎入門

目錄：Khái niệm về pinyin → Thanh mẫu (4) → Vận mẫu (6) → Thanh điệu (5) → Từ vựng (16) → Thử thách bản thân

拼音概念 聲母 b p m f (4) 韻母 a o e i u ü (6) 規則 i→yi u→wu ü→yu 聲調 四聲+輕聲 詞彙 (16) 挑戰 輸入法安裝教學

Pinyin L2 — 聲母擴展 + 三聲變調

目錄：Khởi động → Thanh mẫu (10) → Từ vựng (16) → Biến điệu thanh 3 → Thử thách bản thân

暖身複習 聲母 d t n l + g k h + j q x (10) 規則 jü→ju qü→qu xü→xu 詞彙 (16) 三聲變調 挑戰

Pinyin L3 — 翹舌音/平舌音 + 一不變調

目錄：Khởi động → Thanh mẫu (7) → Từ vựng (16) → Biến điệu của 一 và 不 → Thử thách bản thân

暖身複習 聲母 zh ch sh r + z c s (7) 詞彙 (16) 一不變調 挑戰 21聲母總表

Pinyin L4 — 複韻母（i/u/ü 開頭）+ 拼寫規則

目錄：Khởi động → Quy tắc viết pinyin → Vận mẫu (9) → Từ vựng (20) → Thử thách bản thân

暖身複習 規則 iou→iu uei→ui uen→un + 聲調標註規則 + i/u 獨立規則 韻母 ia ie iao iou + ua uo uai uei üe (9) 詞彙 (20) 挑戰

Pinyin L5 — 韻母（ai/ao/ou/ei + 鼻韻母 an/ang/en/eng/in/ing/ong）

目錄：Khởi động → Vận mẫu (11) → Từ vựng (20+) → Thử thách bản thân

暖身複習 韻母 ai ao ou ei (4) 韻母 an ang en eng (4) 韻母 in ing ong (3) 詞彙 (20+) 挑戰

Pinyin L6 — 韻母（uan/uang/uen + ian/iang/iong/ün/üan）+ 日常用語 + 總複習

目錄：Khởi động → Vận mẫu (8) → Từ vựng (10+) → Giao tiếp thường ngày → Thử thách bản thân

暖身複習 韻母 uan uang uen(un) (3) 韻母 ian iang iong ün üan (5) 詞彙 (10+) 日常用語 你好/謝謝/再見/不客氣/對不起/沒關係 挑戰 36韻母總表
教材特徵總結：
• 每堂固定結構：封面 → 學習規則 → 目錄 → 暖身/概念 → 聲母或韻母表 → 詞彙 → 練習 → 規則/變調 → 挑戰 → 筆記頁 → 聯絡頁
• 6 堂完成全部 21 聲母 + 36 韻母 + 5 聲調 + 變調規則 + 拼寫規則
• 每堂都有「生詞/Từ vựng」用真實詞彙（含漢字+pinyin）作為該堂學的音的應用
• 每堂都有「Thử thách bản thân / 自我挑戰」作為課末測驗
• L3 附 21 聲母總表，L6 附 36 韻母總表
• 這是獨立教材，不依賴漢語教程

4Record Types 定義

record_type說明出現位置範例
concept拼音基礎概念L1聲母+韻母+聲調 = 一個音節
initials聲母（分組教學）L1-L3b,p,m,f / d,t,n,l / zh,ch,sh,r
finals韻母（分組教學）L1,L4-L6a,o,e,i,u,ü / ia,ie,iao / an,ang,en,eng
tone聲調與變調規則L1-L3四聲+輕聲 / 三聲變調 / 一不變調
spelling_rule拼寫規則L1,L2,L4ü省點、y/w規則、iou→iu
vocabulary應用詞彙（漢字+pinyin+圖片）每堂爸爸 bàba, 鸡 jī, 虾 xiā
exercise課內練習每堂聽音選擇、填空、配對
challenge自我挑戰（課末測驗）每堂辨音配對、看圖寫拼音、找錯
pinyin_table拼音組合表每堂知識段聲母×韻母組合方格表
summary_table聲母/韻母總表L3, L621聲母分類表、36韻母分類表
daily_phrase日常用語L6你好、謝謝、再見
appendix附錄（輸入法等）L1iOS/Android 拼音鍵盤安裝

10待確認問題

Combination Table 組合表怎麼處理？

原始教材每教一組新聲母/韻母就有一個拼音組合方格表。這個表要作為獨立 record (pinyin_table)，還是嵌入在聲母/韻母 record 裡面的 combination_table 欄位？

練習的答案要存嗎？

小檔案 PDF 是答案卷。每個 exercise/challenge record 要包含完整答案嗎？還是只記錄題目結構，答案放在單獨的 teacher-only 欄位？

詞彙的深度
