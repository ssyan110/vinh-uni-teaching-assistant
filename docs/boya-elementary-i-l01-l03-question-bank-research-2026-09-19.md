# 《博雅汉语·听说·初级起步篇 I》第一至三课题库研究

研究日期：2026-09-19  
研究对象：第一课至第三课  
研究目的：寻找可以直接给学生使用、可以合法改编，或可以作为自制学习单题型参考的公开资源。

## 一、结论先说

目前没有找到一套能够完整、逐题对应《博雅汉语·听说·初级起步篇 I》第一至三课，并且可以直接复制使用的公开题库。

最合适的做法是分成三层：

1. **直接在线使用**：把公开练习链接给学生，学生在原网站完成；不复制题目、音频或网页内容。
2. **依据开放授权改编**：选用有明确 Creative Commons 授权的资源，重新编写成自己的学习单或课堂练习，并保留署名、授权和修改说明。
3. **仅作题型参考**：看它如何设计听辨、声调、声母、韵母和拼音书写题，但不直接复制。

## 四、按第一至三课的可用资源安排

### 第一课：声母、单韵母、声调、j/q/x 与日常用语

建议组合：

- 先用 [Iowa Lesson 1–5](https://pinyin.uiowa.edu/course-work) 做声母、单韵母和声调的在线听辨。
- 用 [Mastering Mandarin Sounds](https://pressbooks.uiowa.edu/zheng/) 的拼音结构和声调内容，制作自己的「听音选声母／选韵母／标声调」学习单。
- 用 [Pitch Perfect Pinyin](https://laits.utexas.edu/ppp/) 做声调辨认和拼音拼写补充。
- j/q/x 与 ü 的规则可以参考 Iowa Lesson 3、Mastering Mandarin Sounds 和 [Ting Yi Ting 的拼音章节](https://opentext.ku.edu/tingyiting/)，但建议由教师自己重写成与本教材例字一致的题目。
- 日常用语部分没有找到与本课完全对应的开放题库；应保留博雅教材的表达，另做情境替换、听后选择和小组问答。

可制作的学习单题型：

1. 听音，在 `b/p/m/f` 或本课声母中圈出听到的声母。
2. 听音，在 `a/o/e/i/u/ü` 中选择韵母。
3. 听音，写出声调数字或画出声调线。
4. 看声母和韵母，判断能不能组成音节。
5. 看 `ju/qu/xu`，把 `ü` 的拼写规则补完整。
6. 根据日常用语情境选择合适表达，再和同伴互换角色。

### 第二课：复韵母、前鼻韵母、后鼻韵母、声调标记

建议组合：

- 直接使用 [Iowa Lesson 6–9](https://pinyin.uiowa.edu/course-work) 做复韵母和鼻韵母的听辨。
- 用 [MSU Elementary Chinese I Workbook：Initials](https://openbooks.lib.msu.edu/chs101wkbk/chapter/initials/)、[Finals](https://openbooks.lib.msu.edu/chs101wkbk/chapter/finals/) 和 [Tones](https://openbooks.lib.msu.edu/chs101/chapter/tones/) 参考开放练习版式。
- 用 [Mastering Mandarin Sounds](https://pressbooks.uiowa.edu/zheng/) 和 [Ting Yi Ting](https://opentext.ku.edu/tingyiting/) 补充音节结构、鼻韵母对比和声调听辨。

可制作的学习单题型：

1. 听音，在 `ai/ei/ao/ou` 等复韵母中选择正确答案。
2. 听音，区分 `an/ang`、`en/eng`、`in/ing`、`ian/iang`。
3. 看拼音补声调符号，并说明声调符号应该标在哪个韵母上。
4. 听音，把声母、韵母和声调分别写进三栏。
5. 小组轮流读一组容易混淆的复韵母或鼻韵母，同伴负责记录听到的答案。

### 第三课：儿化、y/w 拼写、变调、不和一

建议组合：

- 用 [Ting Yi Ting 的目录](https://opentext.ku.edu/tingyiting/) 和 [第三声变调章节](https://opentext.ku.edu/tingyiting/chapter/lesson22/) 设计声调变化和听辨题。
- 用 [Mastering Mandarin Sounds](https://pressbooks.uiowa.edu/zheng/) 参考音节拼写、声调变化和儿化内容。
- 用 [Pitch Perfect Pinyin](https://laits.utexas.edu/ppp/) 做拼音拼写、y/w 和声调变化的听辨补充。
- y/w、儿化、`不` 和 `一` 的变化没有找到一套完全按照本教材顺序的公开题库；应以本课教材例词为核心，由教师自己制作题目。

可制作的学习单题型：

1. 看 `i/u/ü` 开头的音节，选择正确的 y/w 拼写。
2. 一页一个规则，完成 `i → yi`、`i + n → yin` 等拼写转换。
3. 听两个或三个音节，标出实际听到的声调。
4. 判断 `不` 和 `一` 在句子中的实际读音。
5. 听普通音和儿化音，选择是否有儿化，并圈出变化位置。
6. 小组用本课词语读一轮，同伴只记录实际听到的拼音和声调。

## 六、最终建议：先用哪一套

### 第一阶段：马上可用

先把 [University of Iowa 学习拼音课程页](https://pinyin.uiowa.edu/course-work) 作为学生课外练习入口，因为它的 Lesson 1–9 顺序与本教材第一、二课的拼音内容最接近。

### 第二阶段：制作自己的学习单

以 [Mastering Mandarin Sounds](https://pressbooks.uiowa.edu/zheng/) 和 [Ting Yi Ting](https://opentext.ku.edu/tingyiting/) 为主要开放来源，制作三课共用的题型模板：

- 声母听辨
- 韵母听辨
- 声调听辨
- 拼音拼写
- 音节结构
- 声调变化
- 小组听读记录

题目中的字、音节、例词和日常表达仍以《博雅汉语》第一至三课为准；公开资源只提供题型、解释方式和部分练习素材，不替换教材内容。

### 第三阶段：第三课专项补充

第三课的 y/w、儿化、`不`／`一` 变调需要单独设计。公开资源可以提供规则和听辨方法，但目前没有找到可以直接套用的、与本教材例词完全一致的题库。因此不要等一个「完整现成题库」，应以本课教材例词制作小量、针对性的学习单。

## 七、目前没有做的事

- 没有把任何外部题目复制到本项目教材中。

- 没有把 HSK/YCT 当成《博雅汉语》第一至三课的替代题库。

下一步不是马上制作全部学习单，而是先确定第一批来源：

2. 自制学习单：Mastering Mandarin Sounds + Ting Yi Ting。
3. 第三课专项：依据教材内容，用上述两个开放来源的规则和题型自行改写。

确认这三个来源后，再建立 `lesson-01`、`lesson-02`、`lesson-03` 各自的学习单题目清单，并逐题标注来源、授权和是否需要音频。
