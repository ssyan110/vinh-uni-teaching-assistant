# 一年级每周综合听说测验

适用范围仅为 `BOYA-LS-E1-Y1S1-2026F`／`2026-fall`／`boya-elementary-i`。先读专案 `AGENTS.md`、`PROJECT_REQUIREMENTS.md`、`memory/project-memory.md`、`.agent/agent-workflow-index.md`、`.agent/agent-operating-contract.md` 与 `.agent/skills/boya-lesson-production/SKILL.md`；依专案 run loop 留下来源、验证和停止原因。课程周次以 `docs/course-rules/BOYA-LS-E1-Y1S1-2026F/README.md` 的当前版本为准，每次制作前重新核对。不要把大二课表或其他《博雅》册次混入。

## 定义测验单位

先写下 `offering_id`、周次、日期区间和完整 `lesson_key` 列表。**同一周一起上的课合成一卷**，两课都须有可见题目覆盖，并至少有一道整合两课信息的任务。不要按裸课号各做一卷。只考该周结束前实际教过的内容；若进度改变，先重核范围。

当前课表：W04教学＝9–10，但最新测验范围为第1–10课综合听力、30选择＋20填空共50题、无正式口说；第四段只测验，教师调整前三段TBL时间。旧9–10听说卷已停用，不复用为现行卷。此题数仅W04特例；W05＝11–12；W06＝13–14；W07＝15，另设 1–14 课 100 分钟个人阶段检查；W08＝16–17；W09＝18–19；W10＝20–21；W11＝22–23；W12＝24–25；W13＝缓冲补强、无新课，不虚构新课卷；W14＝已教内容的期末个人听力、简述与即时互动，校方正式日期仍待核实。W07 阶段检查须以口语或听力留下第1–3课拼音与声调的个人表现证据，同时抽样后续课的交际能力；W13 若要诊断题，必须依实际错题或进度另定范围。

## 取材与命题

逐课核对教材 source／canonical 资料、课次标题与页码、学期教师手册、实际教学进度、现有题库和音频清单。题库、旧 Google Form、旧音频只供复用和核对，不自动成为教材权威。来源缺页、课次身份冲突、进度未核实时明确标记，不以合理想象补成「已教」。保存每题的课次、考点和来源依据。

参考 [TOCFL 官方听力题型](https://tocfl.edu.tw/tocfl/index.php/test/listening/list/4) 设计听后辨识主旨、关键细节、顺序、意图及信息整合。称为「参考 TOCFL 题型的课堂测验」，不宣称官方真题、官方认证或已经做过等值定级。选择题的三个或四个选项应只有一个可辩护的正确答案；错项应来自可听出的真实误解，不能靠字面提示猜出。题目和选项与朗读稿互相独立，学生卷不泄漏全文或答案。在该卷已确认包含口说的范围内，才加入简短问答和实际开口的个人／双人任务；W04不加口说。按当卷目标检验学生是否能听懂一次、在有需要时重听，以及能否回应、追问和澄清。所有朗读稿注明说话人、听几遍、题间停顿；播放次数按题型目的决定，不假称 TOCFL 所有题目统一播放次数。

每周先定可在实际课堂执行的题数和分钟数，再写学生卷、教师卷、逐题答案依据、口语观察量表与评分表。未来测验采用适合学生程度和已教词汇／语法的TOCFL风格；实际命题时核对当时官方规格。W04第1–10课题数不通用化，已取消的9–10听说卷不作模板。客观选择题可自动评分；简答、翻译和口语须教师人工核分。学生端用简体中文直述可执行的动作；教师端保留来源、朗读稿、正确答案、可接受变体和评分依据。口语任务给出真实信息差或变化条件，不能只重复朗读音频。读者应能在没有聊天背景的情况下开始并完成测验。

## 音频与 Google Form

先核对音档与本题朗读稿逐字／语义相符，再做格式、时长、峰值、静音、解码和实际播放检查。旧题库对话可能把「小林：」这样的角色标记改写为会读出的「小林，」；教师卷必须区分角色标记稿与实际合成输入，不能以冒号排版掩盖音档里读出的人名。语速或发音有问题时，使用项目已有的 OmniVoice／合适的语音工具只重做受影响的题号；重新核对说话人、停顿、清晰度与题目答案。自动转写只是辅助证据，**教师亲听前不能写「声音已验收」**。保留原档、修订档和题号映射，不覆盖来源音档。缺乏可用语音工具时交付固定朗读稿并标注待录制，不能把文本冒充音频。

若制作 Google Form，建立未发布的审阅版：身份栏、明确的播放说明、听力选择题正确答案与分值、人工核阅简答；口语现场另记分。实际打开表单核对题目顺序、媒体链接、答案键、必填、作答路径和成绩接收处。无法访问 Form 时交付可导入的题目／答案与媒体映射，不声称线上版已完成。发给学生或把材料升为 `20-approved`／`40-release`，仍须本专案相应的人类审核与播放证据。

## 每卷交付与复核

本学期一年级新测验产出放在 `lessons/boya-elementary-i/` 下对应课次／用途的独立审阅目录；既有course来源／索引保留，不另在Documents/Codex建立教材交付目录。放置：`scope.md`（周次、课次、真实进度、来源及缺口）、`student.md`、`teacher.md`（含朗读稿与答案依据）、`items.json`、`audio-map.csv`、`score-sheet.csv` 和 `qa.md`；实际生成的音频另存并在清单里记录路径、版本与检验状态。若某文件不适用，说明原因。文件一律标「审阅稿／未发布」，不冒充课堂批准或校方正式考试。

复核者逐题检查：①只涉及本周已教课次或明示的累计范围；②双课各有覆盖与整合题；③文本、音频、题干、选项、答案互相一致；④简答和口语可人工判分；⑤播放和 Google Form 的真实验证范围写清；⑥时间和分数可执行。发现缺口时保留阻碍及可用审阅稿，不改教材来源、批准状态或注册表来让检查通过。
