# 课堂文案写作与检查

适用范围：新写或正在修改的学生投影片、活动材料与教师提示。既有 finalized 教材保持只读。此规范检查教学可操作性，不能代替来源核对、教师批准或真实课堂试教。

## 先把任务说清楚，再排版

每个活动先用普通话写明：谁和谁做、用什么内容、先做什么、再做什么、最后说出或记下什么。缺少信息时先回到本课设计，不靠润色补造题目、材料、数量或教师个人经历。

学生页保留开始和完成任务所必需的信息。教学目的、巡视重点、时间安排、纠错策略放教师提示；不能把必要的学生操作也藏进备注。分组若是行动条件，写在正文，例如“两人一组，轮流问”，不作为制作脚注。不要要求每页塞满全部条件：连续活动可以共用清楚、仍可查找的指令，封面和分隔页可以只有标题。

极简、大字、关键词和每页一个重点是视觉选择，不能覆盖任务完整性。先缩短赘词，再调版或拆页，不删动作对象与完成要求来制造留白。

## 用具体动作代替抽象标签

| 不足以单独成为指令的文字 | 按实际任务改写的示例 |
| --- | --- |
| 追问 | 听同学的回答，再问一个有关的问题。附两轮对话示例。 |
| 换 | 现在老师问，你来回答。或：交换角色，刚才回答的人开始问。两者不能混用。 |
| 采访 | 两人一组，轮流问下面的问题，记下同伴的答案。 |
| 介绍 | 向小组介绍你的同伴，说出他的名字和你刚了解到的事。 |
| 清晰的界线 | 必须先明确是哪一种界线。例如讨论个人话题时：不想回答的问题，可以说“这个问题我不想回答”。不能跨情境机械替换。 |
| 接住回答／形成产出／说依据 | 根据回答再问一句／写下你们选的活动／说说课文哪一句告诉你答案。按来源和任务选择。 |

示例是写法说明，不是所有课次的固定文案。不得将示例数量、对象或情境直接填入无关活动。教学术语可以出现在专业设计中，但必须对应具体师生活动；不能只堆砌“协商、迁移、边界、证据”等词。

“追问”不能机械等于“为什么／后来／将来”。根据回答选问题；“后来呢”用于经历，“你呢”通常是反问对方同一问题。先示范关系，再要求学生独立运用。

## 教师提示也必须能执行

说明教师先说或展示什么、学生如何开始、谁先谁后、听者做什么、什么表现表示可以结束、学生卡住时如何提供一句帮助。只补本活动需要的部分，不套通用长表。涉及现场自我介绍时准备真实内容提纲，缺少真实资料就标待补，不编造个人经历。

## 两次角色检查，再做语言润色

1. 教师视角：不读旧聊天，能否用该页和配套提示组织活动？指出具体缺项，先修活动逻辑。
2. 学生视角：只看学生可见内容，能否说出现在做什么、对谁做、用哪道题或材料、做完留下什么？模拟漏听一次口头说明的学生，检查能否找回任务。对首次出现的难动作提供一个例子或短句支架，不把整课变成术语解释。
3. 保持教材简繁体与语言要求，使用对应 humanizer 润色。自然度检查不能替代前两步，也不能删掉教学所需的重复、示例、编号或步骤。
4. 生成后重新抽取学生可见文字，与通过检查的文案核对；查看必要提示是否被生成器删除、隐藏到 notes 或缩成标签。逐页记录“原句、困惑、修订、检查依据”，存到该次工作允许的 draft 或内部报告位置。

通过条件：活动指令有明确动作和对象，所需材料可找到，完成要求明确，教师与学生检查发现的问题已处理。封面、分隔页、单词展示页按用途检查，不强套活动模板。自动关键词检查最多用于提醒，不能宣称学生理解已验证；未试教时明确记录“文案审查完成，课堂效果未验证”。

## 核对词语和语法是否已经学过

所有年级和教材共用 `course/language-reference/hsk/` 作为分级参考。先写清该班的目标等级与标准版本；若来源只写“HSK 1—3”而未写版本，同时对照旧 HSK 2.0 与 2025 新版 HSK 3.0，版本差异放入内部审阅记录。

HSK 标注不等于学生已学。逐页把新写的关键词、固定搭配、助词、句式和操作句与该教材的 canonical 词汇／语法记录及已完成教学进度核对；分清“课本出现”“教师正式教过”“学生练过／复习过”“未教”和“未知”。用户明确说尚未教学的内容不得只因列在低等级词表里就留在学生指示中。超出或未知时，先找学生已会的简单自然说法；专有名词等必要内容在内部标记并配理解支持。

HSK 词表只用于范围提醒，不能自动判定句子自然或可直接照做。`没有查到`表示“尚未核实”，不等于“高级”；通过等级查询也不免除教师视角、学生视角与自然口语检查。

同形字可能因读音、词性或词义分成多条词库记录；按句中实际读音和用法核对，不用最低或最高级别概括所有用法。
