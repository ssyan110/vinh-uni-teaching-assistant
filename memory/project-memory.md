## Current High-Value Project Rules

- Huashu Design is the slide engine. HTML presenter is primary. No PPTX workflow unless Adam explicitly changes this rule.
- Vietnamese is used for instructions and labels; Simplified Chinese is used for target learning content; pinyin supports pronunciation.
- Steps 1-8 can be automated before teacher review. Steps 9-18 require teacher approval.
- Lesson 01 is the canonical template for regular lessons.
- Lesson 10 `output/book-1/lesson-10/slides/01-cover.html` is the canonical cover template for future lessons, but covers no longer use the old three keyword/topic pills. Keep the lesson badge (`BÀI N · 第N课`) about 30% larger than the old 12pt badge, roughly 16pt.
- **Course background visual rule (approved 2026-06-08):** Future regular lessons and pinyin lessons should use the updated Pinyin Lesson 1 soft multicolor background style instead of flat single-color backgrounds: warm off-white base, very light mint/sky/yellow/peach/lavender blobs, low opacity, and no busy decoration behind primary content. Background images, watermark, and decorative blobs must always be bottom-layer elements (`z-index:0` / behind content), never overlays above text, cards, tables, or main images.
- **Inserted classroom image rule:** When a slide uses a separately inserted full-slide/reference/diagram image, show the image clearly at full opacity with no CSS blur, opacity reduction, or pale overlay. Do not wrap it in an extra white rounded rectangle, border, or shadow frame unless Adam explicitly asks for a card-style image. Any empty space around a contained image should show the slide background, not a white box.
- Clean PDF backups are finalization artifacts; ask Adam before exporting them.
- **Pinyin course (approved 2026-06-04; template updated 2026-06-05):** 6 independent lessons from AI Mandarin (`Pinyin lessons/`). NOT from 漢語教程. Full spec: `docs/pinyin-lesson-database-spec.md`. Pipeline config: `scripts/pipeline/configs/pinyin.json` v2.0.0. Output path: `output/pinyin/pinyin-{01-06}/`.
- **Pinyin slide baseline:** Future pinyin lessons reuse `output/pinyin/pinyin-01` as the pinyin-course template instead of rebuilding from scratch. Keep its cover, objective, divider, concept, tone, vocabulary, flashcard, practice, appendix/input setup, and closing visual language; swap lesson-specific text/content/images. Pinyin covers use the Lesson 1 layout: `PINYIN N · 拼音第N课`, `pīn/yīn` above `拼音`, and learned pinyin sounds/rules appear as grouped rounded chips in the subtitle slot. Increase spacing between sound tokens and wrap chips to a second line when needed. Pinyin chart and chart-based practice slides have no body title; maximize the chart within the slide safe area, keep equal column widths, and reuse the same chart table layout for tone-marked practice. For `j/q/x + ü`, display written forms `ju/qu/xu` under the `ü` column because the spelling drops the two dots but the sound is still `ü`. Pinyin closing slides use the `下课` visual composition from `/Users/ssyan110/Downloads/Mandarin_Pinyin_Foundations.pptx` (mint classroom background, large rounded white card, students leaving through an open classroom door) while keeping the lesson's original text: `下课`, `Bạn có câu hỏi gì không?`, and `Bài tiếp theo: Pinyin N`.
- **Pinyin wording:** Use `thanh điệu`, not `thanh điều`. Pinyin goal slides highlight taught initials/finals in bold red and adapt the goal text to the lesson, e.g. `Học 5 thanh điệu tiếng Trung`.
- **Pinyin vocabulary grid:** Future `Từ vựng 1`, `Từ vựng 2`, etc. grid slides keep only the top bar label and vocabulary grid. Do not add extra body descriptions like `Tập trung đọc...`.
- **Pinyin practice styles:** Future pinyin exercises reuse `scripts/pinyin-exercise-templates.mjs`: Lesson 1 slide 15 for reading drills, an image-based two-row layout for vocabulary `连连看` / matching, slide 37 for multiple choice/listening choice, and slide 38 for fill-in-blank/listening completion. For matching vocabulary exercises, put pinyin+hanzi cards on the top row and shuffled image cards on the bottom row; title the activity `Nối từ vựng với hình ảnh.` without lesson numbers; leave a generous vertical gap between rows; do not use Vietnamese meaning columns or top label pills. Split dense matching across slides instead of shrinking or crowding. For initial fill-in, keep underline blanks before untoned finals and add small parentheses above the vowel as a tone reminder; revealed sample answers do not show parentheses. Comprehensive fill-in practice must target the lesson's learning goals, not automatically practice finals.
- **Pinyin chart validity:** Do not generate pinyin chart cells by blindly concatenating `initial + final`. Use a validated Hanyu Pinyin combination chart and leave impossible cells blank. For Lesson 4, this matters especially for compound finals such as `ai/ei/ao/ou/er` and `iu/ui/ie/üe`: examples include no `fai`, but yes `fei/fou`; yes `cei/sei`; no fake `biu/bui/fie/jui/qui/xui/zhiu/zhie`.
- **Pinyin classroom slides:** No `Mục lục` or `Quy ước` slides in future pinyin decks. Pinyin slides do not show bottom-right `Trang ...` page indicators.
- **Pinyin review dividers:** For `Ôn bài X` warm-up review sections, show `Khởi động` above the `ÔN BÀI X` label on the divider.
- Images are tracked as lesson data. VP databases should carry `image_role`, `image_prompt`, `image_file`, `image_reuse_from`, `image_status`, and `image_semantic_check`. Complete lessons must have `slides/assets/asset-manifest.json` and `exports/qa/asset-qa-report.json`.
- New lesson generation uses blank placeholder image files first. Use Chrome/ChatGPT contact sheets or targeted replacement only when Adam asks for real images.
- **Vocabulary image generation preference (approved 2026-06-11):** Use Google Chrome + ChatGPT for real lesson vocabulary image generation. Do not use ChatGPT Atlas for this workflow. Do not use local/scripted/SVG fallback images for vocabulary assets unless Adam explicitly asks for that exact fallback; if Chrome/ChatGPT generation or download is blocked, stop and report the blocker.
