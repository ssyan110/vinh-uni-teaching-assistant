# Visual redesign direction · Pinyin Lesson 1

Source reference: `work/design-ref-pinyin-l1/pinyin-l1.pdf`

Important: use this as **style inspiration only**. Do not copy the exact slides, exact illustrations, exact title lettering, exact colors, exact composition, or any `ai mandarin` branding/copyright text.

## New design language

Use a friendly Vietnamese-university classroom style:

- Pastel educational background instead of Kami/editorial parchment.
- Rounded, playful title typography with dark outline/sticker feel, but not the same font or proportions as the reference.
- Hand-drawn-style classroom objects as original vector shapes: flashcards, pencil, notebook, speech bubbles, tone cards.
- Color-coded pinyin concepts:
  - Thanh mẫu: blue
  - Vận mẫu: coral/orange
  - Thanh điệu: green
  - Từ vựng: purple
  - Luyện tập: yellow/cream
- Use large central examples for pinyin concept slides, with connector lines to explanation cards.
- Use clean student-facing Vietnamese + Simplified Chinese only.
- No teacher-prep notes, source notes, tool labels, copyright labels, or audience labels on classroom slides.

## Layout patterns to implement later, after teacher review

1. **Cover slide**
   - Large original outlined title on left/center.
   - Original stationery illustrations cropped around edges.
   - No source/copyright/internal text.

2. **Concept slide**
   - Central pinyin example.
   - Color-coded parts.
   - Three surrounding definition cards.
   - Short question/check at bottom.

3. **Vocabulary slide**
   - Rounded cards with Chinese, pinyin, Vietnamese meaning, and Vietnamese word type.
   - Consistent title: `Từ vựng`.

4. **Practice slide**
   - Large exercise area, minimal decoration.
   - Use book exercises where available.

5. **Teacher prep**
   - Goes to `教师手册`, never classroom slides.
