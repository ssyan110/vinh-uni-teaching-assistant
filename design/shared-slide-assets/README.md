# Shared Slide Assets

Assets in this folder are reusable sources for future lesson decks.

For each new lesson, copy:

```bash
mkdir -p output/book-1/lesson-XX/slides/assets/brand
cp design/shared-slide-assets/brand/logo-watermark.png \
  output/book-1/lesson-XX/slides/assets/brand/logo-watermark.png
```

The lesson-local copy keeps each `slides/` folder portable when shared.
