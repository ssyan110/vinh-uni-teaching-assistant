# 來源與法律聲明

## 來源層級

本 draft 使用的來源代碼與 URL 只取自指定 Markdown 第 4 節，完整資料在 `data/source-map.json`。

| 層級 | 來源 | 本 draft 的用法 |
|---|---|---|
| 第一層：官方核心構念 | S01–S14 | 決定三模式、functions、context／content、text type、language control、vocabulary、strategies、feedback 與 official rating 邊界 |
| 第二層：公開 ACTFL-aligned 工具 | S15–S20 | 參考分析式 rubric 結構與 0–3 組織；不直接沿用 proficiency 對應 |
| 第三層：課程與教材條件 | S21、本課任務規格 | 決定教材範圍與 task-specific 欄位；任務定稿須教師批准 |
| 第四層：課程適配 | 本 draft | 建立 descriptor 切點、任務紀錄與資料流程；明標非官方 |

## 使用聲明

- ACTFL Proficiency Guidelines、Performance Descriptors、Can-Do、World-Readiness Standards、IPA 與 ACAR 的名稱與構念歸屬其發布機構。
- NYSED／Ohio 工具只作指定 Markdown 所列的公開 ACTFL-aligned 參考；不能把本地翻譯或適配版本稱為 ACTFL 官方工具。
- 不大量逐字複製受版權保護的官方 rubric。
- 本系統不能核發 ACTFL official rating，也不把本課分數解讀為 ACTFL sublevel。
