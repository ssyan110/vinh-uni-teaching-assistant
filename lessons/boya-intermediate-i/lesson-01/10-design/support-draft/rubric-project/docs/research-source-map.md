# 研究來源地圖摘要

本頁是 `data/source-map.json` 的人工閱讀版；來源內容、URL、可採用程度與每個 criterion 的 source map 以 JSON 為準。存取日期沿用指定 Markdown：2026-08-23。

## Rubric 構念來源

| Criterion 群組 | 主要來源 | 構念 |
|---|---|---|
| I1–I5 | S05、S08、S15 | 主旨、核心資訊、證據、關係／推論、理解策略 |
| P1–P5 | S04、S08、S09、S19 | 溝通功能、問答追問、確認澄清修補、語篇詞彙、可理解度與語言控制 |
| PR1–PR5 | S06、S08、S20 | 溝通功能、理由與支持、組織、語篇詞彙、可理解度與語言控制 |

## 來源限制

- S01–S14 決定官方構念與 official rating 的使用邊界，不提供本課通用 0–3 表。
- S15–S20 是指定 Markdown 列出的公開工具；只參考結構，不沿用其中的 proficiency mapping。
- S07、S08 的 Can-Do 只作目標、自評與在地化方向，不能直接成為數字成績。
- 本課的理由數、證據數、追問數、準備時間與重做政策都是 task-specific 或課程政策，須事先公布並由教師批准。

## 每個 criterion 的追蹤

每個完整 criterion 都在 `data/rubric.zh-CN.json` 內綁定：

- `source_construct`
- `source_ids`
- `source_pages_or_sections`
- `task_specific_part`
- `adaptation_note_zh_tw`
