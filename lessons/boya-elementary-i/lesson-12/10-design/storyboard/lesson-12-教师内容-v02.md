## 活动11-1｜听天气，选时间

### 第一页｜目标与任务

目标：听懂天气和温度，告诉同桌什么时候去公园。

1. 先看第二页的三道问题。听老师读天气预报，自己记三个时段的天气和温度。
2. 和同桌核对记录；不同的地方再听一次。
3. 轮流说：选哪个时段去公园，为什么。

- 基础（HSK1—3）：说清一个时段、天气和选择理由。
- 挑战（HSK4—6）：比较两个时段；回应同桌的不同选择。
- 完成：每人一份天气记录；每人说一个选择和理由。

### 第二页｜任务材料

听老师读明天的天气预报。

1. 上午、下午、晚上：天气怎么样？多少度？
2. 哪个时段下雨？
3. 你想什么时候去公园？为什么？

| 时段 | 天气（听后记） | 温度（听后记） |
|---|---|---|
| 上午 |  |  |
| 下午 |  |  |
| 晚上 |  |  |

可用：我想……去公园。……，我觉得……。

### 教师材料（不投影）

朗读全文：“大家好。明天上午是晴天，二十四度。下午有雨，二十八度。晚上是阴天，二十二度，还有风。明天上午天气很好，下午太热了。”

读法：第一遍正常语速听整体，留20秒独立记录；同桌比较后，第二遍核对天气和数字。仍有分歧只重读对应时段。不要展示全文或答案。
示范：另读“今天早上晴，二十度”，板书早上／晴／20，再说选择理由。
答案：上午晴24度；下午雨28度；晚上阴22度、有风。下午下雨。上午或晚上去均可，理由须符合预报。
帮助：“先听上午、下午、晚上，再记天气和数字。”
反馈：纠正天气与温度的错配，让学生重说原选择。预算：示范3＋听记核对6＋交流5＋反馈3＝17分钟。

语言：天气、晴天、阴天、下雨、度、热、不太／太……了；补充：因为。


## 活动11-2｜一起选出门安排

### 第一页｜目标与任务

目标：用天气和喜好，和同桌确定一个共同安排。

1. 看第二页三个安排。各自先选一个，想好理由。
2. 轮流告诉同桌：什么时候去、做什么、为什么。
3. 选择不同，就说明理由；一起选定一个安排，再各说一次。

- 基础（HSK1—3）：说清时间、活动和一个天气理由；回答同桌一个问题。
- 挑战（HSK4—6）：比较两个安排；回应同桌的理由，提出双方能接受的办法。
- 完成：两人各说出同一个最终安排和理由。

### 第二页｜任务材料

明天的三个安排

| 时间 | 天气 | 活动 |
|---|---|---|
| 上午9:00 | 晴，24度 | 公园散步 |
| 下午3:00 | 雨，28度 | 商场逛街 |
| 晚上7:00 | 阴，22度，有风 | 商场逛街 |

想一想：喜欢晴天、不喜欢太热的人会怎么选？喜欢逛街的人呢？

问同桌：你选哪个？为什么？我们一起什么时候去，做什么？

可用：我想……。我觉得……太……了。可是……。那我们……吧。

### 教师材料（不投影）

ChatGPT原题名“两种安排”实际列出三个选项，本稿改名；原小林、小王两套喜好会增加角色负担，改作共同讨论问题，实际协商使用学生自己的喜好。
示范（另一情境）：A想下午晴26度去公园，B觉得太热，提出晚上22度；A问天气，双方决定晚上散步。
答案开放，三种选择均可；必须尊重天气数据，不把个人偏好说成唯一答案。
帮助：“先说你想什么时候去，再说那时候天气怎么样。”
巡视：两人是否都说理由，是否回应彼此。只说喜欢时追问天气理由；反馈后两人重说共同决定。13分钟含示范、个人选择、协商与重说。

语言：天气怎么样、很／不太／太……了、喜欢、逛街；补充：散步、可是、那……吧。


## 活动11-3｜六格漫画：天气变了

### 第一页｜目标与任务

目标：用本课词语，讲清天气变化和人物活动。

1. 看第二页六格漫画。A讲①②③，B讲④⑤⑥。
2. 再轮流各讲完整六格；听者问一处不清楚的地方。
3. 回答后，把不清楚的部分再讲一次。

- 基础（HSK1—3）：每格说清发生什么；用天气词和“太……了”表达感受。
- 挑战（HSK4—6）：解释天气怎样影响活动；加入合理的人物想法，回答“为什么”。
- 完成：每人讲完整故事；同桌能说出天气变化和最后的活动。

### 第二页｜任务材料

六格漫画：完整六格同屏，顺序①—⑥。

![第11课六格漫画](../open-slide-draft/lesson-11-12-single-activity-v01/assets/story-lesson-11.png)

①短标注：上午晴24度／下午雨28度（天气预报）。

讲述提示：①预报说什么？②③他们在哪里，感觉怎么样？④⑤天气怎样变？⑥最后做什么？

可用：天气预报｜晴天｜热｜阴天｜刮风｜下雨｜逛街｜太……了

### 教师材料（不投影）

已逐格查看现有图片：看预报→晴天公园散步→擦汗喝水→阴天风吹→门廊避雨→商场逛街。数字、宿舍身份及中午并非图片可直接确认的信息；①预报数字属于明确模拟背景，必要时可短标注，不能说图片本身显示24／28。
示范只讲①②，让学生继续，不提供全文。
帮助：“先说这格的天气，再说他们在哪里、做什么。”
评价：六格顺序及天气／动作关系正确。人物心情、为什么去商场可以合理创编，不能把想象当作画面事实。
反馈：区分预报与实际天气、阴天与已经下雨；重讲有误的两格。20分钟包含看图、示范、分段、两人完整叙事与问答修订。

语言：天气预报、晴天、阴天、刮风、下雨、热、逛街、太……了；补充：因为、后来。


## 活动11-4｜三个城市，你想去哪儿

### 第一页｜目标与任务

目标：比较天气、季节和温度，说自己的选择。

1. 看第二页三个城市的天气，各选一个想去的城市。
2. 轮流告诉同桌天气和理由；各问对方一个天气问题。
3. 听完回答，保留或改变选择，再说明理由。

- 基础（HSK1—3）：说城市、天气、温度和喜好；回答一个问题。
- 挑战（HSK4—6）：比较两个城市；回应不同喜好，说清是否改变选择。
- 完成：每人说最终选择；同桌能复述城市和理由。

### 第二页｜任务材料

12月的一天

| 城市 | 季节／天气 | 温度 |
|---|---|---|
| 北京 | 冬天，下雪 | 零下5度 |
| 曼谷 | 晴天 | 32度 |
| 悉尼 | 夏天，晴天 | 25度 |

①哪个最冷，哪个最热？②你最想去哪儿，为什么？③你喜欢下雪还是晴天？④听了同桌的理由，你想改变选择吗？

可用：我最喜欢……。我觉得……太……了。你为什么喜欢……？

### 教师材料（不投影）

全部是教学模拟，不能声称实时天气或整个12月每天如此；不把曼谷12月标成北半球冬季。
示范：教师选悉尼晴25度，学生选北京喜欢雪；教师问零下5度是否太冷，学生回应自己的喜好。
答案：北京最冷、曼谷最热；城市选择开放。
帮助：“先说天气和温度，再说你喜欢什么。”
巡视：挑战是否回应同伴，而非多说气温；不得编造机票或预算条件。14分钟含选择、问答、修订。

语言：季节、冬天、夏天、雪、零下、度、最、喜欢、太……了；补充：因为、比。


## 活动11-5｜听新预报，改变安排

### 第一页｜目标与任务

目标：听新天气预报，决定要不要改变原计划。

1. 看第二页原计划和四道问题，听老师读周日预报。
2. 独立记上午、下午的天气和温度；与同桌核对。
3. 轮流提一个新安排，说理由；听者复述，讲错就修正。

- 基础（HSK1—3）：记对两个时段；选一个安排，说天气理由。
- 挑战（HSK4—6）：比较新旧安排；回应同桌意见，说清改变或保留的理由。
- 完成：每人一份听记和一次新安排；同桌能复述。

### 第二页｜任务材料

原计划：周日下午3:00去公园散步。

听前问：①上午天气怎么样、多少度？②下午呢？③原计划合适吗？④你建议怎么安排？

| 时段 | 天气（听后记） | 温度（听后记） |
|---|---|---|
| 周日上午 |  |  |
| 周日下午 |  |  |

可选：上午9:00公园／下午3:00公园／下午3:00商场。

可用：原来想……。现在……。我想……。

### 教师材料（不投影）

朗读全文：“大家好！现在说周日的天气。周日上午晴天，二十三度，天气很好。周日下午阴天，下雨，二十七度。上午去公园散步很好，下午下雨，去公园不太好。”
读法：第一遍判断原计划；第二遍核对两个时段的天气与温度；有争议再重读对应时段。
示范用别的数字：“上午晴天，下午下雨。我原来想下午去公园，现在想上午去。”
答案：上午晴23度，下午阴、下雨27度。上午公园／下午商场都合理；不否认下雨事实。
帮助：“先找原来去公园的时间，再听那个时间的天气。”
巡视：23／27是否听反，建议是否和事实分开。反馈后重说。17分钟含听记、协商、修订。

语言：天气预报、晴天、阴天、下雨、度、逛街；补充：原来、因为。


## 活动11-6｜通知同学，确认安排

### 第一页｜目标与任务

目标：把新安排说清楚，让同桌知道何时何地见面。

1. A看第二页通知资料；B背对屏幕，只听。
2. A说完整通知；B记关键词，复述并问一个确认问题。
3. A回答并纠正；交换角色，各再通知一次。

- 基础（HSK1—3）：说清日期、见面时间、地点、活动和结束时间。
- 挑战（HSK4—6）：再解释为什么改安排；主动检查听者有没有听错。
- 完成：每人通知一次、听一次；听者记录准确。

### 第二页｜任务材料

周日最终安排

| 项目 | 信息 |
|---|---|
| 见面 | 周日上午9:00，学校门口 |
| 活动 | 去公园散步 |
| 结束 | 上午11:00 |
| 原计划 | 周日下午3:00去公园 |
| 天气 | 上午晴23度；下午阴、下雨27度 |

听者先在纸上写：哪一天／几点见面／在哪里／做什么／几点结束。

确认：我们几点见面？在哪里见面？几点结束？

### 教师材料（不投影）

本活动采用统一的9:00方案，不将11-5学生开放选择假装成全班已决定。
示范另一个通知：“明天下午两点在教室见面，看电影，四点结束。”听者复述。
答案：周日9:00学校门口→公园散步→11:00结束；原因下午下雨。
帮助：“按什么时候、在哪里、做什么、几点结束来说。”
巡视：B背对资料，有纸笔；漏地点或结束时间时重发通知。交换后的同一资料属于复述练习，不冒充新的独立听力测验。19分钟含准备、两轮通知、核对和反馈。

语言：天气、晴天、下雨、度、怎么样；补充：散步、结束、因为。


## 活动12-1｜平时做什么，现在呢

### 第一页｜目标与任务

目标：分清每天的习惯和现在正在做的事。

1. 看第二页，选两个人，先自己想怎么介绍。
2. 轮流说给同桌听；听者问“现在在哪儿，正在干什么”。
3. 回答后补说第三个人；听者复述一人的现在情况。

- 基础（HSK1—3）：用“每……都……”和“正在……呢”说两个人。
- 挑战（HSK4—6）：判断现在的事是否真的与习惯不同；解释依据，回答追问。
- 完成：两人讲清三个人；每人回答一次，听者复述正确。

### 第二页｜任务材料

今天星期三，下午2:00。

| 人物 | 平时 | 现在 |
|---|---|---|
| 小林 | 每天坐公共汽车去学校 | 车站等公共汽车 |
| 小美 | 每天下午在教室做作业 | 宿舍上网 |
| 小王 | 每天晚上看电影 | 教室做作业 |

①小林每天怎么去学校，现在做什么？②小美平时下午做什么，现在在哪儿？③小王现在在看电影吗？

挑战：小王现在做作业，能说明今天晚上不看电影吗？为什么？

### 教师材料（不投影）

示范虚构的自己：“我每天晚上都看电影，现在正在上课呢。”不要把虚构说成教师真实习惯。
答案：按表描述；小美同一时段不同动作；小林等车可属于每日坐车过程；小王下午作业与晚上电影并不冲突。ChatGPT原“每个人都不同”要求在此纠正。
帮助：“先说每天，再说现在。”
巡视：不把当前动作说成习惯改变；反馈后重说。12分钟含观察、描述、问答和修订。

语言：每……都……、正在……呢、车站、等、上网、作业、看电影、干什么。


## 活动12-2｜听三条消息，说清人在做什么

### 第一页｜目标与任务

目标：听懂三人的地点、动作和下一步安排。

1. 先看第二页四道问题；听老师读小林、小美、小王的三条消息。
2. 自己记地点、动作、时间；再听核对。
3. 和同桌比较；不同就说清要重听哪一人的哪项信息。
4. 轮流介绍三人；听者指出错处，修正后重说。

- 基础（HSK1—3）：说对三人的地点、正在做的事和下一步安排。
- 挑战（HSK4—6）：现在要打电话问作业：先找谁？用消息说明理由。
- 完成：每人一份状态记录、一次介绍；挑战另说选择依据。

### 第二页｜任务材料

今天下午1:40。听老师读三人的消息。

①小林在哪儿，正在干什么？②小美呢？③小王呢？④每人接下来要做什么，什么时候？

| 人物 | 地点 | 现在做什么 | 下一步／时间 |
|---|---|---|---|
| 小林 |  |  |  |
| 小美 |  |  |  |
| 小王 |  |  |  |

挑战：现在找谁打电话问作业？谁明确说能接电话？谁没说？

### 教师材料（不投影）

三条原创朗读稿（按顺序，听前不公开）：
1. 小林：“喂，我是小林。现在一点四十分，我正在车站等公共汽车呢。公共汽车还没来。我一会儿坐车去学校。”
2. 小美：“我是小美。我现在在宿舍，正在上网呢。我两点开始做作业。你现在可以给我打电话。”
3. 小王：“我是小王。我现在在教室，正在做作业呢。我从一点开始做作业，两点去上课。现在我不想打电话。”
读法：第一遍每条间隔3秒听地点动作；第二遍间隔5秒核对时间。争议只重读相应人物。示范另读“我是老师，现在在教室，正在说话”，学生记录教室／说话。
答案：小林车站等车，一会儿坐车去学校；小美宿舍上网，2:00开始作业；小王教室作业，1:00开始、2:00上课。小美明确可打电话；小王不想；小林接电话是否方便没说。
帮助：“先听现在和正在，再找一会儿或开始。”
巡视：不把小美未来作业记作当前；不把小王1:00当当前时间。15分钟含两遍、核对、报告、修订。本活动与12-1是独立情境。

语言：正在……呢、等、车站、上网、作业、一会儿、从……开始、打电话；补充：还没来、可以、不想。


## 活动12-3｜打电话，确认到校时间

### 第一页｜目标与任务

目标：询问位置、动作和到校时间，确认是否会晚到。

- 基础（HSK1—3）：问清三项，重复时间并得到确认。
- 挑战（HSK4—6）：比较到达和上课时间；问晚到怎么办，商量一个办法。
- 完成：每人问一次、答一次；两人确认到达时间。

| A | 教室，正在做作业 |
| B | 车站，正在等公共汽车；预计2:10到教室 |

确认：你是说……到，对吗？

### 教师材料（不投影）

第一轮A在资料页打开前背对屏幕，带着纸上三项提问；B看资料。不要让双方先读到2:10后再伪称信息差。交换轮资料相同，只算交流重做。

语言：喂、在哪儿、正在……呢、等、车站、到、晚、告诉、从……到……；补充：预计、对吗。

## 已修正的具体问题

- “看问题”替换为实际编号问题；“听消息”明确人物、教师朗读全文和听取项目。
- “同伴比较”说明比较天气、时间、动作或教室；有分歧指出哪项并针对重听。
- 11-2原标题说两种安排，表内其实三种，现统一为选安排；减少模拟角色喜好条件。
- 12-1不会把下午做作业与晚上看电影误判为习惯冲突；等车也不必与每日坐车矛盾。
- 电话与课表的听者在资料页出现前背对屏幕；交换使用同资料只作重做，不冒充新信息差。
- 漫画数字作为明确教学背景短标注；区分可见图像事实、背景和合理想象。
- 12-8是同伴确认与教师抽样；不声称8分钟能完成全班逐人口试。
