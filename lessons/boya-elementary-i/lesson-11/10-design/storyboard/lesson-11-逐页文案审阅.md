## 11-1 听天气，选时间

1. 看下一页的表格。听老师说天气，写下三个时间的天气和温度。

2. 和同学看看写得一样吗。不一样的地方，再听一次。

3. 每个人说：几点去胡志明广场？天气怎么样？为什么那个时间去？

基础 HSK1–3：选一个时间，说天气怎么样，为什么那个时间去。

挑战 HSK4–6：选两个时间，比较这两个时间，选一个，说为什么这样选。

### 第二页资料

| 时段 | 天气 | 温度 |
|---|---|---|
| 上午 |  |  |
| 下午 |  |  |
| 晚上 |  |  |


教师：朗读全文：“大家好。明天上午是晴天，二十四度。下午有雨，二十八度。晚上是阴天，二十二度，还有风。明天上午天气很好，下午太热了。”

读法：第一遍正常语速听整体，留20秒独立记录；同桌比较后，第二遍核对天气和数字。仍有分歧只重读对应时段。不要展示全文或答案。
示范：另读“今天早上晴，二十度”，板书早上／晴／20，再说选择理由。
答案：上午晴24度；下午雨28度；晚上阴22度、有风。下午下雨。上午或晚上去均可，理由须符合预报。
帮助：“先听上午、下午、晚上，再记天气和数字。”
反馈：纠正天气与温度的错配，让学生重说原选择。

本版预算：15分钟（含示范、听／看、每人表达、反馈与重说；未试教实测）。

## 11-2 看天气，一起安排出游

1. 两三个人一起看下一页的天气表。
2. 每个人选一天，说去哪里、做什么、为什么。
3. 一起选一天，说你们最后的安排。

基础 HSK1–3：选一天，说天气、温度、去哪里和为什么。
挑战 HSK4–6：比较两天的天气，说各有什么好、不好，最后一起选一天。如果天气变了，说怎么改安排。

### 第二页资料
课本一周天气表（直接使用原表）


教师：资料：直接使用Adam提供的课本天气表截图，周五4日至周四10日，七行及天气图、温度、风向、微风完整保留。没有月份或城市，不编造。日期是课本情境，不是本周实际预报；双温度为最高／最低温，不是上午／下午。
示范：只示范如何读一行，例如周四晴，最高33度、最低20度；学生自行选日期与去处。资料没有给雨天的具体小时，不能推断什么时候开始下雨。
答案开放：依据表格天气解释活动选择。两三人均先表达，再共同选择；不要求私有资料或转身。
帮助：“你想哪天去？那天天气怎么样？去哪里？”
反馈：让学生补具体天气理由，再介绍共同安排。挑战比较两天，并说明天气变了怎么改。
本版预算：18分钟（安排估计，未试教实测）。

## 11-3 看图说故事

学生页只放标题“看图说故事”、整组六格漫画、必要时间／人物背景，以及一句“自己按①到⑥讲故事，说清天气／时间和人物在做什么。”不放分级框。

图片及原有必要标注不变；词句提示若需要，统一标“可用词句：”。

教师：六格顺序：看预报→晴天公园散步→擦汗喝水→阴天风吹→门廊避雨→商场逛街。预报24／28度为给定背景，不能说图片本身显示数字。
示范仅①②，不提供整篇范文。每位学生独立看图、记关键词、练讲完整六格；教师抽样听取个人讲述，反馈后学生自行修订、重讲。不组织分段接龙、同桌问答或互评。
帮助：“先说这格的天气，再说他们在哪里、做什么。”
评价：六格顺序及天气／动作关系正确；人物心情可合理创编，不把想象说成画面事实。
教师抽查不等于全班逐人口试。

本版预算：15分钟（含示范、听／看、每人表达、反馈与重说；未试教实测）。

## 11-4 听新天气，改安排

1. 看下一页原来的安排和“请你想想”。听老师说“新的天气”。

2. 自己写下早上、下午的天气和温度。

3. 每人说新的安排和为什么有新的安排。

基础 HSK1–3：说新的天气和温度，再说做什么、几点去、为什么。

挑战 HSK4–6：说原来和现在的安排有什么不同，为什么不同。

### 第二页资料

原计划：周日下午3:00去公园散步。

| 时段 | 天气 | 温度 |
|---|---|---|
| 周日上午 |  |  |
| 周日下午 |  |  |

请你想想：
1. 上午天气怎么样？多少度？下午呢？
2. 下午去公园好吗？为什么？
3. 你想几点去哪里，做什么？

可用词句：原来……。现在……。我想……。


教师：朗读全文：“大家好！现在说周日的天气。周日上午晴天，二十三度，天气很好。周日下午阴天，下雨，二十七度。上午去公园散步很好，下午下雨，去公园不太好。”
读法：第一遍判断原计划；第二遍核对两个时段的天气与温度；有争议再重读对应时段。
示范用别的数字：“上午晴天，下午下雨。我原来想下午去公园，现在想上午去。”
答案：上午晴23度，下午阴、下雨27度。上午公园／下午商场都合理；不否认下雨事实。
帮助：“先找原来去公园的时间，再听那个时间的天气。”
巡视：23／27是否听反，建议是否和事实分开。反馈后重说。

本版预算：15分钟（含示范、听／看、每人表达、反馈与重说；未试教实测）。

## 11-5 越南城市，你想去哪儿？

1. 选你想去的越南城市，查天气，记下日期、天气和温度。
2. 向同学介绍，说你想哪天去、做什么、带什么，为什么。
3. 同学问一个问题，你回答。

基础 HSK1–3：查一个城市未来三天的天气，选一天，说出门安排。
挑战 HSK4–6：查两个城市未来七天的天气，比较后选一个城市和一天，说为什么；如果下雨，说怎么改安排。

### 同页资料
可用词句：我想去……。那里……。我选星期……，因为……。如果下雨，就……。


教师：第十一课最后的综合练习；学生自由选择越南城市，不限北京等课本城市，也不预设固定越南城市。学生用手机查询天气，记下所用网站／天气应用、查询日期和预报日期。基础一个城市未来三天；挑战两个城市未来七天。使用同一查询日期比较，不能把历史天气当未来预报。
先让学生打开可用的天气网站／应用，再独立记关键词、向同学介绍并回答一问。不复制整段网上介绍，不把网页越南语翻译作为主任务。若无法联网，使用课前已查并标注日期的记录；不要现场编造。
综合表达：天气、温度、日期、出游活动、带什么和选择理由。可自然结合已学的时间、地点和出行表达，不额外强制机票或预算资料。
答案开放：城市／日期选择合理，有查到的天气依据；预报可能变化，要说这是查询时的预报。挑战须比较后作选择，并说雨天替代安排。
帮助：“哪一天？天气怎么样？你想做什么？为什么？”
本版预算：20分钟（含查询、记录、每人介绍与问答；安排估计，未试教实测）。

## 12-1 平时做什么？现在呢？

1. 请听老师说，然后记下来。
2. A介绍他们平时做什么，B听。
3. B介绍他们现在在做什么、为什么要做，A听。
4. A、B都说自己平时晚上八点做什么、为什么。
5. 介绍对方平时晚上八点做什么、为什么。

可用词句：每天都……。现在正在……呢。因为……。

教师：朗读全文：
“今天星期三，现在是下午两点。小林每天早上七点起床，七点半吃早饭，下午一点坐公共汽车去学校，晚上八点复习中文。现在他正在车站等公共汽车，因为车还没来，他要坐车去学校。小美每天早上七点半吃早饭，下午两点做作业，晚上六点吃晚饭，八点上网。现在她正在宿舍上网，因为她在网上找做作业要用的东西。小王每天早上七点起床，下午一点做作业，两点上中文课，晚上八点看电影。现在他正在教室做作业，因为今天的中文课三点才开始，他想先做完作业。”

读法：学生纸上自己记，不显示答案表。第一遍按三个人分段，每个人后停约5秒。第二遍再次按人读，平时与现在之间短停，学生补记录。必要时只重读有分歧的人。

答案：小林7:00起床、7:30早饭、13:00坐车、20:00复习；现在车站等车，车未到，要去学校。小美7:30早饭、14:00作业、18:00晚饭、20:00上网；现在宿舍上网找作业资料。小王7:00起床、13:00作业、14:00中文课、20:00电影；今天改为15:00开课，所以现在先在教室做作业。平时14:00上课与今天15:00开课须分清。

A介绍三人的平时，B介绍三人的现在和原文原因，双方听后补正。个人晚八点的习惯和原因由本人提供；最后介绍刚听到的对方。这里不分HSK两档。帮助：先说每天，再说现在。检查不是把原文原因改成凭空猜测；反馈后重说。15分钟。本活动与12-2、12-3是各自独立的模拟情境，不拼成同一天。

本版预算：15分钟（含示范、听／看、每人表达、反馈与重说；未试教实测）。

## 12-2 听三个人说：在哪儿、做什么

1. 看下一页的空表。听老师读小林、小美、小王的消息，自己写地点、动作和时间。

## 12-3 给同学打电话

1. A是小王，B是小林。A给B打电话，问：在哪里？正在做什么？几点到？B回答。

2. B问几点上课，如果会迟到，怎么办？

### 同页资料

现在：下午1:40　｜　上课：下午2:00—4:00

| 人物 | 在哪里 | 正在做什么 | 到教室的时间 |
|---|---|---|---|
| 小王（A） | 教室 | 等上课 | 已经在教室 |
| 小林（B） | 车站 | 等公共汽车 | 预计下午2:10 |

可用词句：你在哪儿？你正在做什么呢？你几点到？请你告诉老师，我会晚到。

教师：共看资料。A小王给B小林打电话；A正在教室等上课，B正在车站等车，预计14:10到。先按学生页两步说完电话，再从开头完整说一次。B问14:00开课、如果迟到怎么办，双方可商量A帮忙告诉老师。
答案：预计14:10到，比14:00晚10分钟；“预计”不是已经到达。小王当前动作是等上课。可说“请你告诉老师，我会晚到”，再答应帮忙；不把请求当成已完成。示范“喂，小林，你在哪儿？”帮助：先问在哪里，再问几点到。观察双方是否各有问答，反馈后重说。按用户修改，不分级。10分钟。

本版预算：10分钟（含示范、听／看、每人表达、反馈与重说；未试教实测）。

## 综合1 说说你常用的一件东西

你常用的一件东西是什么？是谁的？平时放在哪里？你什么时候用？为什么常用它？

说清东西、是谁的、放在哪里、什么时候用，再说一个原因。

讲一次使用、借用或找这件东西的事。说当时发生什么、你怎么做、后来怎么样。

允许说自己或编一个明确的例子，不要求披露私人物品价值或住址。基础答案要覆盖归属、位置、使用时机和原因；挑战要有经过，不靠更长清单。听者只问一个有关的问题，如“你为什么放在那里？”评分看对象清楚、顺序、理由与回答。无统一范文。

## 综合2 周末出门，你会怎么选？

周末你想和朋友出去。你想什么时候去哪里？怎么去？想买什么、买多少？你觉得多少钱合适？为什么这样安排？

选一个地方，说时间、交通、想买的东西、数量和能接受的价钱，再说为什么。

比较两个出门安排，从天气、时间和花钱说哪里好、哪里不好。选一个，再回答同学不同的想法。

开放计划题，没有给商家实际价格，学生说自己能接受的模拟价钱，不做唯一价格答案或复杂计算。天气可以沿用11-6教学模拟表，明确是练习；不声称实时周末预报。示范“我想周日上午去……”后停止，不给完整范文。听者问“如果下雨呢？”或“为什么不坐公共汽车？”帮助：先说去哪儿，再说几点、怎么去、买什么。

## 综合3 去很近的地方，走路还是坐车？

周末你和朋友去学校旁边的商店买水果。朋友说：“这么近，我们走路去吧。”你同意吗？为什么？如果正在下雨，或者买很多东西，你会改变想法吗？

选走路或坐车，说一个原因。再说下雨时会怎么去。

先说自己的选择和两个原因。听同学不同的想法，回答他的一个理由，最后说什么情况下会改变选择。

不设正式正反队、辩论规则或卡片。先各自答题，再两人简单讨论，允许同意。步行、公交或其他可行方式均可；“商店旁边”只给近的关系，没有具体路程和车费，不要求虚构精确数值。关注是否根据下雨／搬水果改变方案，而非判断哪种交通永远最好。最后重说自己的选择和条件。
