# 效度與使用限制

以下規則來自指定 Markdown 第 3、6、7、8、9、11、13、18、20、21、22、24 節，並由測試固定一部分。

1. 不把課程適配表稱為 ACTFL 官方 rubric。
2. 不把 Can-Do 直接當成 0–3 或百分制成績。
3. 不把 0、1、2、3 換算成 ACTFL 等級。
4. 每個 descriptor 都寫可觀察行為，並附 source construct、task-specific part、adaptation note。
5. 不用文法錯誤數、單字數或課本答案正確率代替對學生學習表現的具體觀察。
6. Presentational 與 Interpersonal 的模式邊界不得混用。
7. 任務完成、feedback、revision、retry 與三模式能力分數分開記錄。
8. 每位學生要有可辨識的個人證據；小組作品不能代替個人證據。
9. 不在每個教材題目後完整填表；只記錄本次活動真正要回饋的面向。
10. 缺席或設備故障使用 `NR`，不能直接記為 0。
11. 沒有自然澄清或確認機會的任務，不可因學生未澄清直接扣分。
12. 內容立場不同不構成扣分理由；應看溝通功能、支持與可理解度。
