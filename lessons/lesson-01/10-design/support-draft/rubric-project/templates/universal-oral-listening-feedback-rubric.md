# 通用口语听说课堂学习表现反馈表

## 课程适配版（课堂反馈用）

本表可用于听力理解、同伴对话、访谈、角色扮演、短讲、报告和重做活动。每次只记录本次活动实际设计、而且有个人证据的观察面向；不计算模式总分，不计算总分，不换算 ACTFL 等级。

本表的 0–3 描述沿用 `data/rubric.zh-CN.json` 的 15 个 criterion。活动名称、任务条件、核心信息、证据数量、互动回合和目标语篇，须在任务目标卡中先写清楚。

## 使用方法

1. 先根据活动选择适用的模式：听力或文本理解选 Interpretive；双向问答、访谈或协商选 Interpersonal；短讲、说明、报告或提案选 Presentational。综合任务可以跨模式选择，但每个 criterion 仍单独记录。
2. 一般活动只选一至两个 focus criteria；PBI 综合任务只有在个人证据充分时才增加面向。没有设计该面向时填 `N/A`，因缺席、设备或记录问题没有证据时填 `NR`，不能把 `NR` 当成 0。
3. 先记录第一次表现 A1，再给一至两项具体反馈。学生完成相同沟通功能、不同信息的平行任务后，另记录 A2。A1 与 A2 分开保存，不自动取最高等级。
4. 圈选等级时使用对应 criterion 的完整描述，不用一个通用印象替代描述。短注必须写学生实际说出、听出、问出、确认或修补的证据。

## A. 诠释理解 Interpretive

用于听力或文本的主旨、核心信息、证据、信息关系和理解策略。没有独立理解证据时，不以同伴告知后的重写代替。

| Criterion | 0 | 1 | 2 | 3 | 本次等级／证据 |
|---|---|---|---|---|---|
| **I1 主旨与沟通目的** | 没有回答，或回答与材料无关。 | 只能说出主题、个别词语或零散信息，不能说明主要意思。 | 主要意思正确，但说话人的目的、观点或范围有一处不清楚。 | 能用一两个完整句准确说明材料的主要意思，并指出说话人的主要目的、立场或观点。 |  |
| **I2 核心信息** | 没有找出任何核心信息。 | 找出少量信息，但遗漏或误解的内容已经改变主要意思或任务条件。 | 只遗漏或误解一项核心信息，整体理解没有改变。 | 找出任务目标卡列出的全部核心信息，并正确说明重要的顺序、比较或关系。 |  |
| **I3 音频／文本证据** | 没有指出任何证据。 | 只能重复材料中的词语，但不能说明这些词语怎样支持答案。 | 至少有一处有效证据，但另一处不具体、不完整或不能完全支持答案。 | 指出任务要求数量的具体词语、句子、时间点或内容；所有证据都能支持答案。 |  |
| **I4 信息关系与推论** | 没有相关回答。 | 只列出信息，不能说明关系；或主要依靠没有证据的猜测。 | 判断大致正确，但解释或支持线索不完整。 | 能说明任务要求的原因、结果、态度、比较、顺序或隐含意思，并指出判断线索。 |  |
| **I5 理解策略与自我修正** | 提供支持后仍没有可用理解证据。 | 需要选择题、引导问题、同伴答案或多次提示后才能修正，无法确认独立理解。 | 在一次中性提醒或规定的再次播放后，能发现并修正部分理解。 | 能利用上下文、语气、连接词、背景知识或笔记检查理解，并在没有别人提供答案时自行修正。 |  |

## B. 人际互动 Interpersonal

用于双向交流中的提问、回答、追问、确认、澄清、重述、换说法、维持互动和可理解度。没有自然的确认或修补机会时，不因学生没有使用该行为而扣除证据。

| Criterion | 0 | 1 | 2 | 3 | 本次等级／证据 |
|---|---|---|---|---|---|
| **P1 沟通功能与任务结果** | 没有尝试、完全离题，或只重复别人说的话。 | 尝试参与，但没有使用正确的沟通功能，或没有形成任务结果。 | 基本完成任务，但遗漏一项必要条件、信息或决定。 | 使用任务指定的沟通功能完成任务，例如确认条件、比较选择、提出建议、协商决定或解决问题。 |  |
| **P2 提问、回答与追问** | 没有形成双向交流。 | 主要只用短句回答；没有主动提问或追问，需要教师持续提问才能继续。 | 能完成主要问答，但追问与对方回答关系不清楚、只是预先准备的问题，或遗漏一个必要回合。 | 能主动开始或推进对话；回答切题，并根据对方刚才的回答提出至少一次真正的追问。 |  |
| **P3 理解、确认与修补** | 在标准化的第二次提示后仍不能理解或回应。 | 经常需要对方重复或改说；只重复原来的说法，无法解决核心误解。 | 大部分信息理解正确；在对方提示后能够澄清或重述，但仍有一项信息没有确认。 | 正确理解对方的核心信息；不清楚时能主动澄清、确认、重述或换一种说法。若没有明显误解，也能确认关键条件。 |  |
| **P4 语篇与词汇运用** | 没有足够语言样本。 | 主要使用单词、短语或背诵句；只有一个独立完整句，难以继续交换信息。 | 在两个主要回合中达到目标语篇，其余回合主要使用短语、重复词或准备好的句子。 | 在开场、发展和回应等主要回合中使用本任务要求的完整句、句子串或相连句子；词汇与主题相关，缺词时能换一种说法。 |  |
| **P5 可理解度与语言控制** | 大部分内容无法理解，或没有可评分语料。 | 需要多次修补；部分关键信息仍无法确认，错误已经影响任务结果。 | 对方需要一至两次自然的确认或重复，但最后能恢复并理解核心意思。 | 对方不需要别人代为解释就能理解核心意思；发音、声调、词序或语法问题不改变关键信息。 |  |

## C. 表达呈现 Presentational

用于个人短讲、说明、报告、提案、比较、叙述或反思。这里观察连续表达，不放入听者即时追问、澄清或协商。

| Criterion | 0 | 1 | 2 | 3 | 本次等级／证据 |
|---|---|---|---|---|---|
| **PR1 沟通功能与内容** | 没有尝试，或内容完全离题。 | 只说出主题或零散信息，没有真正完成指定沟通功能。 | 完成主要沟通功能，但遗漏一项必要内容。 | 完成任务指定的说明、推荐、比较、叙述或表达观点功能，并包含目标卡列出的全部必要内容。 |  |
| **PR2 理由、例子与支持信息** | 没有任何支持信息。 | 只有结论或个人意见，没有相关支持；或所举内容与观点无关。 | 至少提供一项有效理由或例子，但另一项不完整、重复或与观点关系不清楚。 | 提供任务要求数量的理由、例子、事实或细节，并清楚说明它们与主要观点的关系。 |  |
| **PR3 组织与信息顺序** | 没有可辨认的组织。 | 主要是信息清单或彼此不相连的句子，听者需要自己推测关系。 | 基本顺序可以理解，并使用至少一个连接方式，但有一处跳跃、重复或缺少结尾。 | 有清楚的开头、发展和结束；信息顺序合理，并使用因为、所以、首先、另外、不过、最后等连接方式。 |  |
| **PR4 语篇与词汇运用** | 没有足够语言样本。 | 主要使用单词、短语或互不相连的简单句，难以形成完整说明。 | 能使用若干完整句或句子串，但重复较多，部分内容仍依赖背诵句或孤立短语。 | 大部分内容达到本任务指定的完整句、句子串、相连句子或短段落；使用与主题有关的词汇，缺词时能换一种说法。 |  |
| **PR5 可理解度与语言控制** | 大部分内容无法理解，或没有可评分语料。 | 多处内容需要猜测；错误使主要观点、理由或事件关系不清楚。 | 部分内容需要听者集中注意或听一次重复，但整体意思可以恢复。 | 听者能够理解主要观点和支持内容；发音、声调、词序或语法问题不改变关键信息。 |  |
