# 《博雅汉语听说·中级冲刺篇 I》课堂学习表现反馈表

## 课程适配版（课堂反馈用）

### 使用狀態

本表用來記錄學生在一次課堂任務中的學習表現，幫助教師給出下一步回饋。它不是學校成績表，也不產生正式評定。

固定聲明：

> 本表用于课堂学习反馈，不用于学校成绩、正式评定或 ACTFL official rating；0–3 只表示学生在本次任务中表现出的学习状态，不换算为 ACTFL 等级。

|---|---|---|---|---|

| 嘗試 | 角色 | 對話夥伴 ID | 證據連結／檔名 | 是否補評 |
|---|---|---|---|---|
| □ A1　□ A2 |  |  |  | □ 是　□ 否 |

### 使用規則

- 三模式各五項，每項 0–3；每次只圈出最能描述本次表現的等級，不計總分。
- `NR` 表示無法取得證據，不等於 0；沒有設計該觀察面向時可使用 `N/A`，並寫明原因。
- `task_completion_score` 另列，只作任務回饋，不加入任何總分。
- A1 與 A2 分開保存；retry 不自動取最高分。
- 一次活動可以只選 1–2 個 focus criteria；教師不必在每個教材題目後填完整表。
- 回饋重點應包含一條具體證據與一個下一步行動，不用分數代表學生整體程度。

## B. 人际互动：Interpersonal Speaking

來源構念：S04、S08、S09、S19。詳見 `data/source-map.json`。

| 评价项目 | 3 完整达成 | 2 部分达成 | 1 初步证据 | 0 无可评分证据 | 得分 |
|---|---|---|---|---|---:|
| **P1. 沟通功能与任务结果** | 使用任务指定的沟通功能完成任务，例如确认条件、比较选择、提出建议、协商决定或解决问题。 | 基本完成任务，但遗漏一项必要条件、信息或决定。 | 尝试参与，但没有使用正确的沟通功能，或没有形成任务结果。 | 没有尝试、完全离题，或只重复别人说的话。 |  |
| **P2. 提问、回答与追问** | 能主动开始或推进对话；回答切题，并根据对方刚才的回答提出至少一次真正的追问。 | 能完成主要问答，但追问与对方回答关系不清楚、只是预先准备的问题，或遗漏一个必要回合。 | 主要只用短句回答；没有主动提问或追问，需要教师持续提问才能继续。 | 没有形成双向交流。 |  |
