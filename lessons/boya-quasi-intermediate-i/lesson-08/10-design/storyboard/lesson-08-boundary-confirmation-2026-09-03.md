## 线上预习 PPT

固定顺序：封面 → 学习流程 → 学习目标（Can-Do）→ 词语 → 听力和阅读练习 → 短文一 → 短文一的句式 → 短文二 → 短文二的句式 → 短文三 → 短文三的句式 → 综合表达 → 我觉得很难的地方 → 课前检查 → 谢谢。

承担内容：

- 阅读三篇短文前，打开教材按印刷页码阅读并听取对应音频。
- 词语页覆盖 canonical source 的全部生词和专有名词；越南文意思来自课程契约，例句来自例句数据库。
- 记录短文主旨、人物经历、军事思想、作品影响和自己不懂的地方。
- 预习本课句式，并为实体课的口语活动准备个人信息或问题。

## 实体课 PPT

固定顺序：封面 → 学习流程 → 学习目标 → 先想一想 → 听力练习 → 前三个听力（n-1、n-2、n-3）→ 请你说说（简单的问题练习口语）→ 每篇短文依序完成「短文 → 短文听力练习（通常 n-4/n-5/n-6）→ 口语练习 → 6—8句介绍刚刚的内容 → 你说的和短文哪里不一样？→ 句式练习 → 针对该 section 的小问答（可选）」→ 综合表达 → 全文介绍（课本填表）→ 根据课本回答问题 → 请你说说（介绍学生个人信息）。

承担内容：

- 先看题目、抓关键词，再听并记录重点，最后回答和核对。
- 以同伴问答、短文重述、内容比较、句式使用和个人口语表达为主。
- 三篇短文分别使用教材对应的听力练习和口语产出；没有来源的小问答不自动添加。
- 综合表达使用课本信息表、课本问题和学生个人信息介绍。
