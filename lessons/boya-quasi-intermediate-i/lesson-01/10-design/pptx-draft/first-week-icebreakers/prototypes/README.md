# 第一周破冰：三种视觉 prototype

这三份 PPTX 使用同一组课堂内容，只改变视觉系统。每份包含四张投影页：

1. 主题与课堂流程
2. 教师先说：学生先听
3. 听完以后，学生来问老师
4. 小组设计新学期活动或学习计划

## 01｜瑞士编辑风

高留白、强网格、黑色大标题和少量彩色强调。整体最成熟、最清楚，适合希望第一堂课看起来像正式大学课程的版本。

[打开 PPTX](lesson-01-破冰原型01-瑞士编辑.pptx)

## 02｜校园海报风

大字、圆环、彩色点和轻微错位。三份中最有活力，学生一进教室就能感受到“第一周、一起开始”的气氛。

[打开 PPTX](lesson-01-破冰原型02-校园海报.pptx)

## 03｜生活杂志风

使用侧边色带、暖色局部色块和编辑式跨页。比 02 更安静，比 01 更有生活故事感，适合把破冰做成“认识彼此的第一段故事”。

[打开 PPTX](lesson-01-破冰原型03-生活杂志.pptx)

## 状态

这些文件是 `prototype_only`，不是 `20-approved` 或 `40-release` 版本。三份均为 16:9 原生可编辑 PPTX，学生端可见文字最低 20 pt，使用 KaiTi 与 Times New Roman，不需要打印材料。
